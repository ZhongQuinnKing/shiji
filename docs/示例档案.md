# 示例档案（看看"轻档案"长什么样）

> 这份是**示例**，不是你的档案。你使用拾级的过程中，它会在聊到深处时自然形成
> 一份类似的东西（本地环境存在技能目录旁的 `profile/`；平台环境走平台自身记忆），
> 随时可看、可改、可删。规则见 `references/01-档案与相处守则.md`。

---

**我是谁**：大三，一所双非学校的会计学专业，家在县城，家里第一个大学生。

**我的处境**：绩点 3.4（专业 20 名左右），没有实习，六级刚过；在纠结考研还是
直接就业，家里希望我考公。

**我想去哪**：留在大城市做财务 / 审计方向；如果考研，想考 985 的会计专硕。

---

**它长什么样，三个特点**：

1. **就三格**——我是谁 / 处境 / 想去哪；多余的一个字不记
2. **随聊随记**——聊到深处顺手记下，不审问、不索要隐私
3. **可看可改可删**——说"看看我的档案"就能看；说"改一下"就改；说"删了"就删，
   删完告诉您删了什么
