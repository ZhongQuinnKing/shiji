# 常见问题（FAQ）

先看这里，再提 issue——高频问题基本都在这。

## 安装与使用

**Q：怎么装？**
三种路子，挑一条：
- Claude Code / 命令行 AI：`git clone https://github.com/ZhongQuinnKing/shiji ~/.claude/skills/shiji`，
  或直接跑仓库里的 `install.sh`
- Codex / 豆包：一句话——"请把 `https://github.com/ZhongQuinnKing/shiji` 克隆（下载）
  并按其中的 AGENTS.md / 技能方式使用"
- ChatGPT、Kimi、通义、元宝等：下载后把用得到的篇章传进知识库/智能体，配一句启动指令
详见 [安装指南.md](../安装指南.md)。

**Q：要花钱吗？要不要注册？**
全免费、无会员墙、不需要注册任何东西。你用的 AI 助手本身可能要钱，那是它的账。

**Q：支持哪些 AI 助手？**
只要能读文件都行——原生技能平台（Claude、豆包、Codex）体验最完整；
其他平台按"知识库 + 启动指令"用，内容完全一样。

**Q：我的 AI 上下文不大，一百五十多篇装不下怎么办？**
三种加载方式，按你的 AI 挑：

1. **全量**（上下文 128k 以上，如 Claude、Gemini）：整包喂进知识库，不用挑。
2. **按线分片**（最常用）：只喂跟你情况相关的两三条线——比如大三准备考研，
   就喂 `kaoyan/` 加 `study/` 再加红线清单。
3. **最小组合**（小模型、手机端）：只喂三样——`00-红线清单.md`（保证不越线）、
   `SKILL.md` 里"怎么回答（路由）"一节（保证找对篇）、你当前问题相关的一两篇。
   缺什么它会说，你再补。

一句话：**红线清单永远在场，其余按需加载**——拾级本来就是"按问题读那几篇"
的设计（渐进披露），不必一次装全。

**Q：手机能用吗？**
能，走"知识库路线"最顺：手机浏览器打开仓库页 → Code 按钮下载 ZIP → 把最小
组合（见上一问第 3 种）传进你手机上的 AI App（豆包、DeepSeek、Kimi 都支持
上传文件）。手机端建议就用最小组合——轻、够用。

**Q：需要联网吗？**
方法类问题不联网也能答（家底够厚）；政策/考情/行情类，它会**主动联网查最新**
并注明来源（双源回答）——分不清"存的"和"刚查的"，你可以直接问它。

## 内容与时效

**Q：内容会不会过时？**
**政策类会**——这是所有静态内容的天性。我们的三道防线：①双源回答：时效问题
必联网、以官方为准；②核心政策篇目标注「最后核验」日期；③月度巡检 +
[MAINTAINING.md](../MAINTAINING.md) 的复查周期表。发现过时，欢迎用「内容反馈」
模板提 issue（30 秒）。

**Q：为什么有的篇目写着"以官方当年公告为准"？**
故意的。政策年年微调，与其写死一个会过期的日期，不如教你"去哪查、怎么查"——
顺手还告诉你今年的变化点在哪。

**Q：答得不对怎么办？**
两种可能：①它把"拿不准"标出来了——这是诚实原则，不是错误；②真错了——用
[内容反馈](https://github.com/ZhongQuinnKing/shiji/issues/new/choose) 模板提 issue，
附上官方来源，我们核完就改，改动会进 CHANGELOG。

## 更新与卸载

**Q：怎么更新到最新版？**
- 命令行环境：重跑一次 `install.sh`（或 `cd` 到技能目录 `git pull`）
- 上传制平台（豆包等）：下载新版、重新上传覆盖（保留原路径即可）
更新内容看 [CHANGELOG.md](../CHANGELOG.md)。

**Q：怎么知道出新版了？**
两个办法：① 到仓库页看 [CHANGELOG.md](../CHANGELOG.md) 与最新提交日期；
② 点仓库右上角 **Watch → Custom → Releases only**——发布新版会发邮件提醒你
（只提醒发版，不打扰）。

**Q：不用了怎么卸载？**
删掉那个文件夹就完了——它不写系统目录、不装服务、不留后台进程。
（如果它在平台里存过你的"轻档案"，说一句"删了"即可。）

## 隐私与边界

**Q：它会记录我聊了什么吗？收集数据吗？**
不收集、不上传。它只有一份"轻档案"（你是谁、在烦什么、想去哪），
本地环境存在你机器上的 `profile/` 里，**可查可改可删**；平台环境用平台自己的
记忆机制，同样可删。详见 [NOTICE.md](../NOTICE.md) 与 README 的透明说明。

**Q：能帮我写论文 / 做作业 / 代考吗？**
不能——红线写死：不代笔、不诊疗、不防诈、不查人、不涉违禁。
它教你方法、给你话术、指给你官方入口，但**动手的人必须是你**。

**Q：能拿它做商业用途 / 二次开发吗？**
看许可四档：自己用自己改——自由；原样分享——署名即可；**修改后对外发布——先来
拿授权**；商业使用——必须联系议价。全文见 [NOTICE.md](../NOTICE.md)。

## 参与

**Q：我想纠个错 / 提个建议 / 晒个用法？**
- 纠错、建议、投稿 → [issues](https://github.com/ZhongQuinnKing/shiji/issues/new/choose)
  或 [Discussions](https://github.com/ZhongQuinnKing/shiji/discussions)
- 想动手改 → [CONTRIBUTING.md](../CONTRIBUTING.md)：三种玩法（纠错 / 增补 / 工具），
  门槛最低的一种 30 秒能完成

**Q：我有个用法它答不上来，是 bug 吗？**
可能不是——试试把处境说具体点（"我大四、没实习、想投产品岗"好过"简历怎么写"）。
如果确实是库里没有的知识，它会诚实说明，并给出收录通道。
