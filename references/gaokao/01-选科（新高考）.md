# 高考·选科（新高考）

选科不是"选喜欢的课"，是**选你能报的专业范围**。分数可以靠复习补，资格一旦锁死，高考完再想改，只剩复读一条路。

**适用范围**：本篇只对新高考省份有用。老高考省份分文理科，不存在选科问题，请直接看 `02-志愿填报规则`。新高考内部又分 3+3 与 3+1+2 两套，赋分细则、改科窗口、科目开考安排各省不同，一律以**你所在省教育考试院当年公告**为准。

## 一、两套模式的区别

**3+3**：语数外三门统考，再从六门（浙江是七门）里任选三门。语数外用原始分，选考的三门按等级赋分计入总分。

**3+1+2**：语数外三门统考；物理、历史二选一，叫首选科目，用原始分；再从政治、地理、化学、生物四门里选两门，叫再选科目，按等级赋分。

**等级赋分是什么**：再选科目不看卷面分，看你在这一科考生里的排名。规则是把所有考生按原始分从高到低划成 A 到 E 五档，各档人数比例大致为 15%、35%、35%、13%、2%，再分别转换到 100—86、85—71、70—56、55—41、40—30 五个分数区间。赋分起点 30 分，满分 100 分，转换后考生排序不变。各省的档位比例与区间略有差异，以本省办法为准。

物理与历史不赋分，是因为两类分列计划、分开划线，同类考生用同一张卷、同一个排名队列，原始分本身可比。

## 二、选科与可报专业的关系

教育部《普通高校本科招生专业选考科目要求指引（通用版）》是这件事的总闸。它落地之后，理工农医四大门类里绝大多数专业要求**物理 + 化学两门同时必选**。

- 计算机、电子信息、人工智能、电气、自动化、航空航天、集成电路、机械、材料：物理 + 化学
- 数学、统计、化学、生物科学等理学类：物理 + 化学
- 临床医学、口腔医学：物理 + 化学，部分院校再加生物
- 农学、环境、食品、动物医学：多数院校要求物理 + 化学
- 只选物理不选化学：可报专业面明显收窄，主流工科与临床医学基本关门

不绑物理化学的那一边：

- 法学、汉语言文学、新闻传播、外语：多数不限选科
- 经管类：多数物理或历史均可，但金融工程、经济统计、数字经济这类偏量化的专业常要求物理
- 公安学类（治安学、侦查学等）：一般要求必选政治；公安技术类多要求物理 + 化学
- 护理学、中医学：各校差异大，从"不限"到"物化双选"都有

**口径纪律**：同一个专业，A 校要物理 + 化学，B 校可能只要物理；同一所学校，今年的要求和去年也可能不同。唯一权威是本省当年招生专业目录加目标校当年招生章程。

## 三、什么时候定，能不能改

多数学校在高一结束或高二上学期完成选科分班，之后按组合走班。少数省份允许高二上学期结束前调整。

改科的代价有三层：落下的课要自己补，尤其化学、生物这类连贯性强的科目；部分省份对"改科后按新科目参加考试"有明确时间要求，过期只能按原科目考；改科往往连带影响分班、师资和同学圈。

所以有一种情况必须早改：**想报的专业被现行选科卡死**。想读临床医学却选了历史，这不是"努力一下"能解决的。

## 四、怎么在"分数好看"与"专业面宽"之间取舍

先纠正一个幻觉：**赋分只看排名，不看卷面**。选一门高手扎堆的科目，你的卷面分不变，赋分会被压下去；选一门考生整体偏弱的科目，同样的卷面分能赋得更高。所以"哪科好拿分"这个问题，真正的问法是"我在哪一科的考生群里排名更靠前"。

三条取舍纪律：

1. **专业面优先于分数好看。** 专业面是资格，分数是程度。先保证门开着，再谈进门多高。物理 + 化学再加任意一科，本科可报专业覆盖率极高；放弃化学，等于主动关掉一大片门。
2. **别为躲强者而牺牲方向。** 为了避开化学的竞争去选地理，最后想报的专业全要化学，这是本末倒置。
3. **第三科看性价比。** 物化锁定之后，第三科主要看两件事：你在这一科考生群里的相对位置，以及它能不能顺带满足某个专业的额外要求（比如想报公安学类就得有政治）。

## 五、场景细分

**目标明确型**（想学医、想学工）：物理 + 化学是底线，第三科按专业要求补。想学医且目标校要求生物的，第三科就别犹豫。

**目标模糊型**（不知道学什么）：选物理 + 化学，再加一门自己排名靠前的科目。这个组合把门开到最大，把决定往后推两年，是模糊期最稳的答案。

**偏文型**（擅长记忆与表达）：历史 + 政治 + 地理或生物。这条路能走得很好，但要清楚它锁掉了什么。理工农医绝大多数专业从此关门，将来能走的是人文、社科、经管、法学、语言、教育这些方向。它不是"差"，是窄而深，选之前得认这个窄。

## 六、话术成品句

问班主任或教务（问具体的，别问"我该选什么"）：

> "老师，我想确认三件事：我们学校这几门选考科目分别有几个班、走班怎么排；往年选这几个组合的同学，最后赋分大概在什么区间；如果我高二上学期想调整，最晚什么时候提。"

问高校招生办（打电话、发邮件都能问）：

> "老师您好，我是 XX 省高中生，选科是 XX 组合。想确认贵校 XX 专业今年是否要求物理和化学同时必选，以及明年会不会调整。"

## 七、一个真实场景

小周想学计算机，听同学说"化学难"，选科时改成了物理 + 生物 + 地理。高二下学期他翻招生目录才发现，本省所有开设计算机类专业的院校，选考要求一栏写的都是"物理 + 化学"。他回头找班主任改科，学校答复走班已经排定，下一次调整在高三上，来不及补课。

那年他高考考得不差，但填报时所有计算机专业都提示"选考科目不符"，一个都报不了。

**复盘**：他不是输在分数上，是输在从没打开过那本招生专业目录。选科之前查一遍目标专业的选考要求，只要十分钟。

## 八、依据与边界

- **全国一致**：3+1+2 的基本框架、首选科目用原始分、物理类与历史类分列计划分开划线；《选考科目要求指引（通用版）》"物理 + 化学"的总体方向
- **各省不同**：赋分的档位比例与区间细则、改科窗口、选考科目的开考安排、走班制度
- **年年会变**：高校的选考科目要求随当年招生专业目录更新，不能照搬往年
- **拿不准的**：某校某专业今年到底要不要化学，只能查它当年的招生章程，或直接问招生办

## 一句话

选科是用一次决定，换未来四年的所有可能。分数可以补，资格补不回来。
