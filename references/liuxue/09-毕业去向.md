# 留学·毕业去向（留下、回国、继续读）

临近毕业的三岔路：**留下工作、回国、继续读书**。选之前先把"身份账"算明白——
**工签/移民政策变化频繁，所有规则以各国官方最新口径为准**，本篇给决策框架。

## 一、三条路，三个算盘

### 路线 A：留下来工作

- 核心变量是**毕业工作签体系**（各国都有面向留学生的过渡签：美国 OPT 类、
  英国 Graduate Route 类、加拿大 PGWP 类、澳洲 485 类、香港 IANG 类）——
  **时长、能不能带家属、转永居难度，各国差别巨大**，按自己的专业和时间查官方口径
- 想留下的现实：**求职要提前一年启动**（当地招聘节奏＋工签时间线双重约束）
- 留不下的常见原因不是"不够优秀"，是"启动太晚"

### 路线 B：回国

- 第一件事：**学历认证**（留服认证——回国就业、落户类手续的前提，早办）
- 时机核心：**应届生身份**（部分城市落户、校招都认它——算准毕业时间窗口）
- 执行细节：时间线错位、海归专场、留学生落户——详见
  `job/32-海归回国求职`（那边是"回来了怎么打"，这里是"回不回的决策"）

### 路线 C：继续读

- 硕→博：走申请-考核/套磁（同 `grad/05` ＋ `08` 的博士篇）；
  海外申博看重研究经历，**硕士期间就要攒**
- 博→博后：学术路线的一站（也有产业界的研究岗做过渡）
- 自查一句：继续读的理由是"往前走"（方向更清晰）还是"往后躲"
  （不想面对就业）？——用 `kaoyan/01` 的问法问自己

## 二、决策四格（各打一分，别凭"大家都说"）

1. **身份可获得性**：留下来对你有多难？（专业/国家/时间都是变量）
2. **职业发展**：哪个市场更认你的专业？（同一个学位，两地含金量不同）
3. **家庭与生活**：离家的距离、长期规划、伴侣的去向
4. **个人偏好**：你想在哪里生活——这条不丢人，它是真实且重要的变量

四格各有倾向时，**听"最不可逆"的那格**：身份窗口会过期、应届身份会用掉，
生活偏好可以慢慢调。

## 二·补、四格打分示范（同一条路也要拆开看）

以"想留英工作但家里希望回国"为例：

| 维度 | 留下（打 1-5） | 回国（打 1-5） |
|------|----------------|----------------|
| 身份可获得性 | 3（工签有窗口但要抢） | 5（天然可回） |
| 职业发展 | 4（行业在这边强） | 3（国内同类岗位也认） |
| 家庭与生活 | 2（离家远、父母渐老） | 5 |
| 个人偏好 | 5（喜欢这边的节奏） | 3 |

**读法**：两侧总分接近 = 这是真纠结，不是"想不开"——**这时候听"最不可逆"
的那格**（身份窗口会过期、应届身份会用掉），先留下试三年，
不行再回，比"先回再想出去"可逆得多。

## 二·补2、案例：两条路的两年后

【情境】两位同班留学生的选择——

- **小 Z 留当地工作**：第 1 年拿毕业工签进了一家本地公司，
  第 2 年跳槽涨薪 30%；但身份仍是"每年续"的状态，且两年没回过家。
- **小 L 毕业即回国**：赶上应届窗口进了大厂，落户办成、离家两小时高铁；
  但偶尔会想"要是当初试试留下……"

【拆解】两个人都没有"错"，但都各有代价：小 Z 付的是"不确定性+想家"，
小 L 付的是"没试过的想象"。**决策的成熟＝提前把代价看清楚，
然后认下你要付的那一份。**

## 三、时间线（无论选哪条，提前一年动）

- **留下**：入学就开始研究工签规则 → 毕业前一年跑当地招聘
- **回国**：毕业前一年盯国内秋招（远程面试＋提前批补偿错位）→
  毕业回国 → 办认证 → 接春招/补录
- **读博**：提前一年套磁（`grad/05` 的三件套）

## 四、四个常见坑

1. 到毕业才想"留不留"——工签和招聘都有时间窗，过期不候
2. 回国错过应届生窗口——有的城市落户只认毕业当年（算准）
3. 只押一条路——三条线的准备（求职/回国手续/升学材料）**可以并行**，
   稳的人从不单押
4. 学历认证拖延——手续要时间，回国落地第一件事就办

## 一句话

毕业去向没有标准答案，只有**算清楚了的选择**——
身份账、职业账、生活账各算一遍，提前一年动身。
**无论选哪条，别选"被时间推着走"的那条。**
