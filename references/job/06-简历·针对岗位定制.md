# 简历·针对岗位定制

## 为什么必须定制

HR 一眼看穿"群发简历"：他招运营，你最大的亮点是编程；他招技术，你满篇社团。
一份简历打天下 = 每份都不匹配。

## 第一步：精读 JD（拆三层）

1. **硬性要求**（学历/专业/技能词）——不满足就换岗，别硬投
2. **加分项**（"有 XX 经验优先"）——有对应素材的，写进简历
3. **暗语翻译**（黑话对照）：

| JD 上写的 | 大概意思 |
|-----------|-----------|
| 抗压能力强 / 能适应快节奏 | 活多节奏快，偶尔加班 |
| 有较强的沟通协调能力 | 要频繁对接别人 |
| 有主人翁意识 / 自驱力强 | 没人手把手带你 |
| 熟悉 XX 行业动态 | 面试会问行业理解，提前准备 |
| 可接受长期在 XX 地区 | 异地岗，想清楚 |

**拆解实操范例**（拿"新媒体运营"岗演示一遍）：

> JD 原文（节选）："负责小红书/公众号内容运营，提升账号数据；
> 有数据分析能力，能根据数据优化内容；具备一定的文案功底；
> 有短视频剪辑经验者优先；能承受快节奏工作节奏。"
>
> 拆三层：
> - 硬性：内容运营 + 数据 + 文案（三条都要有证据）
> - 加分：短视频剪辑（有就写，没有不硬凑）
> - 暗语："快节奏"=活多；"提升账号数据"=面试必问"你怎么提升的"
> （→ 简历里对应布点：账号数据放第一行；"数据优化"用具体的"根据复盘调整选题"落点）

## 第二步：关键词对齐（带操作步骤）

系统先筛关键词——JD 的技能词一个不出现 = 可能到不了 HR 眼前。

**操作步骤**：
1. 把 JD 里的技能词/工具词圈出来（10-15 个）
2. **逐一在你简历里"查找"**（Ctrl+F）——真会的：用**一模一样的词**写出来
   （JD 说"数据分析"，别只写"会 Excel"→ 写"数据分析（Excel/SQL）"）
3. 不会的：**不硬塞**（塞进去的每个词，面试都可能被问）
4. 换岗位：这一步**重跑**（对照 `26-JD逆向法` 的十份 JD 求交集）

## 第三步：内容排序跟着岗位走

- 投运营岗：最相关的实习/项目放经历区第一条，写满三行
- 投技术岗：项目和技术栈往前，校园经历压到一行
- 投国企/考公：教育背景与学生干部的重要性上升

**定制不是重写**，是"换朝向"——素材不变，把同频的转到正面。

## 第四步：多版本管理 + 定制的"度"（防过度）

- 按方向备 **2-3 版**；每投一岗做 **20% 微调**（甜点区）
- **五个微调点**：求职意向 / 关键词 / 排序 / 开头一句亮点（无摘要时补一行）/
  自我评价版本
- **过度定制的坑**：改到一半以上就是重写（时间成本失衡），**只在"最想去的岗"
  才重写**；微调版本间别改到"经历失真"（面试对不上=灾难）
- 文件命名：`姓名-学校-产品-A版.pdf`；投递记录留表（见 `09`）

## 第五步：网申字段 vs 附件简历（一致性——新）

网申系统里还有一份"在线简历"（字段填的）——**和附件必须对得上**
（时间/职位/数字不一致 = 直接减分，系统和人都会看两遍）。
填完做一次**对照检查**：附件里的每段经历，系统字段里都有对应且一致。

## 附：求职信（Cover Letter——外企/部分岗位）

**什么时候要**：外企、部分国企/事业单位、申请类岗位点名要时；
**中文邮件投递的"正文"就是求职信**（见 `09` 的邮件范例）。

**三段式**（半页以内）：
1. 我是谁 + 投什么岗 + 从哪看到的
2. **为什么是你们**（一句具体的，显示你做过功课）+ 我的匹配点（一个最硬的证据）
3. 期待 + 感谢 + 联系方式

## 自检（偷懒但有效）

改完对着 JD 念一遍简历：**给陌生人看半页，他能猜出你投的哪个岗位吗？**
猜不出来，滚回去再改。
