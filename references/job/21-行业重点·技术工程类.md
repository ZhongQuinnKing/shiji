# 行业重点 · 技术工程类

（计算机、电子、通信、机械、土木、化工等工科方向的求职重点。
**结构：看什么 / 写什么 / 考什么**；细分方向逐个深写。）

## 一、看什么（面试官的眼）

**项目与作品 > 实习 > 学历 > 一切**。技术岗是"用作品说话"的行业：
- 项目：做了什么、解决什么问题、你的部分、结果数字（性能/规模/精度/成本）
- 作品：GitHub/线上作品（**有链接放链接**）
- 实习：对口实习大加分（没有用项目补，见 `04`）
- 证书：行业认证是加分（如华为 HCIA/HCIP 等头部厂商认证）

## 二、写什么（通用原则）

- **项目前置**（教育背景之后直接项目，用 `templates/05-技术岗版`）
- **技术栈写准**：只写"真用过"的（写了就被问）；**15-20 项聚焦清单 >
  40 项冗长清单**（可信度更高）
- **问题-方案-结果句式**："针对接口慢的问题（问题），引入缓存+优化 SQL（方案），
  响应时间从 800ms 降至 120ms（结果）"
- **项目按"技术闭环"写**：背景与目标 → 技术选型 → 你独立负责的模块与难点 →
  量化成果（效率提升/响应时间/成本节省）→ 代码/演示链接

## 三、考什么（校招流程）

**笔试**（算法题/专业题为主——按方向刷：牛客/LeetCode）→ **技术面**（1-3 轮：
项目深挖 + 基础（操作系统/网络/数据库/专业基础）+ 代码）→ **HR 面** → 部分加面。

**项目深挖的"七层树"**（面试官会按这个深度挖——写上去的项目提前过一遍）：
```
① 背景（为什么做）② 你的角色（独立做了什么）③ 原理（底层怎么跑）
④ 方案（为什么选它、替代方案）⑤ 实现（关键细节）⑥ 验证（怎么证明有效）
⑦ 故障与复盘（踩过什么坑、后来改了什么）
```
**讲不清的层，别写进简历。**（七层全过一遍的项目，就是你面试的王牌。）

## 四、细分方向（各方向深写）

| 方向 | 一句话 |
|------|--------|
| 计算机·后端 | 高并发/分布式/数据库 + 语言深度 |
| 计算机·前端 | 框架原理/工程化/性能 + 作品（个人站） |
| 计算机·算法 | 论文/竞赛/实习 + 数学（门槛最高） |
| 电子/半导体 | 芯片测试/PCB/Verilog + 动手项目 |
| 机械/智能制造 | CAD/CAE/PLC + 工艺与设备项目 |
| 土木/建筑 | 规范/BIM/造价 + 工地实习 |

### 计算机·后端（岗位最多，竞争最密）
- **栈**：一门服务端语言到"能干活"（Java/Go/Python/C++ 选一深练）+ HTTP + MySQL
  （索引/事务）+ Redis + 消息队列 + 分布式基础
- **面试高频**：并发、MySQL 调优、Redis 场景、一致性
- **标准**：能独立开发完整功能模块（"能自己扛"）
- **提醒**："后端转一切"是错觉——先在一个语言上扎到深度

### 计算机·前端（早不是"切图"）
- **栈**：HTML/CSS/JS + React/Vue + 浏览器原理 + 性能优化 + 工程化（Vite）
- **高频**：事件循环、闭包、组件通信、手写代码
- **标准**：高性能、可维护的页面（难点在性能与状态管理）
- **加分**：个人站点/组件库放链接——跳过初筛概率高一截

### 计算机·算法（门槛与光环都最高）
- 三向：研究向 / 工程向 / 应用向（推荐、搜索、NLP、CV）
- 硬门槛：数学 + 模型理论 + 框架实战；**硕士近乎起步价**，顶尖岗看顶会论文
- 现实（2026）："冰火两重天"——没有论文/强实习**别硬冲**，从工程岗入行更稳

### 电子 / 半导体（补——本方向专属）
- **关键词**：芯片测试、PCB 设计、Cadence、Verilog、模拟/数字电子、半导体工艺、
  封装、信号处理、仪器操作
- **简历重点**：**动手项目 > 理论课分**——电子设计大赛/实验室项目/自制的板子，
  写清"设计-打样-调试"的完整闭环
- **去向**：芯片公司/通信设备/央国企研究院所（流程见 `24`）

### 机械 / 智能制造（补）
- **关键词**：CAD(SolidWorks/AutoCAD)、CAE(ANSYS)、机械设计、工艺优化、
  PLC 编程、设备运维、质量检测
- **简历重点**：课程设计/竞赛（机械创新设计大赛）/实习车间的完整项目——
  写"参与哪个环节+解决什么问题"
- **去向**：制造企业/新能源车企/央国企（很多走笔试+结构化面试，见 `22`/`24`）

### 土木 / 建筑（补）
- **关键词**：制图（CAD/Revit/BIM）、结构计算、施工组织、造价（广联达）、规范
- **简历重点**：工地实习（哪怕短）> 纯课程；测量/算量/画图的实操写细
- **去向**：施工单位/设计院/中字头央企（校招笔面试流程同央国企，见 `24`）

（各方向的关键词更多，见 `25-专业关键词库`；目标岗位的具体要求，
用 `26-JD逆向法` 拉最新的。）

## 五、常见坑

- 写"精通 C++" → 被问到第三层就挂——**写"熟练"保平安**
- 项目答辩把团队的活说成自己的 → 一问细节穿帮
- 没有项目就硬编 → 课程设计认真做=最好的素材（`04`）
- 只刷题不理解 → 换个问法就露馅
- 简历"什么都写一点" → 深度审查过不去（聚焦 1-2 个方向）

## 六、给"零项目"同学的三条路

1. 课程大作业按项目标准重做（补文档+放 GitHub）
2. 跟一个开源项目（哪怕修文档/改小 bug——真实协作）
3. 自己造一个（解决自己实际需求的小工具——完整做完）

## 七、备考路线（校招实操）

**三层递进**：①算法题=入场券（笔试 150 题起，稳妥 200-300，算法岗 400+，
按题型刷不刷量）②工程能力=胜负手（项目深挖。**很多人挂在"项目讲得支支吾吾"**）
③系统设计=拉差距（大厂终面"设计短链/秒杀"——有意识、说得出思路）。

**三维投入**：算法 40% / 技术栈 35% / 项目 25%。
**项目优先级**：实习 > 开源 > 个人；硬指标：1000 行+、能跑、有文档；
避开烂大街（"电商仿站"）——做自己真在用的。

**简历按方向换脸**：用 `06`/`26` 对齐每个岗位 JD。

## 八、趋势信号（2026 观察，以最新为准）

1. **"AI 不是岗位，是技能"**——"有 AI 应用经验者优先"越来越普遍，
   用 AI 做点真东西放进项目，是最省力的差异化
2. **务实选方向**——后端/前端仍是主力；新能源/芯片/半导体等国家重点领域需求大，
   跟目标行业的招聘节奏走（`24`），别盲目追风口
