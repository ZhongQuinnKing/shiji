# 行业重点 · 技术工程类

（计算机、软件、电子、机械、土木、化工等工科方向的求职重点。**结构统一：看什么 / 写什么 / 考什么**）

## 一、看什么（面试官的眼）

**项目与作品 > 实习 > 学历 > 一切**。技术岗是"用作品说话"的行业：

- 项目：做了什么、解决什么问题、你的部分是什么、结果数字（性能/规模/准确率）
- 作品：GitHub 仓库/线上作品（**有链接放链接，比描述强十倍**）
- 实习：有对口实习=大加分（没实习用项目补，见 `04-简历·没实习怎么办`）

## 二、写什么（简历重点）

- **项目前置**：教育背景之后直接项目经历（用 `templates/05-技术岗版.html`）
- **技术栈写准**：语言/框架/数据库/工具——**只写"真用过"的**（写了就被问）
- **问题-方案-结果句式**：
  "针对接口慢的问题（问题），引入缓存+优化 SQL（方案），响应时间从 800ms 降至 120ms（结果）"
- **难点是金矿**：你踩过的坑、权衡过的方案——面试官最爱问这个

## 三、考什么（校招流程）

**笔试**（算法题为主：刷题平台练起来——提前 2-3 个月开始）
→ **技术面**（1-3 轮：项目深挖 + 计算机基础（操作系统/网络/数据库）+ 代码）
→ **HR 面**（稳定性/性格）
→ 部分公司加面（交叉面/主管面）

**项目深挖的应对**：面试官会顺着简历往深处问——**每个写上去的项目，
你都要能讲清"为什么这么做、考虑过什么替代方案、你独立做了哪部分"**。
讲不清的部分，别写。

## 四、细分方向（简要差异 + 各方向深写）

| 方向 | 侧重 |
|------|------|
| 后端 | 高并发/分布式/数据库 + 语言深度 |
| 前端 | 框架原理/工程化/性能 + 作品（个人站） |
| 算法/数据 | 论文/竞赛/实习 + 数学基础（门槛最高） |
| 测试/运维 | 工具链/脚本能力 + 细心（稳） |

### 后端（岗位最多，竞争也最密）

- **技术栈**：一门服务端语言到"能干活"（Java/Go/Python/C++ 选一深练）+ HTTP + MySQL
  （索引、事务）+ Redis + 消息队列 + 分布式基础
- **面试高频**：并发编程、MySQL 调优、Redis 场景题、一致性
- **评价标准**：能不能独立开发一个完整功能模块（不是"跟过项目"，是"能自己扛"）
- **现实提醒**："后端转一切"是错觉——语言只是工具，**先在一个语言上扎到深度**

### 前端（早不是"切图"了）

- **技术栈**：HTML/CSS/JS + React 或 Vue + 浏览器原理 + 性能优化 + 工程化（Vite 等）；
  Node、跨端、可视化是加分项
- **面试高频**：事件循环、闭包、组件通信、小代码手写
- **评价标准**：高性能、可维护的页面——**今天的难点在极致性能与复杂状态管理**
- **加分动作**：个人站点/组件库放链接——**有作品的候选人跳过初筛的概率高一大截**

### 算法（门槛和光环都最高）

- **三向分化**：研究向（论文/模型）、工程向（推理/优化）、应用向（推荐/搜索/NLP/CV）
- **硬门槛**：数学 + 模型理论 + 框架实战；**硕士几乎是起步价**，顶尖岗只认顶会论文
- **现实（2026）**："冰火两重天"——顶尖人才被高薪抢，普通算法岗极度内卷；
  **没有论文/强实习，不要硬冲**——从工程岗入行更稳，算法可以后置

## 五、常见坑

- 简历写"精通 C++" → 被问到第三层就挂了——**写"熟练"保平安**
- 项目答辩时把团队的活说成自己的 → 一问细节穿帮
- 没有项目就硬编 → **课程设计认真做=最好的项目素材**（详见 `04`）
- 只刷题不理解 → 面试官换个问法就露馅

## 六、给"零项目"同学的三条路

1. 把做过的**课程大作业**按项目标准重做一遍（补文档+放到 GitHub）
2. **跟一个开源项目**（哪怕修文档/改小 bug——真实协作经历）
3. **自己造一个**（解决自己一个实际需求的小工具——完整做完，比大而空强）

## 七、备考路线（校招实操）

**三层递进的考察**（想清楚每层是干嘛的）：
1. **算法题 = 入场券**：笔试和一面硬门槛——过笔试至少刷 150 题，稳妥 200-300，
   投算法岗 400+（刷题平台按专题刷，不刷量刷"题型"）
2. **工程能力 = 胜负手**：面试大头在"深挖项目"——架构、踩坑、线上问题怎么查——
   **很多人挂在"项目讲得支支吾吾"**（对照 `12-行为面试` 的素材库练）
3. **系统设计 = 拉开差距**：大厂终面常考"设计一个短链/秒杀系统"——校招要求不高，
   但要**有意识、能说出思路**

**三维投入参考**：算法 40% / 技术栈 35% / 项目 25%。

**项目的优先级**：实习项目 > 开源项目 > 个人项目。
硬指标：代码 1000 行以上、能跑起来、有文档；**避开烂大街题目**
（"电商仿站"人人在写）——做一个你自己真的在用的小东西，最加分。

**简历按方向换脸**（同一批经历，投不同岗重排）：针对性简历的面试率明显高于"一份投所有"——
用 `06` 和 `26` 的方法对齐每个岗位的 JD。

## 八、两个趋势信号（2026 观察，以最新为准）

1. **"AI 不是岗位，是技能"**——2026 的技术岗 JD 里"有 AI 应用/大模型经验者优先"
   越来越普遍——**去用 AI 做点真东西放进项目里**，是最省力的差异化
2. **选方向要务实**——后端/前端的岗位量仍是主力；盲目追风口转方向，
   不如在手的方向里扎深——**风会变，深度不变**
