# 简历速成工作流（从零到能投，约 20 分钟）

**触发**：用户说"帮我做/写一份简历""我的简历怎么弄""帮我改简历"——直接启动本流程，
不要只讲方法。目标：**十几分钟后，用户手里有一份能直接打印投递的成品。**

配合资料：结构对照 `01`，表达对照 `02`，定制对照 `06`，质检对照 `07`。

## 第一幕·访谈（约 10 分钟，一次问一组）

不问卷轰炸，**一次问一组、问完给个短反馈再往下**（有节奏感，像聊天不像审讯）。
边问边把信息记进档案。

- **第 1 组**：怎么称呼？电话和邮箱？想投什么岗位（或什么方向）？
- **第 2 组**：学校、专业、学历、起止时间？成绩（GPA/排名）怎么样——好就写，不好就跳过。
- **第 3 组**（重点）：做过哪些事——**实习、项目、课程大作业、社团、比赛、兼职都算**，
  挑记得最清的几件说。
  **每段追问三件事**：①你具体负责什么 ②怎么做的（用了什么方法/工具）
  ③结果——**挖数字**："做了多久？多少篇 / 多少人 / 多少播放？有没有从多少到多少的变化？"
  （用户说"记不清"，给区间也行："大概几十？一百多？"）

  **素材挖掘提问库（用户说"想不起来"时，照着问——至少问到他回忆起 3 件）**：

  - **学业类**：帮老师做过什么？课程大作业里你负责哪块？有没有拿过高分的作业？
    毕业设计做的是什么？
  - **组织类**：社团/学生会干过什么？办过什么活动？管过多少人/多少钱？班委做过什么？
  - **比赛类**：参加过什么比赛（专业的/通识的：数学建模/英语演讲/短视频/创业赛）？
    拿到什么名次？
  - **赚钱类**：兼职/家教/接单做过什么？带过几个学生？成绩涨了多少？
  - **作品类**：运营过什么账号（自己的也算）？写过什么发出来的东西？
    做过什么小工具/小设计？
  - **数字追问（万用六连）**：多久一次？一共几次？多少人参与？多少钱？多少篇/条？
    从多少到多少？

  问的节奏：一类一类过，用户说"没有"就换一类——**总有一类能挖出东西**；
  挖到就说"这个能写！"——给正反馈，用户会想起更多。

- **第 4 组**：技能（写到能验证的程度）、语言成绩、证书。

访谈结束时说一句定位的话（"你这两段经历能写出四条硬货，够撑一页"）——
用户需要知道自己手上有什么牌。

## 第二幕·生成初稿（约 5 分钟）

- 按 `16-可填骨架` 的结构生成完整初稿
- 表达规范：动词开头、量化、一行一个结果（对照 `02`）
- 朝向目标岗位：最相关的经历放前面，关键词对齐（对照 `06`）
- **真实性铁律**：只用访谈里用户给的信息——**数字不许发明**；
  某段经历确实没有数字，就如实写（如实的小事胜过虚构的大事）

## 第三幕·出成品（约 5 分钟）

**先选模板**（问用户，或按去向自动推荐）：

| 模板 | 适合谁 |
|------|--------|
| `templates/01-极简通用版.html` | 大多数岗位（互联网/通用）——默认 |
| `templates/02-稳重版（国企事业单位向）.html` | 国企、事业单位、公务员、银行（含照片位、政治面貌位） |
| `templates/03-英文版（外企向）.html` | 外企、对英语有要求的岗位 |
| `templates/04-创意版（设计传媒新媒体向）.html` | 设计、传媒、新媒体（克制的个性设计） |
| `templates/05-技术岗版.html` | 计算机、工程类（项目前置 + 技术栈区） |
| `templates/06-教师教育岗版.html` | 师范、教培（资质证书前置） |
| `templates/07-实习申请版.html` | 低年级找实习（放大校园实践与潜力） |
| `templates/08-学术复试版.html` | 考研复试、申研（科研经历前置） |

模板全部免费、纯 HTML，没有任何付费墙。把定稿内容装进选好的模板，然后告诉用户：

> 把下面的内容存成 `简历.html`，双击用浏览器打开 → 按 Ctrl/Cmd+P →
> 选"另存为 PDF" → 得到一份可以直接投递的简历 PDF。

**环境差异处理**：
- 能写文件的环境：直接生成 `简历.html` 文件（模板目录：`references/job/templates/`）
- 不能写文件的环境（纯对话）：把完整的 HTML 代码给用户，教他存成文件打开；
  如果用户操作不了，退化为"纯文本成品 + 一句话排版说明"

## 交付时的三句质检

生成后自动过一遍 `07-自查清单`，并附三句话：
1. 哪个数字需要你确认一下（不确认的数字别投出去）
2. 哪句最可能被面试追问（提前想好怎么答）
3. 投出去前用手机打开看一眼（HR 手机初筛）

## 验收标准（做完自查）

- [ ] 一页（打印预览确认）
- [ ] 每段经历都有数字或如实结果
- [ ] 用户能讲出简历上每一句的细节（讲不出的句子删掉）
- [ ] 已生成 PDF 或已教会用户生成 PDF
- [ ] 手机上打开不费劲
