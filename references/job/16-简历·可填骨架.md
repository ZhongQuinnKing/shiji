# 简历·可填骨架

这是"最后一公里"：照着填，就是一份结构正确的简历。配合 `01-结构与版面` 用；
填完对照 `17-正例逐条点评` 再校一遍手感。

## 使用方法

1. 复制骨架到备忘录/文档
2. 按【】提示填（每栏都给了填写示例，照样子仿写）；填不出的先留空，别硬编
3. 填完对照 `07-自查清单` 过一遍
4. 排版的落地方式（选一种）：
   - **贴进 Word/WPS**：粘贴选"只保留文本"→ 全篇统一字体、标题加粗、
     行距 1.2、页边距"适中"——十分钟排完
   - **在线工具**（超级简历类）：选"单栏极简"模板逐块填
   - **让 AI 转 HTML**（给现成提示词，直接复制）：

> 把这份简历内容生成成单栏一页的 HTML：A4 尺寸、打印友好（@page A4）、
> 中文字体用系统字体栈（PingFang/微软雅黑）、姓名居中大字号、
> 模块标题带下细线、正文 14px、行距 1.5。样式内联，输出完整 HTML 文件。
> （也可以直接用本技能 `templates/` 里的模板套）

## 每栏填写示例（照着仿写——新）

## 填写的纪律

1. 每个【】都要"能验证"（数字经得起追问，头衔是真的）
2. **填不满的处理**：不是拉行距硬撑——**把已有的写细**（项目多写一层做法、
   课程挑相关的列出、技能写具体）——**写细 ≠ 注水，注水一眼假**
3. **塞不下的删除顺序（照着删）**：与岗位无关的 → 年代久远的（高中及以前）→
   同类里最弱的 → 形容词与套话 → 次要证书 → 过渡句
4. 塞不下永远是"删内容"，不是"缩字号、挤边距"（`01` 的版面雷区）
5. 一骨架多用途：按方向存 2-3 份，微调五处（`06`）
