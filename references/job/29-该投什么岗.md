# 该投什么岗（求职定位）

投递之前先想清楚：**"我能干什么 × 市场要什么 × 我要什么"——三圈的交集**。
这一篇把三个圈逐个落地成可操作的步骤，最后给交集法与定位案例。

## 一、第一圈：我能干什么（30 分钟做完）

**能力盘点**：用 `04` 的素材挖掘法列全部经历/技能/证书——列完看"**证据集中的
方向**"（三件事都跟数据有关 → 数据类岗位有天然优势；都跟人打交道 → 销售/HR/运营方向）。

**偏好盘点**（两问定倾向）：

- 跟**人**打交道多，还是跟**数据/东西**多？（销售/运营/HR vs 研发/财务/设计）
- 坐得住钻得深，还是跑得动变化快？（研究/技术 vs 商务/项目）

**答法纪律**：凭"**你做过的事里哪件最不累**"来答——不凭想象（"我应该喜欢分析"
往往是你没做过分析）、不凭专业（专业只证明你学过，不证明你适合）、
不凭别人说（"你性格适合当老师"是别人的投射）。

## 二、第二圈：市场要什么（岗位世界）

**"专业→岗位"不是一对一**——一个大类专业通常通向十几类岗。先看几个示例：

| 专业大类 | 常见通向 |
|----------|----------|
| 计算机 | 开发 / 测试 / 产品 / 运营 / 数据 / 售前 / 技术支持 |
| 汉语言 | 文案 / 编辑 / 新媒体 / 行政 / 教师 / 策划 / 出版 |
| 会计财管 | 会计 / 审计 / 税务 / 财务分析 / 银行 / 券商后台 |
| 机械 | 设计 / 工艺 / 质量 / 设备 / 销售工程师 / 采购 |
| 新闻传播 | 记者 / 编辑 / 公关 / 广告 / 新媒体运营 / 品牌 |
| 生物 | 研发助理 / 质检 / 医药代表 / 注册 / 临床协调 |

（你的专业没在上面？用下面的"三步列法"，十分钟能列出来。）

**三步列法**：

1. 打开招聘平台，搜你的专业名 → 看"相关岗位"推荐
2. 每个感兴趣的方向，**用 `26` 的 JD 法看三个真实 JD**——看它的"日常"（职责动词）
   而不是 title
3. 找一个**在岗的人**聊 15 分钟——"你一天在干嘛"比任何攻略都真实

**约在岗人的话术**（学长姐/社群）：

> "学长好，我是 X 学校 X 专业的，正在看 XX 方向的岗位。想请教您 15 分钟：
> 主要是想听听真实的工作日常——您方便的时候我随时可以。"
> （说清"我是谁+问什么+占多久"，通过率比"能聊聊吗"高得多）

**该问的 5 个问题**（比"这工作好不好"有用一百倍）：

1. 您典型的一天是怎么过的？（听具体动作）
2. 这行最需要的能力是什么？最劝退的点是什么？（听两面）
3. 新人前半年通常卡在哪？
4. 这行的人后来都去哪了？（听通道）
5. 如果让您给三年前的自已一个建议，是什么？

## 三、第三圈：我要什么

- 行业方向（→ `24` 单位类型导览）
- 城市（→ `33` 的五笔账）
- 生活方式（节奏/加班/稳定 vs 成长——**诚实地排序**：把这三样排个先后，
  排完你会发现自己纠结的其实是"既要又要"）

## 四、交集与梯度（怎么定下来）

- **主投方向 1-2 个 + 相邻方向 1-2 个**——同一批能力能覆盖的相邻岗
  （"运营"和"文案"共享一半素材）——**一岗多投不是海投**
- **梯度**：同一方向里按"够得着"排冲/稳/保（同 `10`）——不需要唯一的
  "正确答案"，有"方向 + 梯度"就能开投
- **用投递校准方向**：先投 20-30 份（2-4 周），看反馈（哪类岗回你、哪类不回）——
  **反馈也是情报**；投递第一个月本来就是校准期，别指望一次想准

## 五、案例：一个汉语言学生的定位实录

【情境】小周四下，成绩中游，实习只有一段校媒经历，家长让考编，
自己想做"新媒体"，又觉得自己"啥都不会"。

【盘点的过程】

1. 列素材：校媒写了 40 篇稿（10 篇 10w+）、做了半年公众号排版、
   帮社团拉过两笔赞助——**证据集中在"内容 + 轻度商务"**
2. 列市场：搜"汉语言 岗位"→ 文案/编辑/新媒体/行政/教师/策划；
   看三个新媒体 JD：核心是"选题+写作+数据复盘"
3. 问自己：写稿不累、拉赞助也能干、坐办公室整理档案最煎熬——
   **排除行政/档案方向**
4. 定位落地：主投"新媒体内容"（校媒作品直接当作品集）+
   相邻"文案策划"；梯度：互联网公司内容岗（冲）/ 品牌方新媒体（稳）/
   文化传媒公司（保）

【拆解】她不是"想清楚了才行动"，是**盘点+搜市场+小步验证**把方向逼出来的。
你也可以：**这三步本身就是"想清楚"的过程，不是它的前提。**

## 六、三个常见误区

1. **追热门忽略匹配**：全员转产品/算法——你的证据对不上，投一百份也白投
2. **自我设限**："我专业只能投 XX"——同一专业通向的岗位面通常宽得多（见上表）
3. **只看 title 不看日常**：两个都叫"运营"，一个天天写文案一个天天跑供应链——
   **看清 JD 里的日子，再决定投不投**

（定位定了，下一步就是 `01` 起——简历按定位落笔。）
