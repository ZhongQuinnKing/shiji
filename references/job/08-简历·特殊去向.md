# 简历·特殊去向

不同去向，简历的规矩不一样。投之前先搞清对方要什么。

## 一、国企 / 央企 / 公务员 / 事业单位

- **优先用对方的模板**：很多单位有固定简历表（官网下载），必须用他们的，
  自己设计的反而扣分
- 格式：结构工整、要素齐全（政治面貌、籍贯、家庭情况……他们要的都给）
- 排位变化：**党员身份、学生干部经历、获奖、证书**的重要性上升；
  写全称号（"2024 年度校级一等奖学金"）
- 照片：正装证件照，别用生活照
- 少用花哨的语言：朴实、规范、多写事实
- 盖章件：有的单位要求成绩单/证书复印件盖章——提前办好

## 二、教师 / 教育机构

- **教师资格证、普通话等级**放最显眼位置
- 师范生写清：师范专业、教育实习经历（学校、带班、课时）
- 非师范生：突出教学相关经历（家教、支教、机构兼职）+ 证书
- 笔试面试常考：试讲——简历里能体现"站过讲台"的都往前放

## 三、外企 / 对英语有要求的岗位

英文简历（Resume，应届一页）：

- 句式习惯：**过去式动词开头**（Led / Built / Analyzed / Coordinated），
  不用 "responsible for"（老气，且是"职责"不是"成就"）
- 量化同样是灵魂：数字全世界 HR 都吃
- 时态统一：过去的经历全用过去式
- 大小写：标题规范（Experience / Education / Skills）
- 邮箱别用 QQ 数字邮箱（不专业感），语言成绩写清（IELTS 7.0 之类）
- 中文版和英文版**内容要一致**（面试官两个都看，对不上就尴尬）

## 四、银行类

- 证件照、身高（有的表格要）、稳重的措辞
- 强调：细心、抗压、合规意识（相关的实习/活动往这靠）
- 银行的网申表格长且严：提前把材料备齐（成绩单、证书扫描件）

## 五、一个通用提醒

特殊去向的共同规律：**对方要什么，你给什么，别给他不需要的**。
先花十分钟研究这个单位的招聘公告和往年风格，比闷头改简历有用得多。
