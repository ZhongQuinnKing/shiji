# 简历·特殊去向

不同去向，简历的规矩不一样。这一篇按"先选对模板 → 再按去向调内容 → 盯住各自的时间线"走。

## 〇、先对模板（八套模板去向对照）

| 去向 | 用哪套模板 | 一眼差异 |
|------|-----------|----------|
| 国企 / 事业 / 公务员 | `templates/02-稳重版` | 公文风、照片位、政治面貌 |
| 互联网 / 通用 | `templates/01-极简通用` | 默认标准 |
| 外企 / 英语岗 | `templates/03-英文版` | 全英文、过去式、无照片 |
| 设计 / 传媒 / 新媒体 | `templates/04-创意版` | 克制的个性 |
| 技术 / 工程 | `templates/05-技术岗版` | 项目前置、技术栈区 |
| 教师 / 教培 | `templates/06-教师教育岗版` | 资质证书前置 |
| 低年级找实习 | `templates/07-实习申请版` | 校园实践放大 |
| 考研复试 / 申研 | `templates/08-学术复试版` | 科研经历前置 |

## 一、国企 / 央企 / 公务员 / 事业单位

- **对方的模板优先**：很多单位有固定简历表（官网下载）——**必须用他们的**，
  自己设计的反而扣分
- 要素给全：政治面貌、籍贯、家庭情况……他们要什么给什么
- 排位变化：**党员身份、学生干部经历、获奖、证书**重要性上升——写全称号
  （"2024 年度校级一等奖学金"）；级别如实
- 照片：正装证件照；语言：朴实规范，少形容词
- 盖章件（成绩单/证书复印件）：提前办好
- **选调生专区**（公务员里的特殊通道）：门槛=名校+党员+学生干部（各省政策差异大，
  盯目标省份的公告）；渠道在各省组织部/人事考试网
- 时间线：**国企秋招启动早**（9-10 月是黄金期）——提前备好材料

## 二、教师 / 教育机构

- **教师资格证、普通话等级**放最显眼位置
- 师范生：写清师范专业 + 教育实习（学校、带班、课时）
- 非师范生：教学相关经历（家教、支教、机构兼职）+ 证书
- 简历里能体现"站过讲台"的都往前放（后面考编的**试讲**是命门——展开见 `23`）
- 时间线：教招各地不同、**春招岗位更多**——盯目标城市教育局/人事考试网

## 三、外企 / 对英语有要求的岗位

- 句式：**过去式动词开头**（Led / Built / Analyzed），不用 "responsible for"
- 量化全世界 HR 都吃；时态统一；标题规范（Experience / Education / Skills）
- 邮箱别用纯数字 QQ 箱；语言成绩写清（IELTS 7.0）
- 中文版与英文版**内容一致**（面试官两个都看）
（写法细则见 `20-简历·英文写作手册`）

## 四、银行类

- 证件照、身高（有的表格要）、稳重措辞
- 强调细心、抗压、合规意识（相关的实习/活动往这靠）
- 网申表格长且严：材料提前备齐（成绩单、证书扫描件）
- 时间线：银行秋招早（9-10 月），**网申关键词要按 `05` 的对齐法做**（机器筛）
（流程与面试展开见 `22`）

## 五、社招 / 跨行（边界提示）

- 有工作经验后：简历转向"**项目与业绩**"导向——删校园经历、加工作产出
- 跨行求职：把旧经历做"**可迁移化翻译**"（去掉行业 title，留下能力）
- 诚实边界：本技能聚焦应届与准应届；社招深水区建议结合行业内人的经验——
  需要时把具体情境拿来问，我们能帮的帮、帮不了的明说

## 六、各去向时间线总表（参考，以当年公告为准）

```
秋招（主力）：
  互联网 8-10 月 ｜ 国企 9-10 月 ｜ 银行 9-10 月 ｜ 外企 9-11 月
  教编/事业：各地自主，秋春两季都有
春招（补录+回血）：
  3-4 月集中 ｜ 教编春招岗位通常更多
特殊：
  考研出分后转求职——3 月全力投（见 10-求职策略）
```

## 七、通用提醒

共同规律：**对方要什么，你给什么，别给他不需要的**。
先花十分钟研究这个单位的招聘公告与往年风格，比闷头改十版简历有用。
