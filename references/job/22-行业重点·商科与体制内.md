# 行业重点 · 商科与体制内

（金融、会计、经济、管理，以及公务员、国企、事业单位方向。结构统一：看什么 / 写什么 / 考什么）

## 一、金融 / 咨询（商科的上层赛道）

**看什么**：**实习层级几乎是硬通货**（头部机构实习 > 普通实习 > 无）；
院校背景现实存在（部分机构有 target school 潜规则）；证书是加分项。

**写什么**：
- 实习：写"参与了什么项目、独立做了哪块、支撑了什么决策/产出"
- 证书：CPA（会计核心）/ CFA（金融）/ 从业资格——按进度如实写（"CPA 已过 2 门"）
- 数据敏感度：任何实习里"跟数字打交道"的证据都往前放

**考什么**：网申（简历关最狠）→ 笔试（行测+专业）→ 多轮面试（行为面+案例面）→ 实习转正制

## 二、会计 / 审计（最可复制的商科路径）

**看什么**：证书（初级会计→CPA）+ 事务所实习 + 细心。
**写什么**：CPA 进度、事务所/企业财务实习、Excel/财务软件能力（具体到函数和模块）。
**考什么**：事务所校招（四大/八大）：网测（数理逻辑）→ 面试（case+英语）→ offer；
节奏早（**大三上就开始**）；加班强度是行业真相，面试会问你的预期。

## 三、银行（稳定性赛道，流程最标准化）

**看什么**：院校 + 表达与形象 + 性格（笔试是门槛，**面试定生死**）。

**写什么**：金融课程/证书、活动组织经历（客户沟通潜力）、服务类兼职；
**网申关键词要对齐**（银行网申是机器筛+人工筛两道——填满实践经历模块、
用数据说话、关键词匹配岗位）。

**考什么（全流程）**：
1. **网申**：内容真实+重点突出+关键词匹配；投递别赶最后一天（系统卡）；
   照 `24` 的时间节奏走
2. **笔试**：行测 + 英语 + 综合知识（金融/经济/财会）+ 性格测试 + 部分行有本行特色题。
   备考法："**以考促练**"——多考几场真笔试 + 每场错题复盘（有考公基础的人上手快）
3. **无领导小组讨论**：核心是**找准角色**（不积极时抛框架、积极时做时间官）；
   熟悉行业热点搭语料库（普惠金融、科技金融、绿色金融）；**多人模拟+复盘**
4. **（半）结构化面试**：分步应答 + STAR；提前准备银行情景题（客户投诉、同事矛盾）
   与经济热点（"三农"、个人养老金）；**别照背模板**（考官一眼就看出背稿感）
5. 部分银行已引入 **AI 面试初筛**（见下"国企"段的说明——同一套应对）

**策略**：**秋招优先**（岗位多、竞争小于春招）；广泛投递 + **保底思维**
（先拿一个保底 offer）；四大行与股份制银行流程有差异——各投各的。

## 四、公务员 / 选调生（考试赛道，另一套规则）

**看什么**：**笔试成绩是决定性的**（行测+申论），简历权重低。
**写什么**（报名表）：党员/学生干部/获奖如实填——部分岗位是硬性条件。
**考什么**：国考（10 月报名/11-12 月笔试）；省考（多数 3 月笔试）；
选调生（名校+党员+学生干部，各省政策不同）。
备考是独立的一条线（提前半年+），报录比残酷——**想清楚再投**。

## 五、国企 / 央企（"稳定>适配>优秀"的筛选逻辑）

**看什么**：**核心筛选逻辑记住八个字——稳定性 > 适配性 > 优秀程度**。
面试官找的是"愿意留下来、能按规矩办事"的人，不是简历最花的人。

**写什么**：党员/学生干部/获奖/证书写全（正面项）；稳定型实习；
**专业不对口也可以投**（转正后靠适配，别自我淘汰）。

**考什么（全流程 + 时间节点）**：
1. **信息**：官网 + "国聘"平台 + 宣讲会——国企信息散在各家官网，**自己建信息表盯节点**
2. **时间**：秋招是主力（8-9 月启动，8-10 月网申高峰，10 月底-12 月笔面高峰）；
   春招 3-4 月补录。**注意：收到笔试/面试通知后可能只有 2-3 天准备期**——
   行测题感必须**提前练好**，不能等通知
3. **笔试**：行测是"基本盘"，**企业文化是"拉分项"**（熟记核心价值观与战略方向——
   能源类关注"双碳"、通信类懂"云网融合"）；技术岗加专业；部分考英语。
   严格限时练（资料分析每篇 ≤7 分钟）
4. **结构化面试**（五大高频题型 + 应对结构）：
   - 自我认知与岗位匹配（"为什么选我们"）→ **地域/业务绑定 + 经历 + 长期规划**
     （别只说"国企稳定"——那是最差的答案）
   - 计划组织协调 → 事前调研规划 / 事中执行协调 / 事后总结
   - 人际沟通（"领导安排不合理怎么办"）→ **服从优先**，用事实辅助，不直接要求领导调整
   - 应急应变 → STAR-R（多一个 R：反思）
   - 价值观/合规（"同事操作不合规怎么办"）→ 明确制度、协助解决、坚守底线
5. **2026 新趋势**：多家国企/银行把 **AI 面试**放进初筛（机器关）——
   考察自我介绍与职业规划，机器分析关键词、逻辑、语速**甚至微表情**。
   对策：**结论先行、全程看镜头、坚决不背稿**（背稿的语速和眼神藏不住）
6. **背调更严**：涉密/风控/资金岗必查——**简历一个字都不能注水**

## 六、事业单位（教师编 / 医院编 / 其他）

考试制为主：公告（各地人事考试网）→ 笔试（公共基础+专业）→ 面试（结构化/试讲/技能）。
**信息差是最大的坑**：各地公告时间/条件不同——**盯紧目标城市的人事考试网**（这也是
"行情调研法"的用武之地，见 `26`）。

## 七、这一赛道的通用提醒

- **时间线早**：商科头部实习从大二暑期就开始卷——早规划
- **证书按进度写**，别写成"已过"（背景调查会查到）
- **体制内的"稳定"是用"天花板换的"**——选之前问自己是不是真要这种生活，
  别只因为"爸妈觉得好"
