# 简历·自查清单（逐条过 + 每条怎么查）

清单人人有，**会用清单的人不多**。"数字够不够"人人会勾，"怎么查数字"才是分水岭。
自查的目的不是找安慰——**是在 HR 之前，先把能毙掉你的问题毙掉**。

## 〇、先学会"怎么自查"（三遍法）

自查最大的敌人是"自己看自己"的盲区——用流程对冲：

1. **第一遍·静音速读**：改错别字和明显问题（10 分钟）
2. **第二遍·隔一天再读**：放一晚——明天看今天的字，问题会自己跳出来
3. **第三遍·打印 + 朗读**：用红笔在纸上改（纸面阅读的发现率高一截）；**出声读一遍**——
   拗口的地方就是要改的地方

## 一、内容（每条附"怎么查"）

- [ ] 每段经历都有"结果"，不只写"职责"
  → **怎么查**：逐段问"这段能回答'做成了什么'吗？"——只能答"负责了 XX"就是不合格
- [ ] 全文数字够不够（每段至少一个）
  → **怎么查**：拿荧光笔把所有数字圈出来——**哪段一个圈都没有=红灯**；
    再顺一遍：这些数字是我"做出来的"还是"参与到的"
- [ ] 团队项目写清了"我负责什么"，没有通篇"我们"
  → **怎么查**：搜"我们"两个字——每出现一次问："这句换成'我'成立吗？"
- [ ] 最想看的内容在视线最先到的地方
  → **怎么查**：把简历倒过来只看标题和加粗——**第一眼看到的是不是你最强的那段**
- [ ] 内容与目标岗位相关（不相关的删或压）
  → **怎么查**：把 JD 铺在旁边，逐条问"这条对这个岗位有用吗？"——答不上就删
- [ ] 时间线连续、无空白疑点
  → **怎么查**：拉一条时间轴，看有没有说不清的"空窗"——有就准备一句解释
- [ ] **终极一问**：假装你是面试官，从简历上挑 3 个最想追问的点——
  **你能不能秒答？**答不上的那条，就是最该改的

## 一·补、关键词自查（ATS——大厂的第一道门，最容易漏的一条）

大厂/银行/国企的网申系统会**先机器筛一遍关键词**（ATS）——JD 里的技能词
在你简历里"找不到"，简历可能**根本到不了 HR 眼前**。

- [ ] **怎么查**：把目标 JD 里的技能词、工具词圈出来（10-15 个），逐个在你简历里
  **搜一遍**——真实会的：**用 JD 里一模一样的词**写出来（JD 说"数据分析"，
  你就别只写"会 Excel"）；不会的：**不硬塞**（塞进去的每个词面试都会被问）
- 多投几个岗位时：岗位换了，这一遍**重跑**（对照 `06-针对岗位定制` 和 `26-JD逆向法`）

## 二、真实（底线区）

- [ ] 每个数字经得起追问（"3200 怎么来的？"）
  → **怎么查**：把最"亮眼"的 3 个数字拿出来，**自己先回答一遍**追问（怎么算的/谁统计的/
    你的部分）；答不上——删掉或写实
- [ ] 没有编造的实习、项目、头衔
- [ ] 奖项级别如实（"国家级比赛的省级赛区"≠"国家级奖"——被问穿=信用破产）

## 三、版面

- [ ] 一页 / 一栏朴素排版 / 字体一种、字号两级、颜色≤两种
  → **怎么查**：全选看字体统计（有没有混入第二种字体）；缩到 50% 看层级还清不清
- [ ] 行距边距舒服
  → **怎么查**：打印一张——纸面上挤不挤一眼就知道
- [ ] 照片符合去向习惯（国企要、互联网不必——见 `08`）

## 四、细节（最冤的扣分区）

- [ ] 没有错别字 → **怎么查**：朗读一遍；再让一个朋友读一遍（别人的眼睛最灵）
- [ ] 标点统一（中文全角、英文半角）
  → **怎么查**：用查找功能搜半角逗号"，"和句号"."（混用的重灾区）
- [ ] 时间格式全篇统一 → **怎么查**：目视扫时间列——"2024.03"和"2024年3月"不能混
- [ ] 电话、邮箱核对 **两遍**（读出声核对）
- [ ] 技能栏没有"精通"（除非真经得起拷问——见下方翻车实例 2）

## 五、三个测试（详见 `01`）

- [ ] 打印测试 / 手机测试 / 十秒测试

## 六、翻车实录（都发生过）

1. **电话错一位**：某同学投了 50 家没回音，后来发现简历电话错一位——
   **不是没人要，是没人打得通**
2. **"精通 Excel"**：面试官追问"说下 VLOOKUP 多条件匹配"——当场卡壳，
   后面的面试氛围一起雪崩（技能栏每一行都是"请来考我"的邀请）
3. **通篇"我们"**：面试官问"那部分具体是你做的？"——支支吾吾说不清。
   **团队功劳写不出个人贡献=零信息**
4. **奖项注水**：写"国家级奖项"，实际是"国赛省赛区三等奖"——HR 一查档次
   直接出局（背调时代，注水=自杀）
5. **9 号字塞两页**：内容挺好，但 HR 第一反应"看着费眼"——**没被读完的简历
   等于没投**

## 七、按去向的自查侧重（差异化）

- **技术岗**：项目细节 + 技术栈的真实性（写了就要能被深问——`21`）
- **国企/体制**：证件照、政治面貌、获奖全称、材料盖章（`08`）
- **外企**：中英双版内容一致性；无照片、无生日（`20`）
- **创意岗**：**每个作品链接亲自点一遍**（死链=直接减分）

## 八、投出前的 5 分钟终检（固定流程）

```
1. 电话 / 邮箱：出声核对两遍
2. 所有链接：一个个点开（作品/GitHub/主页）
3. 文件命名：姓名-学校-岗位-简历.pdf
4. 格式确认：PDF 打开没乱版；大小正常
5. 投递正文：称呼、错别字、附件提到没有
```

**终检外挂**：让 AI 按这份清单再挑一遍（见 `18-简历·让AI帮你改`）——
它最擅长干"逐条找茬"这种活；**但它挑出来的每一条，自己过脑子再改**。
