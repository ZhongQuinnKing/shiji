# 简历·自查清单（投递前逐条过）

投出去之前，从头到尾过一遍。每一条都问自己："是"还是"否"——
否的条目，改完再投。

## 内容

- [ ] 每段经历都有"结果"，不只写了"职责"
- [ ] 全文的数字够不够（理想状态：连续三段经历里，每段至少一个数字）
- [ ] 每段经历都能回答："你具体做了什么、做成了什么样"
- [ ] 最想被看到的内容，在视线最先到的地方
- [ ] 所有内容与目标岗位相关（不相关的，删或压缩）
- [ ] 团队项目写清了"我负责什么"，没有通篇"我们"
- [ ] 时间线连续、无空白疑点（有空档，想好面试时的解释）

## 真实

- [ ] 每个数字都经得起追问（"这个 3200 是怎么算的？"——答得上吗）
- [ ] 没有编造的实习、项目、头衔
- [ ] 奖项级别如实（校级就是校级，没有夸大）

## 版面

- [ ] 一页（学生简历的硬标准）
- [ ] 一栏朴素排版（没有花哨模板、进度条）
- [ ] 字体一种、字号两级、颜色不超过两种
- [ ] 行距、边距舒服，不挤
- [ ] 照片符合去向习惯（国企要、互联网不必）

## 细节（最容易被扣分的地方）

- [ ] 没有错别字（打印出来逐字读一遍——屏幕上看不出错）
- [ ] 标点统一（中文全角、英文半角，不混）
- [ ] 时间格式统一（都用"2024.03"或都用"2024年3月"）
- [ ] 邮箱体面、电话正确（有人留错电话，机会直接飞了）
- [ ] 技能栏没有"精通"（除非真经得起拷问）

## 投出前的三个测试（见 `01-简历·结构与版面`）

- [ ] 打印测试：缩到 50% 还能看清重点
- [ ] 手机测试：手机上不费劲
- [ ] 十秒测试：朋友看 10 秒，能说出你现在最强的一点
