# 简历·字体与排版细节

简历的专业感，一半在内容，一半在"看不见的排版"。这一篇把字体和排版的"手感"讲透——
八套模板的设计逻辑也在这里。

## 一、中文字体的安全选项（每台电脑都有，不会缺字变样）

**黑体系（现代、清晰——大多数场景）**：

- 苹方 / 微软雅黑 / 思源黑体——屏幕阅读最舒服，互联网、外企、创意岗首选

**宋体系（传统、稳重——体制内场景）**：

- 宋体 / 思源宋体——印刷感强，国企、事业单位、学术简历首选

**混排（更高级的做法）**：标题用黑体、正文用宋体——或西文用西文字体、中文用中文字体
（模板的 font-family 已按这个原理排列：**西文字体放前面**，数字和英文就会用更雅致的西文字形渲染）

**千万别用**：艺术字、手写体、卡通字体、毛笔体——一个都不行。
（唯一的例外：创意岗的姓名可以用一个有个性的字体——也只限姓名一处。）

## 二、字号层级（黄金刻度）

| 元素 | 字号 | 备注 |
|------|------|------|
| 姓名 | 22-26px | 全篇最大，居中或左对齐 |
| 模块标题 | 14-15px | 加粗/加线条，与正文区分 |
| 正文 | 13-14.5px | 全篇统一 |
| 时间/次要信息 | 12.5-13px | 灰色，不抢主信息 |

**行距 1.4-1.55**：低于 1.3 挤，高于 1.6 散。
**全篇只用两种字号层级 + 一个灰度**——层级多了就是乱。

## 三、打印与屏幕的差异（投递前必调）

- 屏幕上刚好的一页，**打印出来常常是 1.1 页**（打印边距更大）
- 解决：把页边距设为"适中"（上下 2cm、左右 1.5-2cm 起），
  或把次要内容删一句——**永远是删内容，不是缩字号**
- 手机预览：现在很多 HR 手机初筛——**手机上看着不费劲**是底线

## 四、排版"手感"五条（专业与非专业的分界）

1. **对齐**：同级信息左对齐一条线；时间统一右对齐——不要一页里三种对法
2. **留白**：模块之间空一行，比"撑满"高级；一页没写满不是缺点
3. **一致性**：日期格式统一（"2024.03"就全篇"2024.03"）；标点统一（中文全角/英文半角）
4. **重点靠粗体，不靠颜色**：一页最多一个强调色（也只在标题线用）
5. **每一条经历的行数均等感**：两行的别配四行的——把四行的删到三行，或拆开

## 五、八套模板的字体逻辑（为什么这么设计）

| 模板 | 字体选择 | 逻辑 |
|------|----------|------|
| 01 极简通用 | 系统黑体栈 | 万能、屏幕最舒服 |
| 02 国企稳重 | 宋体系 | 印刷感 = 体制内审美 |
| 03 外企英文 | Georgia/Times 衬线 | 西式传统，外企熟悉的样子 |
| 04 创意岗 | 无衬线 + 一个强调色 | 克制地表达"有审美" |
| 05 技术岗 | 黑体 + 蓝灰标题线 | 工程师的"清爽理性" |
| 06 教师教育岗 | 黑体 + 青绿色 | 温和不呆板 |
| 07 实习申请版 | 黑体 + 蓝灰色 | 清爽学生气 |
| 08 学术复试版 | 宋体系 | 学术的严肃传统 |

**换模板换的是气质，不换的是纪律**——八套全都单栏、可被系统解析、打印即 PDF。
