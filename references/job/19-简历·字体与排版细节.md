# 简历·字体与排版细节

简历的专业感，一半在内容，一半在"看不见的排版"。这一篇把字体和排版的"手感"讲透——
八套模板的设计逻辑也在这里。（打印向的参数统一用 **pt**，与 `01` 的口径一致。）

## 一、中文字体的安全选项（每台电脑都有，不会缺字变样）

**黑体系（现代、清晰——大多数场景）**：苹方 / 微软雅黑 / 思源黑体——
屏幕阅读舒服，互联网、外企、创意岗首选。

**宋体系（传统、稳重——体制内场景）**：宋体 / 思源宋体——印刷感强，
国企、事业单位、学术简历首选。

**混排（更高级的做法）**：标题黑体、正文宋体；或西文用西文字体、中文用中文字体
（模板的 font-family 已按这个原理排列：**西文字体放前面**，数字和英文
会用更雅致的西文字形渲染）。

**千万别用**：艺术字、手写体、卡通字体、毛笔体——一个都不行。
（唯一例外：创意岗的"姓名"可以用一个有个性的字体——也只限姓名一处。）

## 二、字号层级（黄金刻度——与 `01` 统一口径）

| 元素 | 字号（打印向 pt） | 备注 |
|------|-------------------|------|
| 姓名 | 16-20pt | 全篇最大，居中或左对齐 |
| 模块标题 | 11-12pt（加粗） | 与正文区分靠粗细和线条 |
| 正文 | 10.5-12pt | 全篇统一 |
| 时间/次要信息 | 9-10pt | 灰色，不抢主信息 |

**行距 1.15-1.5**：低于 1.15 挤，高于 1.5 散。
**全篇只用两种字号层级 + 一个灰度**——层级多了就是乱。
（网页版模板里对应 px 值见 `templates/`，逻辑一致。）

## 三、打印与屏幕的差异（投递前必调）

- 屏幕上刚好一页，**打印常变成 1.1 页**（打印边距更大）——解决靠"删内容"，
  不是缩字号；页边距按"适中"（上下 2cm、左右 1.5-2cm 起）
- 手机预览：HR 手机初筛是常态——**手机上不费劲**是底线

**黑白打印测试（最狠的一测——新）**：把简历**黑白打印**一张——
如果去掉颜色后"重点全没了 / 整页灰蒙蒙"，说明你在靠颜色撑结构——
**好简历黑白打出来照样立得住**（这也是最接近 HR 打印场景的测试）。

## 四、排版"手感"五条（专业与非专业的分界）

1. **对齐**：同级信息左对齐一条线；时间统一右对齐——不要一页三种对法
2. **留白**：模块之间空一行，比"撑满"高级；一页没写满不是缺点
3. **一致性**：日期格式统一；标点统一（中文全角/英文半角）
4. **重点靠粗体不靠颜色**：一页最多一个强调色（也只在标题线用）
5. **经历条目行数均等感**：两行的别配四行的——把四行删到三行，或拆开

## 五、打印与投递的实操（新）

- 投递用 **PDF**（不用打印件）；现场投递（宣讲会/招聘会）才需要打印——
  用普通 A4 纸即可，**别用铜版纸**（显得用力过猛）
- 打印前把"留白小的页面"检查一遍：有些打印机会吃掉边缘 2-3mm
- PDF 过大（>1MB）压一下图片质量；**别为了压缩把文字变成图片**（ATS 读不出）

## 六、八套模板的字体逻辑（为什么这么设计）

| 模板 | 字体选择 | 逻辑 |
|------|----------|------|
| 01 极简通用 | 系统黑体栈 | 万能、屏幕最舒服 |
| 02 国企稳重 | 宋体系 | 印刷感 = 体制内审美 |
| 03 外企英文 | Georgia/Times 衬线 | 西式传统 |
| 04 创意岗 | 无衬线 + 一个强调色 | 克制地表达审美 |
| 05 技术岗 | 黑体 + 蓝灰标题线 | 清爽理性 |
| 06 教师教育岗 | 黑体 + 青绿色 | 温和不呆板 |
| 07 实习申请版 | 黑体 + 蓝灰色 | 清爽学生气 |
| 08 学术复试版 | 宋体系 | 学术的严肃传统 |

**换模板换的是气质，不换的是纪律**——八套全部单栏、可被系统解析、打印即 PDF。
