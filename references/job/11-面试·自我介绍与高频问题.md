# 面试·自我介绍与高频问题

面试的第一关都是自我介绍。这一篇讲：怎么讲好，以及高频问题背后的"考察点"。

## 一、自我介绍：准备两个版本

**公式：我是谁 + 最匹配的两点（带事实）+ 为什么来**

- **1 分钟版**（主用）：
  "面试官好，我是 XX，XX 大学 XX 专业。我最大的两块经历：一是 [实习/项目，一句话带数字]，
  二是 [另一段，一句话]。我投这个岗位是因为 [和岗位真实的关系]——
  [一句你对该岗位的理解]。这是我对自己的简单介绍。"
- **3 分钟版**（面试官说"详细讲讲"时用）：在中间展开两段经历的故事（用 STAR，见 `12`）

**三个雷**：

- 复述简历（"我 2021 年入学，2022 年……"）——他要听的不是时间线，是重点
- 空话（"我性格开朗、学习能力强"）——没事实的形容词都是噪音
- 背稿感——框架记牢，话要现场说，允许口语化

## 二、高频问题与"考察点"

**每个问题背后都有他想确认的东西**，回答是去回应那个东西，不是背标准答案：

| 问题 | 他真正想确认 |
|------|--------------|
| 你的优点 / 缺点？ | 自我认知是否真实（缺点要"真的缺点+正在改"，别说"我太完美主义"） |
| 为什么选我们公司/这个岗位？ | 你是否认真了解过（面试前查：公司业务/产品/近期动态） |
| 你的职业规划？ | 稳定性（3-5 年内的合理计划即可，别夸张，也别"我想创业"） |
| 期望薪资？ | 你的预期是否合理（先查同岗区间；学生可以答"更看重平台，薪资参考贵司标准"） |
| 你还面了哪些公司？ | 进度与倾向（如实说大方向，别报一长串） |
| 你还有什么问题？ | **必答项，且是加分题**——见下 |
| 能接受加班吗？ | 真实的工作强度（诚实了解，别违心打包票） |

## 三、"你还有什么问题"——用好的三个

- "这个岗位入职后前三个月，最希望我做到什么？"
- "团队目前最看重的能力是什么？"
- "您在这个团队多久了，最喜欢这里的什么？"（对面试官本人的真实好奇，拉近距离）

**别问**：薪资福利细节（留给 HR 面）、网上能查到的、暴露没做功课的。

## 四、准备方法（不是背，是练）

1. 把上表里的问题抄下来，每个写下你的**事实要点**（不是逐字稿）
2. 手机录像自答一遍——回放看：眼神、语速、有没有"嗯……那个……"
3. 找朋友/家人当面试官练一遍——真实的问答感，练三次就换一个人
4. 每次真实面试后 24 小时内复盘：被问住了什么、答坏了什么，补进题库
