# 简历·英文写作手册

投外企、英语岗位、海外申请用。核心：**英文简历是"成就清单"，不是"经历叙述"**。
配合 `templates/03-英文版（外企向）.html` 使用。

## 〇、先分清 Resume vs CV（别交错东西——新）

- **Resume**：求职用，1 页，成就清单——**投外企/英语岗交这个**
- **CV**：学术用，详细长版（含论文/会议/教学）——**申请研究生、学术岗才用**
（搞混 = 外企 HR 收到两页 CV 直摇头。）

## 一、中西简历的五个不同

1. **不放照片、生日、性别、籍贯**——欧美习惯里这些不该出现；
   中文简历的"政治面貌"直接**整行不写**（不做英译）
2. **不用自传式段落**——全部短句 + bullet points
3. **动词开头、过去式**——每条要点一个动词起头
4. **量化的胃口更大**——数字最有说服力；没数字就用规模/频率/效率
5. **一页（应届）**——和中文一致

## 二、结构词（固定搭配）

```
SUMMARY（可选，两三行）· EDUCATION · EXPERIENCE · PROJECTS · SKILLS
```

- EDUCATION：GPA 按 4.0 制标注（3.7/4.0, Top 12%）
- 时间：`Jul 2025 – Sep 2025`（月缩写在前）
- 大小写：**Title Case**（实词首字母大写：Data Analysis, Machine Learning）

## 三、动词表（Action Verbs——按能力分类）

**领导与组织**：Led · Managed · Coordinated · Organized · Initiated
**创建与执行**：Built · Developed · Designed · Launched · Implemented
**分析与研究**：Analyzed · Researched · Evaluated · Modeled · Tested
**优化与改进**：Improved · Optimized · Streamlined · Accelerated · Reduced
**沟通与支持**：Presented · Partnered · Supported · Trained · Documented

**句式**：`动词（过去式）+ 对象 + 方法/工具 + 结果`
> Led a 5-member team to organize 3 campus events with 800+ attendees;
> secured ¥5,000 in sponsorship.

## 四、中式英语的坑（扩展表）

| 别写 | 要写 |
|------|------|
| I am responsible for... | Led / Managed / Owned...（直接动词开头） |
| Participated in... | 换成实际动作：Analyzed / Drafted / Coordinated... |
| Learned / Studied... | 学习经历不算成就——写成果 |
| Have strong learning ability | 删掉——"Self-taught Python; built 3 tools" |
| Completed the task well | Be specific：within X days, with Y% improvement |
| **Skill: Python**（单复数混乱） | **Skills: Python, SQL**（Skills 复数、冒号后列表规范） |
| **Hobby: reading, music** | 弱——换成有故事的（Marathon runner (2,000 km since 2023)） |
| **computer science**（全小写） | **Computer Science**（专有名词大写） |
| 逐字直译中文简历结构 | 按英文习惯重组（见上"结构词"） |

## 五、时态与一致性

- 过去经历全用**过去式**（Led, Built）；现在仍做用**现在时**（Lead, Build）
- 全篇标点、大小写风格统一（Title Case 到底）

## 六、和中文版的关系

- 投外企：**两版都备**（面试官两个都看）——内容必须一致
- 英文版不是直译："统筹、对接、落实"翻成具体动词（Coordinated / Liaised / Executed）
- 用 AI 帮忙（正当用法）：中文要点给 AI——"翻成英文简历要点，动词开头、过去式、
  数字保留，一条一行"——翻完念一遍，读得顺才算能用

## 七、Cover Letter（英文求职信）与 LinkedIn（新）

**Cover Letter**（点名要时才写；半页）三段：
1. 谁 + 投什么岗 + 从哪看到
2. Why you：一个最硬的匹配证据（数字）+ 一句"为什么是这家"（显示做过功课）
3. 期待 + 感谢（附简历文件名）

**LinkedIn**：外企 HR 会搜你——①头像专业 ②标题=岗位词（Data Analyst | SQL/Python）
③把简历的成就线搬上去（英文）。**没 LinkedIn 不是扣分项，写歪了才是。**

## 八、交作业前的英文自检

1. 每条要点是动词开头？（不是→改）
2. 数字和规模露出来了吗？（没有→挖）
3. 让一个英语母语者读会皱眉吗？（会→重写那半句；有工具就借一个真人 eyes）
