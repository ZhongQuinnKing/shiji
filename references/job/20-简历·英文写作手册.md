# 简历·英文写作手册

投外企、英语岗位、海外申请用。核心：**英文简历是"成就清单"，不是"经历叙述"**。
配合 `templates/03-英文版（外企向）.html` 使用。

## 一、先记住中西简历的五个不同

1. **不放照片、不放生日、不放性别、不放籍贯**——欧美习惯里这些不该出现
2. **不用"个人自传"式段落**——全部短句 + 要点（bullet points）
3. **动词开头、过去式**——每一条要点都是一个动词起头
4. **量化的胃口更大**——数字最有说服力，没有数字就用规模、频率、效率
5. **一页（应届）**——和中文一致

## 二、结构词（固定搭配）

```
SUMMARY（可选，两三行）· EDUCATION · EXPERIENCE · PROJECTS · SKILLS
```

- EDUCATION 里 GPA 按 4.0 制换算标注（例：3.7/4.0, Top 12%）
- 时间格式：`Jul 2025 – Sep 2025`（月在前、缩写规范）
- 职位/公司大小写：Title Case（每个实词首字母大写）

## 三、动词表（Action Verbs——按能力分类）

**领导与组织**：Led · Managed · Coordinated · Organized · Initiated
**创建与执行**：Built · Developed · Designed · Launched · Implemented
**分析与研究**：Analyzed · Researched · Evaluated · Modeled · Tested
**优化与改进**：Improved · Optimized · Streamlined · Accelerated · Reduced
**沟通与支持**：Presented · Partnered · Supported · Trained · Documented

**句式模板**：`动词（过去式）+ 对象 + 方法/工具 + 结果`

> Led a 5-member team to organize 3 campus events with 800+ attendees;
> secured ¥5,000 in sponsorship.

## 四、中式英语的坑（逐条对照）

| 别写 | 要写 |
|------|------|
| I am responsible for... | Led / Managed / Owned...（直接动词开头） |
| Participated in... | 换成你实际做的事：Analyzed / Drafted / Coordinated... |
| Learned / Studied... | 学习经历不算成就——写成果 |
| Have strong learning ability | 删掉——用事实证明（"Self-taught Python; built 3 tools"） |
| Completed the task well | 多好？Be specific：within X days, with Y% improvement |

## 五、时态与一致性

- 过去经历：全用**过去式**（Led, Built）
- 现在仍在做：用**现在时**（Lead, Build）
- 同一份简历里不要混着来；全篇标点、大小写风格统一

## 六、和中文版的关系

- 投外企：**两版都备**（面试官两个都会看）——内容必须一致，别一个版本上有、另一个没有
- 英文版不是直译：中文的"统筹、对接、落实"要翻成具体动词（Coordinated / Liaised / Executed）
- 让 AI 帮忙时（正当用法）：把你的中文要点给 AI："翻成英文简历要点，动词开头、过去式、
  数字保留，一条一行"——翻完自己念一遍，读得顺才是能用

## 七、交作业前的三句英文自检

1. 每一条要点是不是以动词开头？（不是→改）
2. 数字和规模有没有露出来？（没有→挖）
3. 让一个英语母语者读，会不会皱眉？（会→删掉那半句重写）
