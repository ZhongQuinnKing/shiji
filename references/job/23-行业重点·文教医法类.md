# 行业重点 · 文教医法类

（师范教育、医疗、法学、传媒、艺术设计方向。结构统一：看什么 / 写什么 / 考什么）

## 一、师范 / 教育

**看什么**：教师资格证（硬门槛）+ 普通话等级 + **教学经历**（实习教学/支教/家教/机构）。
**写什么**：用 `templates/06-教师教育岗版.html`——资质证书前置、教学经历写"带过多少学生/
多少课时/什么结果"。

### 入编渠道（先搞清地图）

- **校招**：师范生的主场——竞争压力小于社招、节奏紧凑、部分岗位/人才引进**免笔试**；
  秋招春招都别错过，**跨区域报考**（别只盯一个城市）
- **社招/公招**：看各地教育局与人事考试网——信息差是最大的坑，自己盯紧
- **特岗/其他**：基层路径，政策每年调整，以当年公告为准

### 全流程与准备

1. **信息**：教育局官网 + 招聘公众号 + 高校就业平台——建一个自己的"信息数据库"
   （岗位表按城市/学段/学科归档）
2. **研读公告**：笔试考什么、面试什么形式、评分标准——**公告里都写着**，
   大多数人的失败从这里就开始了（没读透）
3. **笔试**：教育综合（网课+教材+刷题组合拳，别裸背）+ 学科知识（按目标地区题型精准准备，
   部分地区有高考题风格）+ 个别地区考行测
4. **面试**：结构化 + 试讲（见下）

### 试讲：命门中的命门

- **无生试讲（通常 8-10 分钟）**：熟读对应学段教材 → 设计完整教学环节
  （导入 → 新授 → 练习 → 小结）→ **提前备一篇逐字稿**（练熟后必须脱稿）
- **加分项**：互动设计（提问、小组活动）、**板书**（简洁、有视觉结构）、
  "教学评一体化"意识（设计评价学生的动作）——摸到新课标"自主、合作、探究"的边
- **分学科打磨**：语文=诵读感染力；数学=动手探究设计；英语=发音和教态表现力
- **练法**：找空教室/微格教室，**录像回看**——看自己的教态、语速、眼神
  （同 `14-模拟演练与复盘` 的录像法）；对空气讲十遍，比看攻略有用

### 结构化面试

按类别准备题库框架：自我认知 / 教育教学 / 应急应变 / 综合分析 / 师德师风 / 人际关系——
每题用"总分总"结构（亮观点 → 分条说 → 回扣小结），**录音打磨表达**，控制时间。

### 心态与实战

广撒网争取面试机会——**真考场是最好的训练场**，前几场当练兵。目标定了就专注，
不摇摆。（笔试备考 3-6 个月是常态，节奏早定早稳。）

## 二、医疗（长周期，提前想清楚）

**看什么**：学历层次（三甲门槛高）+ 实习医院 + 规培规划 + 科研（论文/课题）。
**写什么**：临床实习（科室轮转/参与诊疗的边界内表述）、科研经历、执医考试进度。
**考什么**：执业医师考试（分阶段）→ 规培（几年）→ 医院招聘考试（笔试+技能操作+面试）。
**关键决策点**：本科→规培 or 读研→专培——**和院校、科室、城市强绑定**，
大三就要开始调研（用 `26-行情调研法`）。

## 三、法学

**看什么**：**法考（法律职业资格考试）是硬门槛**——过了和没过的简历是两个世界；
+ 实习（律所/法院/检察院/公司法务）。
**写什么**：法考状态（已过/备考中）、实习经历（跟的什么案子/做的什么文书）、
专业方向（民商/刑事/知产……）。
**考什么**：
- 律所：笔试（文书写作）→ 面试（专业问答+稳定性）
- 法检：公务员考试通道（同体制内，`22`）
- 公司法务：面试为主，看专业+沟通
**现实提醒**：前几年收入可能低（实习律师期）——**是长线行业**，
选之前和家里对齐预期。

## 四、传媒 / 内容

**看什么**：**作品集 > 学历**（写过的稿/做过的视频/运营过的账号——直接甩链接和账号）。
**写什么**：作品列表（名称+你的角色+传播数据）、实习（媒体/大厂内容岗/自媒体）。
**考什么**：笔试（写作题）+ 面试（作品深挖+行业理解）。
**起步建议**：校园媒体/自己的账号——**现在就开始产出，就是最好的简历**。

## 五、艺术 / 设计

**看什么**：作品集是命（版式/项目逻辑/审美）。GPA 与院校重要性相对下降。
**写什么**：作品集链接放最显眼处；项目写"解决什么问题+你的设计决策+落地结果"。
**考什么**：笔试（极少）+ 面试（作品集答辩——每个作品都能讲出"为什么这么做"）。
**提醒**：作品集**宁精勿多**——5 个做透的作品，胜过 20 个敷衍的。

## 六、共性总结

1. **资质/证书是这些行业的第一道墙**（教资/执医/法考）——**早考**
2. **作品/实习是第二道墙**——用 `04`（没实习怎么办）的思路提前攒
3. **入行节奏各不相同**（医法长线、传媒作品先行、教育考试为主）——
   用 `26-行情调研法` 摸清你那一行的**真实时间表**，别用别人的节奏焦虑自己
