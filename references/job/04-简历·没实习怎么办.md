# 简历·没实习怎么办

这是学生最普遍的焦虑。先把话说透：

**简历写的是"你做成过什么"，不是"你在哪待过"。** 实习只是素材的一种——
没有它，不代表简历没得写；有它，也不代表自动加十分（打杂式实习写得烂，照样是废纸）。

## 第一步：盘素材（你比自己以为的有货）

拿张纸，把这五类全列出来，别筛选，先列：

1. **课程大作业 / 毕业设计**——几乎每门专业课都有，选做得最深的两三个
2. **比赛**——专业的、通识的（挑战杯、数学建模、英语演讲、短视频大赛……）
3. **自学项目 / 作品**——学过的东西总留了点痕迹：笔记、作品、小工具、账号
4. **校园活动**——社团、学生会、志愿活动、迎新、晚会
5. **兼职与家教**——家教也是"面向客户的交付"，能写

盘出来你会发现：能写的，比你以为的多。

## 第二步：把课程作业「变身」成项目经历

学生最容易忽略的金矿。变身公式：

**背景一句 + 我负责什么 + 方法和工具 + 结果（数字）**

例：
> "数据库课程设计（团队 4 人，我负责查询优化）：对 5 万条模拟订单数据设计索引方案，
> 查询耗时从 2.3 秒降到 0.4 秒，答辩获全班最高分"

全是真话，但读起来像一段正经项目经验。区别不在"编"，在于**你有没有把它当项目来写**。

## 第三步：自学项目的写法

- 技术岗：GitHub / 作品链接放技能栏或项目里——**代码和文档比你自述可信**
- 非技术岗：写作（公众号/知乎）、设计、视频、翻译练习……**放作品，不放形容词**
- 一句话原则：`"自学 + 产出物 + 可验证"`——"自学 Python 半年，完成爬虫小工具 3 个（附仓库）"

## 第四步：如果时间还够——攒一段真的

（很多人大三下才慌，其实还来得及）

- **远程实习**：不少小公司/创业团队接受短期远程，去招聘平台搜"远程实习"
- **校园里的"准实习"**：帮老师的课题做数据、给学院做公众号、给社团做视觉——
  没合同，但有真实产出，写得实事求是
- **比赛**：以赛代练，两个月能出一段像样的经历
- **开源 / 公益项目**：GitHub 上找标记 good-first-issue 的项目，
  或者参与公益组织的志愿项目——一段真实的协作经历

## 第五步：选对投递方向（扬长避短）

没有实习时：

- **避开**把"实习经历"写进硬性门槛的岗位（点名"需 X 段实习"的，别浪费感情）
- **主攻**看"潜力与作品"的通道：校招项目、暑期训练营、看笔试/项目能力的岗位
- 简历里，把**项目与作品区放大**，教育背景写扎实（GPA/课程/竞赛）——
  你的故事是"学生里最能打的"，不是"职场里最嫩的"

## 最后：一条不动的底线

**不编实习。** 编出来的经历活不过面试第一轮追问，而且性质是造假——
这不是技巧问题，是人品问题。真实素材写好了，比假实习更有说服力。
