## 逐条点评（对照学）

**"求职意向：新媒体运营"**
→ 顶部写目标岗位：HR 一眼确认"投对了"。而且整份简历朝向统一，没有第二个方向的噪音。

**"独立运营……粉丝从 0 增至 8600，最高单篇赞藏 1.2 万"**
→ 动词"独立"（敢于认领主导）+ 从 0 到 8600（增长数字）+ 单篇峰值（高光时刻）。
三个数字都是运营岗 HR 天生在找的东西。

**"建立选题库……爆文率从 8% 提到 22%，方法被团队沿用"**
→ 这条是"超越职责"型条目：不只做了活，还留下了方法。"被团队沿用"=你的价值被人接住了——
面试官看到这句一定会问，而问就是你的机会。

**"统筹选题会，协调 6 名编辑，68 篇，平均阅读量提升 40%"**
→ 校园经历写成了"有组织形态的成果"：人数、产出量、提升幅度。
对比反例："担任编辑，锻炼了团队协作能力"——零信息。

**"我负责数据与投放"**
→ 团队项目先标明"我负责什么"，后面整条都是"我"的视角。面试官不关心团队简历，只关心你。

**技能栏："Excel（透视表/函数，处理万行级数据）"**
→ 不是"熟练使用 Office"，而是具体到工具内能力+可验证的规模——一句话把"会用"变成"能用"。

**一个刻意的留白**：没有自我评价栏。
→ 当经历本身已经足够说话时，自我评价是多余的。**写不出事实型的自我评价，就该删掉整栏**。

## 这份简历为什么好用

1. 全篇**每一段都有数字**，且数字都长在岗位关心的点上（增长、内容量、效率）
2. 一条"超越职责"的亮点（方法被沿用），给了面试官一个必问的钩子
3. 版面单栏、无花哨——ATS 能读，HR 手机上看也清楚
4. 没有一句"我性格开朗"——所有的优点都是"做出来的"，不是"说出来的"

仿写时注意：**抄结构，别抄内容**——数字和经历必须是你自己的。虚构的数字经不起面试追问。
