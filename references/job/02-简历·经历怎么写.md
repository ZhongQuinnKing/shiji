# 简历·经历怎么写：量化表达

## 核心公式

一条好的经历 = **动词 + 做了什么 + 怎么做（方法/工具）+ 做成了什么（数字）**

- 反例："负责社团活动的组织工作"——看了等于没看
- 正例："策划并落地 3 场校园活动，累计参与 800+ 人次，拉取赞助 5000 元"

## "我没有数字！"——数字是算出来的，不是编的

从这些地方找：

- **规模**：多少人 / 多少场 / 多少篇 / 多少钱
- **时间**：持续多久、多久一次
- **增长**：从多少到多少（粉丝从 200 到 2000）
- **占比**：完成度、覆盖率、通过率
- **排名**：第几名、前百分之几
- **效率**：3 天做完了原计划一周的事

**课程作业也能算**："小组 5 人作业，我负责数据部分，处理 3000 条数据，
报告获班级最高分 92"——一句话里四个数字，全是真的。

## 改写练习：弱 → 强

| 弱 | 强 |
|----|----|
| 参与了校园公众号运营 | 独立运营校园公众号 4 个月，产出 15 篇原创，平均阅读量 600+，最高单篇 3200 |
| 协助老师做科研项目 | 参与国家级课题数据整理，清洗问卷 800 份，建立分析底表，支撑论文第三章 |
| 在 XX 公司实习 | 负责业务日报，用透视表把 2 小时的手工统计压到 15 分钟，方法被组内沿用 |
| 担任班委 | 管理班级 32 人的考勤与活动通知一学年，通知零遗漏 |

规律一句话：**把"我参与了一个事"，变成"我把一个事做成了什么样"。**

## 动词选择

- 主导 / 独立完成——只在真主导时用
- 策划 / 设计 / 搭建 / 优化 / 迭代
- 分析 / 调研 / 测算 / 验证
- 撰写 / 产出 / 编辑
- 组织 / 协调 / 对接 / 推动

两个慎用："负责"（虚，换成具体动作）、"参与"（弱，换成你实际做的事）。

## 学生版 STAR

STAR（情境-任务-行动-结果）是面试讲故事用的；简历上**只留 AR**——
行动（你怎么做的）+ 结果（做成什么样）。情境和任务，面试官感兴趣自然会问，
简历的空间留给"你做了什么、做成了什么"。

## 诚实边界（不可越）

- 数字可以**选好看的呈现**，不能编。夸大的数字经不起面试追问，而且是不诚信——
  一句追问就穿帮，比平庸更致命。
- 一段经历实在没亮点：**别硬写**，删掉，把空间让给更值得写的。
- "把小事写好"和"把没有的说成有"是两回事：真做过的，值得被好好表达；
  没做过的，一个字都不能出现。
