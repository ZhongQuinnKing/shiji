# 简历·经历怎么写：量化表达

## 核心公式

一条好的经历 = **动词 + 做了什么 + 怎么做（方法/工具）+ 做成了什么（数字）**

- 反例："负责社团活动的组织工作"——看了等于没看
- 正例："策划并落地 3 场校园活动，累计参与 800+ 人次，拉取赞助 5000 元"

## "我没有数字！"——数字是算出来的，不是编的

从六个地方找：**规模**（多少人/场/篇/钱）、**时间**（多久/频率）、
**增长**（从多少到多少）、**占比**（完成度/覆盖率）、**排名**（前百分之几）、
**效率**（3 天做完原计划一周的事）。

课程作业也能算："小组 5 人作业，我负责数据部分，处理 3000 条数据，
报告获班级最高分 92"——四个数字，全是真的。

## 从零改写实操（拿一段"水经历"从头改到尾——新）

**原始素材**（一个同学的口述）：
> "我在学生会干过，就是帮忙办活动，搬东西布置会场什么的，还管过我们部门的群。"

**第一步·挖**（按"数字六处"逐项问）：
- 办过几场？多大？（3 场，最大一场 800 人）
- 布置会场你具体管什么？（物料——每次对清单、对接 2 家供应商）
- 群是什么群？多少人的？你管什么？（干事群 40 人——发通知、收集报名、答疑）
- 有没有什么"结果"？（3 场活动的物料零缺漏；通知响应率从"刷屏催"到"一次发全"）

**第二步·组**（动词+做法+数字）：
> "学生会干事（活动执行）：3 场校园活动物料统筹（最大场次 800 人）——
> 对接 2 家供应商、逐项核对清单，三场物料零缺漏；负责 40 人干事群的通知与答疑，
> 优化信息模板后，重复追问减少大半。"

**规律**：素材里的"搬东西布置会场"是真的，"物料统筹+零缺漏"也是真的——
**同样的真事，写法决定它值不值钱**。

## 改写练习：弱 → 强

| 弱 | 强 |
|----|----|
| 参与了校园公众号运营 | 独立运营校园公众号 4 个月，产出 15 篇原创，平均阅读量 600+，最高单篇 3200 |
| 协助老师做科研项目 | 参与国家级课题数据整理，清洗问卷 800 份，建立分析底表，支撑论文第三章 |
| 在 XX 公司实习 | 负责业务日报，用透视表把 2 小时的手工统计压到 15 分钟，方法被组内沿用 |
| 担任班委 | 管理班级 32 人的考勤与活动通知一学年，通知零遗漏 |

**两个极端都要躲（新）**：
- **夸张到失真**："操盘千万级项目"（一问细节就崩，且是诚信问题）
- **保守到无味**："参与了相关活动的协助工作"（真话，但等于没写）
——**中间线**：每个动词、每个数字，回答得了面试追问，就叫到位。

## 动词选择（按能力分类——新）

| 能力纬度 | 动词 |
|----------|------|
| 领导组织 | 主导 / 统筹 / 组织 / 协调 / 推动 |
| 分析研究 | 分析 / 调研 / 测算 / 验证 / 复盘 |
| 创造产出 | 策划 / 设计 / 搭建 / 撰写 / 产出 |
| 优化执行 | 优化 / 迭代 / 提升 / 压缩（耗时）/ 对接 |

两个慎用："负责"（虚）、"参与"（弱）——换成你实际做的事。

## 行数标准（新）

- **最相关的一段**：2-4 行（写满）
- **次要的**：1-2 行
- **加分的边角**：一行式（"获校级一等奖学金（前 5%）"）
**行数就是你的重视程度信号**——面试官会顺着行数找重点。

## 学生版 STAR

简历上**只留 AR**（行动+结果）；S/T 留给面试里讲（见 `12`）。

## 自检三问（每条经历过一遍——新）

1. 有动词吗？（"负责/参与"开头=红灯）
2. 有数字吗？（一个都没有=黄灯）
3. **能答追问吗？**（面试官问"这个 3200 怎么来的"——秒答=绿灯）

## 诚实边界（不可越）

- 数字可以**选好看的呈现**，不能编——一句追问就穿帮，比平庸更致命
- 一段经历实在没亮点：**别硬写**，删掉，把空间让给更值得写的
- "把小事写好"和"把没有的说成有"是两回事：真做过的，值得被好好表达；
  没做过的，一个字都不能出现。（英文版写法见 `20`。）
