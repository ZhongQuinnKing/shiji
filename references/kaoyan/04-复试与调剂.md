# 考研·复试与调剂

## 一、复试考什么（先看细则）

各校复试细则（官网必读）通常包含四模块，**分值占比以细则为准**：

1. **专业课**（笔试/面试）：回归教材+学科主干框架——别在专业基础上出现记忆断层
2. **英语**：听力/口语（自我介绍、专业相关话题——准备高频问题+万能句式）
3. **综合素质**：导师提问为主——考察思维、诚实、科研潜力
4. **科研/实践经历**：有论文/项目/竞赛的讲得清清楚楚（没有就讲课程项目，
   `job/03` 的方法照样用）

## 二、准备动作（出分后立即启动）

- **自我介绍双版本**（1 分钟精简 + 3 分钟详细，**中英文都备**）——
  内容对齐"专业匹配度+科研潜力"
- **科研经历可视化**：有成果的准备 PPT/一页纸（真实、结构清晰）
- **了解导师**（见 `05`）：官网+知网读导师论文 1-2 篇——面试聊到"为什么选这个方向"
  时，有备而来和空话之间的差距是断崖式的
- **全真模拟**：找同学互当考官（同 `job/14` 的模拟法）——复试的紧张只能用模拟消化

## 三、面试问答与礼仪

- **答题结构**：紧扣问题 → 分层论述（第一/第二）→ 简短收尾；不懂的领域别硬接
- **遇到不会的问题**（高情商模板，照搬即可）：
  > "这个问题涉及我的知识盲区，我目前了解不深。我尝试用学过的 XX 理论
  > 从另一个角度分析一下，您看可以吗？"
  > 或："这个问题很有深度，我回去后会重点查阅 XX 方向的文献补足。
  > 我目前的理解是……"
  **核心=态度诚恳 + 展示思维过程 + 学习意愿**——切忌编造（导师一问就露）
- **礼仪**：着装整洁得体（商学院类偏正式，其他专业干净大方即可）；
  进门问好、坐姿端正、眼神环视各位老师（不只盯主考）；
  离场道谢——**细节分是白给的，别丢**
- **心态**：能进复试说明成绩过关——把姿态放在"交流"而不是"受审"

## 四、调剂（Plan B 的打法）

- **时间窗口**：初试出分→国家线→**调剂系统开放**（窗口很短，出分后就该准备
  B 校名单）——**别等复试被刷了才想调剂**
- **信息战**：意向校的缺额/往年调剂要求（关注研招网+目标校官网+调剂群）；
  准备"调剂版"简历与邮件（同 `05` 的方法，换对象即可）
- **心态**：调剂是"再选一次的主动权"，不是失败——
  学校层次可能降档，但"上岸"本身仍然兑现了考研的核心收益
- **纪律**：调剂系统操作看官方流程说明；一切"付费调剂保录"都是骗局

## 五、时间线总览（出分后）

```
出分 → 对线（过去年线）：
  ├─ 稳进复试 → 全力复试（+ 同步准备导师联系）
  ├─ 卡线     → 复试+调剂双线并行（两套准备）
  └─ 未过线   → 调剂系统+二战评估（`01` 的决策清单重过一遍）
```

**一句话**：复试是"信息 + 准备 + 真诚"的三重奏——
信息保你不犯蠢，准备保你不慌，真诚保你被记住。
