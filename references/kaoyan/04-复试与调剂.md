# 考研·复试与调剂

## 零、先读懂四个"线"（每年 3 月刷屏的就是它们）

- **国家线**：教育部划的总底线，分 A/B 区（B 区线更低——报 B 区院校或调剂到 B 区
  时用）——多数情况下，过线才有复试/调剂资格
- **34 所自划线**：部分高校自主划线，通常**先于国家线公布**——报了这些学校，
  盯它们的线
- **院校线/专业线**：学校（学院）在国家线基础上划的实际复试线——
  **你要查的是这个**（同 `02` 的提醒：校线常是摆设，看院线）
- **单科线**：总分过线但英语/政治**单科**不过线，照样进不了复试——
  偏科的人重点盯这一条

判断顺序：报自划线校 → 看自划线；其余 → 找院线，国家线兜底。

## 一、复试考什么（先看细则）

各校复试细则（官网必读）通常四模块，**分值占比以细则为准**：

1. **专业课**（笔试/面试）：回归教材+学科主干框架
2. **英语**：听力/口语——准备高频问题+万能句式（见第四节成品句）
3. **综合素质**：导师提问为主——考察思维、诚实、科研潜力
4. **科研/实践经历**：有成果的讲清（没有就讲课程项目，`job/03` 的方法照样用）

## 二、准备动作（出分后立即启动）

- **自我介绍双版本**（1 分钟精简 + 3 分钟详细，**中英文都备**）——
  内容对齐"专业匹配度+科研潜力"
- **科研经历可视化**：有成果的准备 PPT/一页纸（真实、结构清晰）
- **读导师论文**（见 `05`）：官网+知网读目标导师近两年论文 1-2 篇——
  被问"为什么选这个方向"时，有备而来和空话之间是断崖式差距
- **全真模拟**：找同学互当考官（同 `job/14` 的模拟法）——**复试的紧张
  只能用模拟消化**

## 三、复试现场还原（一问一答怎么走）

【情境】三分钟自我介绍刚讲完，主考翻着材料开口——

- **导师**："你本科做过什么研究？"
  - 弱："我本科学得比较基础，没有太多研究……"
  - 强："本科我做过两个课程项目：①X 项目，我负责了 Y 部分，
    结论是 Z；②毕业设计做的是 W。和您方向最相关的是 X 这个——
    它让我对 [方向] 产生了兴趣，也是我报考的理由之一。"
- **导师**："（专业课）说说 X 理论的适用条件？"
  - 会：分点作答（"三条件：第一……第二……第三……"），**答完停住**
    （别画蛇添足）
  - 不会：走第四节标准姿势
- **导师**："如果这次没录取，你打算怎么办？"
  - 弱："呃……没想过。"
  - 强："我会先复盘这次面试的不足。如果还有调剂机会就争取；
    没有的话，我会先工作积累，但不会放弃这个方向——我已经读了一些
    [方向] 的文献，会继续投入。"

**拆解**：复试问来问去就三件事——**你做过什么（真实）、你能不能做（潜力）、
你要不要来（动机）**。每个回答都往这三件事上靠。

## 四、不会的问题怎么办（标准姿势，背下来）

> 版本一："这个问题涉及我的知识盲区，我目前了解不深。我尝试用学过的
> XX 理论，从另一个角度分析一下，您看可以吗？"
>
> 版本二："这个问题很有深度，我回去后会重点查阅 XX 方向的文献补足。
> 我目前的理解是……"

**核心＝态度诚恳 + 展示思维过程 + 学习意愿**——切忌编造（导师一问就露）。

## 五、英语口语成品句（出分后就背）

- 自我介绍开场："Good morning, professors. It's my honor to be here..."
- 没听懂："Sorry, could you please repeat the question?" / "Do you mean…?"
- 临时卡壳缓冲："That's an interesting question. Let me think for a moment…"
- 结束："Thank you for your time. I would be glad to have the opportunity
  to study here."
（听力：把自我介绍和"为什么报这个学校/专业"的英文版练到脱口而出——
八成学校就考这些。）

## 六、调剂：Plan B 的打法（时间战）

- **提前准备**（出分后就做）：列出 5-10 所"可能有名额"的 B 校名单
  （往年有调剂名额的、层次合理的）——**别等复试被刷才想调剂**
- **系统开放那一刻**（调剂系统窗口很短，通常数天，好名额按小时消失）：
  - 提前把个人信息、志愿草稿备好；开放后**优先填最想的 2-3 个**
  - 志愿有锁定时间（锁定期间不能改）——**想清楚再填，别乱占位**
  - 同步打目标校研招办电话（礼貌、简短）："老师您好，我初试 X 分，
    报考 X 专业，请问贵校今年有调剂名额吗？需要什么条件？"
- **材料**：调剂版简历与邮件（同 `05` 的方法，换对象即可）
- **纪律**：一切"付费调剂保录"都是骗局；系统操作走官方说明

## 七、案例：擦线考生的 72 小时

【情境】小秦初试 352，报的 A 校去年线 350、前年线 358——擦边。出分数线
那天发现 A 校今年 355，**差 3 分，进不了复试**。

【72 小时操作】

- 第 1 天：启动备好的 B 校名单（8 所）；给 3 所打电话确认名额；
  备好调剂材料和自我介绍
- 第 2 天：系统开放后，按"最想去→保底"填 3 个志愿（避开锁定陷阱——
  第一志愿填把握最大的）；同步给 2 所目标校发了调剂邮件
- 第 3 天：收到 2 个复试通知，选其一；按 `05` 的方法连夜读了导师论文

【结果】一周后调剂复试通过，上岸 B 校——虽然降了档，但"考研的收益
（平台+方向）兑现了"。

【拆解】她的从容不是运气——**是出分第一周就把 B 校名单和材料备好了**。
调剂赢在"准备得早"，输在"等复试刷了才开始"。

## 八、时间线总览（出分后）

```
出分 → 对线（比往年数据）：
  ├─ 稳进复试 → 全力复试（+ 同步准备导师联系）
  ├─ 卡线     → 复试+调剂双线并行（两套准备）
  └─ 未过线   → 调剂系统+二战评估（`01` 的决策清单重过一遍）
```

**一句话**：复试是"信息 + 准备 + 真诚"的三重奏——信息保你不犯蠢，
准备保你不慌，真诚保你被记住。
