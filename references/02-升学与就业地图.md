# 升学与就业地图（全路径总览）

"本科毕业该干嘛"是最高频的问题——**考研、留学、就业、考公**四条路，
加上"读完之后去哪"的再分岔，构成一张全图。这篇是总览：
各路径差异一张表看全，再去对应专线深入。

## 一、本科毕业的四条路（速览）

| 路径 | 时间成本 | 金钱成本 | 主要难点 | 收益 | 适合谁 |
|------|----------|----------|----------|------|--------|
| 直接就业 | 0 | 0 | 校招竞争 | 早挣钱早积累 | 有方向/有实习/行业看能力 |
| 考研 | 备考 1 年＋读 2-3 年 | 低 | 竞争激烈 | 学历与平台跃迁 | 目标行业要硕士/想换出身 |
| 留学 | 申请 1 年＋读 1-4 年 | 高 | 申请与费用 | 学历＋视野＋语言 | 预算够/想出国经历 |
| 考公考编 | 备考 1 年内 | 低 | 竞争极烈 | 稳定 | 求稳且符合条件 |

（四条路可并行评估、别单押——同 `liuxue/09` 的"三线并行"纪律；
每条的决策方法：考研 → `kaoyan/01`；留学 → `liuxue/01`；就业 → `job/29`；
**考公考编 → `gongkao/00` 与 `gongkao/01`**。）

**四条路各自往下走**（这一章是总图，具体篇目都在各线）：

- 就业 → `job/` 全线；签约与手续看 `job/36`，专科与高职看 `job/37`
- 考研 → `kaoyan/` 全线；**推免（保研）另有一条独立时间线**（`kaoyan/07`），
  启动比考研早一年，别等大四才知道；专科起点还有专升本（`kaoyan/08`）
- 留学 → `liuxue/` 全线；低年级先做背景（`liuxue/10`）
- 考公考编 → `gongkao/` 全线；应届身份是**一次性红利**（`gongkao/00`），
  基层项目是"用时间换通道"不是换编制（`gongkao/06`）

**还有一条不在四条路里、但该单独看**：`tebie/` 特殊通道与少数处境——
入伍（`tebie/00`，含兵役登记这项法定义务）、残疾学生、港澳台侨、
预科与民族班、在职学历。这些不是"少数人的事"，是**信息差最大的一批**。

**起点在高三的话**：这一整张图的前一站是 `gaokao/`——选科定了能报什么专业，
志愿填错了前面十二年都白搭。先进校，再看这张图。

## 二、读完之后的岔路

- **硕士毕业**：就业 / 考公 / **读博**（→ `grad/05`）/ 再留学
- **博士毕业**：学术轨（高校/研究所）vs 产业轨（→ `job/31` 的博士双轨）
- **留学毕业**：留下 / 回国 / 继续读（→ `liuxue/09`；回国的执行 → `job/32`）

## 三、贯穿全图的四根轴（差异就藏在这）

1. **学历层次**（本/硕/博）：学习、生活、求职的逻辑各不同
   （→ `job/31`、`grad/01`、`liuxue/08` 的三档对照）
2. **国内 vs 国外**：体系、成本、回报不同——考研线 vs 留学线，
   交接带是 `job/32`（海归回国）
3. **学校层次与地域**：保研率、校招资源、城市红利存在客观分层
   （→ `job/31` 的出身打法、`job/33` 的城市算法）
4. **专业**：各专业大类有特有节点与节奏（→ `job/34`）

## 四、特殊通道与特殊群体（容易漏的角落）

- **专科 / 专升本**：专科考研走"**同等学力**"路径（毕业满两年，且**须加试两门本科主干课程**——这是规定动作不是可选项，
  以招生简章为准）；专升本是最常见通道——决策方法同 `kaoyan/01`
- **专项计划**（少数民族骨干、退役士兵等）：有独立规则与名额——
  **符合条件的人是红利，别因为"不懂规则"而浪费**；查教育部与目标校当年简章
- **公费师范 / 定向医学生等**：入学协议带履约约束（服务年限/定向地区）——
  毕业去向要在协议框架内规划，**入学时就把协议读明白**
- **在职考研 / 非全日制**：报考类别选"定向"（→ `kaoyan/06` 的报名实务）；
  适合一边工作一边提升
- **经济困难**：助学贷款、绿色通道、奖助学金是"**正经的钱**"——
  该用就用（→ `life/08` 的助学节）

## 五、怎么用这张图

- **"选哪条路"**：去对应线的决策篇（`kaoyan/01`、`liuxue/01`、`job/29`）
- **"进去了怎么走"**：去对应线的全程篇
- **跨线问题**（"考研还是留学"）：两边的决策篇都读，**用同一套账比较**
  （时间/金钱/难度/收益四列），别用印象比

## 六、三档阅读路线（第一次用怎么读）

- **第一档·救急**（今天就要办事）：只读"对应那条线的 00 或决策篇"——
  如明天报名就读 `kaoyan/06`，后天面试就读 `job/11`；**别通读，先过眼前这关**
- **第二档·理顺**（有一段缓冲期）：读"你所在阶段的全流程篇"——
  如大三读 `kaoyan/00` 或 `liuxue/00`，大四读 `thesis/00`；
  配一篇"理解层"（`life/00`/`workplace/00`/`job/35`）把"为什么"也补上
- **第三档·系统**（想真正变强）：按线从头读到尾 + `03-依据与参考体系`
  的书单延伸——这时你已经比大多数同龄人会查、会判、会做了

## 一句话

路是分岔的，账是通的。**用同一套算法比较不同的路，用提前量赢下每一个窗口**——
这张图帮你先看清全局，再走好脚下这一步。
