# 日常协作与沟通

职场里真正每天消耗你的，不是大任务，是这些"小事"：求人、拒绝、跨部门、群聊、邮件。
这一篇把它们一次说清。

## 一、求人办事的正确姿势

职场请求的四件套：**背景一句 + 具体请求 + 时间 + 给人退路**

- 反例："在吗？帮我看个东西。"（对方：什么？多大？急吗？）
- 正例："XX 你好，我在做 XX 项目（背景），有张表想请你帮我看下公式对不对，
  大概十分钟（具体+时长），明天上午前都行（时间），你这周忙的话我再想别的办法（退路）。"

**先给人方便**：能自己查的不问人；必须问的，把材料备齐再去——**别让人陪你做你的功课**。

## 二、拒绝的艺术：不是"不"，是"条件"

直接拒绝伤人，硬着头皮答应坑自己。标准公式：**肯定 + 现状 + 条件**

> "这个事挺重要的（肯定）。我手上正在赶 XX，这周实在排不开（现状）。
> 两个选择：要么下周一我给你做，要么你找 XX 先顶一下？（条件）"

要点：**给出替代**（时间/人/部分帮忙），拒绝就变成了"协商"。
另外：拒绝要**当面/私聊**，别在群里当众说——给人留面子，是给自己留余地。

## 三、跨部门沟通（难，但有公式）

跨部门的天然难点：**你不归我管，我凭什么帮你**。所以：

1. **先对齐利益**：说清"这对你们有什么好处"（帮这个忙能让他们少出什么错/多拿什么数据）
2. **找对人**：不一定是title最高的，是"实际经手的那个人"——先摸清楚
3. **留下书面**：跨部门的事，聊完补一条消息/邮件（"刚刚我们商定：……"）——
   口头的跨部门承诺，经常在几天后变成"我没说过"
4. **升级是最后手段**：直接搬领导压人=结仇。先沟通、再拉共同的上级同步，
   且说"需要您帮我们协调"而不是"他们不配合"

## 四、群聊与消息礼仪

- **@人之前想一秒**：这事需要全群知道吗？——大多私聊更合适
- **长文私聊、结论进群**：给群里的信息要短、要给别人省时间
- **别在群里公开指责**：哪怕对方有错——私聊说、当面说，群里只说事不说人
- **收到消息的处理闭环**："收到"→ 完成 → "已发你，见附件"——
  **有头有尾的人在职场像黄金一样稀缺**

## 五、邮件与正式沟通（用得少，但要会）

- **标题**：`[需回复] XX项目-报价确认-6月10日前`——一眼知道干嘛、什么时候
- **一件事一封邮件**：混着说的邮件没人回全
- **正文**：结论在前、要点编号、待办加粗（谁在什么时候做什么）
- **抄送规则**：抄相关的人，不抄无关的人（乱抄=没重点）

## 六、把"闭环"变成肌肉记忆

职场信誉的复利公式 = **事事有回音**：

1. 别人交代的事：**确认收到**（"收到，明天下午给您"）
2. 中途有变：**提前说**（不为难别人等）
3. 完成之后：**主动回复**（不用人催）

这三步做到位，你的"靠谱指数"会肉眼可见地涨——**靠谱，是普通人最硬的通行证**。

## 七、当你要"麻烦别人"很多次时

让帮忙可持续的方法：**回赠 + 公开致谢 + 记住偏好**
- 人家帮了你，找机会还（哪怕小：带杯咖啡/帮他对个小忙）
- 在合适的场合（领导面前/群里）感谢**具体的人+具体的事**
- 记住对方的习惯（有人喜欢上午处理请求，有人讨厌语音消息）——
  **被记住偏好的人，会愿意再帮你**
