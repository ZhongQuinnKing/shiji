# 考公·政审体检与录用

这一篇只交代流程：有哪几步、每步交什么、什么时候交、什么情况下会卡住。走完面试的人，最后栽在这些环节上的不少，原因大多不是条件不符，是材料没备齐、时间没赶上。

## 一、程序的顺序

按《公务员录用规定》，录用公务员按这个顺序进行：发布招考公告 → 报名与资格审查 → 考试 → 体检 → 考察 → 公示 → 审批或者备案。

面试结束到正式录用之间，考生要配合的是体检、考察、公示三段。各省各系统节奏不同，从面试成绩公布到拟录用公示，常见是一到两个月，也可能更长。**每一步的时间节点以招录机关的通知为准。**

## 二、考察（俗称政审）

**谁来做。** 招录机关组织考察组，由两人以上组成，采取个别谈话、实地走访、审核人事档案、查询社会信用记录、与本人面谈等方式。应届生的考察组一般去学校，社会人员的去原工作单位或户籍地。

**查什么。** 两块。一是**报考资格复审**，核实报名时填的信息和证件是否真实、准确、完整；二是**考察**，按当年公告列明的项目进行，涉及品行、能力、学习和工作表现、遵纪守法、廉洁自律、职位匹配度等方面。

**交什么。** 各地各系统清单不完全一样，常见的有这些：

| 材料 | 由谁出具 | 备注 |
|------|----------|------|
| 身份证、户口本 | 本人 | 原件核验、复印件留存 |
| 学历学位证书 | 本人 | 加学信网学历在线验证报告 |
| 现实表现证明 | 学校（应届）／单位（在职）／社区或街道（待业） | 一般要盖章 |
| 无犯罪记录证明 | 户籍所在地派出所 | 部分岗位还需直系亲属的 |
| 个人征信报告 | 本人查询打印 | 部分岗位要求 |
| 个人自传或总结 | 本人 | 部分单位有指定格式 |
| 劳动合同、社保记录 | 本人 | 有工作经历要求的岗位 |
| 单位同意报考证明 | 现工作单位 | 在职人员、部分定向岗位 |

毕业两年内没有工作单位的，现实表现材料一般由社区或街道出具，报名前可以先问清口径。

**档案。** 考察组审核人事档案。收到调档函后，档案通过机要或官方渠道转递，**不能自己拿着送，更不能自行拆封**——拆封的档案会变成无效状态。审核重点是完整性，比如出生年月、参加工作时间、学历学籍等信息的相互印证；发现缺失，按要求补齐即可。

档案有断档、毕业时档案落在自己手里、曾经更名或信息不一致的，建议在考察组进场前主动说明并备好证明材料。等查出来再解释，周期会拉长。

## 三、体检：标准、复检、时限

**依据两个标准。** 《公务员录用体检通用标准（试行）》适用于绝大多数职位；《公务员录用体检特殊标准（试行）》适用于对身体条件有特殊要求的职位，主要包括人民警察职位（公安、监狱戒毒机关）、司法警察职位，以及海事、检验检疫、安监等系统的相关职位。特殊标准没有规定的项目，仍按通用标准执行。

**两个标准的复检规则不一样，这条最关键：通用标准里的项目可以申请一次复检；特殊标准里的项目一律不进行复检。**

| 情形 | 适用项目 | 时限 |
|------|----------|------|
| 当日复检 | 心率、视力、听力、血压等 | 当天安排 |
| 当场复检 | 边缘性心脏杂音、病理性心电图、病理性杂音、频发早搏等 | 当场安排 |
| 申请复检 | 除上述之外的项目 | 接到体检结论通知之日起 **7 日内**提交书面申请 |

**几条硬规则：** 未在规定时间内提交书面复检申请的，视为自动放弃；复检只能进行一次，结果以复检结论为准；当日、当场复检只做一次，仍不达标的不再择日复检；不按要求完成全部体检项目的，视同自动放弃体检资格；体检不合格的，不得确定为考察人选。复检一般由实施机关安排到另一家医院。

## 四、公示与审批

体检、考察都过了之后，招录机关提出拟录用人员名单向社会公示，**公示期不少于五个工作日**。公示内容包括招录机关名称、拟录用职位、拟录用人员的姓名、性别、准考证号、毕业院校或工作单位，以及监督电话。

公示期满后三种处理：没有问题的，或反映的问题不影响录用的，办理审批或备案；反映有严重问题并查有实据的，不予录用；一时难以查实的，暂缓录用。

审批环节，中央机关及其直属机构的拟录用名单报中央公务员主管部门备案，地方招录机关的名单报省级或设区的市级公务员主管部门审批。审批通过后按通知报到，新录用公务员试用期一年，试用期满考核合格予以任职定级。

## 五、放弃的后果与诚信档案

不同环节放弃，后果差别很大：

| 环节 | 通常的处理 |
|------|-----------|
| 笔试弃考 | 一般不记入，不影响后续报考 |
| 资格复审前放弃 | 一般无影响，部分公告要求提前书面告知并提交放弃声明 |
| 面试确认后无故放弃、当天临时弃考 | 可能记入诚信档案库 |
| 拟录用名单公示后放弃 | 记录期限一般长于面试环节 |
| 录用后无故逾期不报到、试用期内放弃 | 记录期限一般最长，可达五年 |

具体记录期限各地各场次不同，常见的规定形态是这样的（举例，非统一标准）：资格复审、面试、体检、考察环节放弃但在规定时间内提供书面申请的记半年；同类情形累计两次的记一年；接到通知后未在规定时间内提供书面申请的记两年；公示后放弃的记三年；录用后无故不报到或试用期内放弃的记五年。

被记入诚信档案的，记录期内不得报考，档案全国联网，跨省也避不开。另外两类：**考试违纪违规**（抄袭、伪造证件、使用通讯设备等）通常五年内不得报考；**串通作弊、替考**为终身禁考。被机关或参照管理单位辞退未满五年的，不得列为拟录用人选。

想放弃的时候，正确做法是**先按规定提交书面放弃声明，再退出**，不要等到当天不去。

## 六、案例：一份材料的三个问题

【情境】小徐毕业两年，无工作单位，进入考察环节，收到通知后不知道现实表现证明该找谁开。

【对话】

> "老师您好，考察通知里写着要现实表现证明。我毕业两年了，没有工作单位，这份材料由谁出具？"
> "户口所在地的社区或者街道，要盖章。"
> "无犯罪记录证明是去派出所开吗？"
> "对，户籍所在地派出所。"
> "这两份有截止时间吗？"
> "考察组进场前一周交到我们这里，具体日期下一条通知里会写。"

【结果】他按这个清单三天办完，没有返工。【拆解】问材料只问三件事：**谁出具、要不要盖章、什么时候交到哪里。**

## 七、依据边界

全国口径：录用的程序顺序、考察组的组成与方法、公示期不少于五个工作日、体检的两个标准及复检规则、被辞退未满五年不得拟录，这些是全国统一规定。
各省各系统自定：考察材料的具体清单与出证单位、档案审核的细节要求、体检的集合方式与费用、诚信档案的记录期限。
文中的清单与时长按常见做法整理，**以你要报的那一场的体检公告、考察通知为准**。

## 一句话

最后这几关不考能力，考的是清单和日期：材料谁开、章盖没盖、七日之内提没提，办齐了就是办齐了。
