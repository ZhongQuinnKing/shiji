# 复习与考试

## 一、复习计划（倒排 + 配比）

- **倒排**：从考试日往前排——最后 2 周只留给"做题+错题+背诵"，
  新知识在考前 3 周内不再开新坑
- **每日节拍**：硬核科目（需要算/推的）放黄金时段；记忆型内容放碎片和睡前
- **配比**：复习时间 ≈ 新学时间（`02` 的 1:1 原则）——考前一个月全转复习

## 二、真题：最诚实的考官

- **当考试做**：掐表、闭卷、一次做完——**平时不模拟，考场必失控**
- **做完做三件事**（比做十套都有用）：
  1. **对答案标错因**（见下"错因分类"）
  2. **回归考点**：每题考的是书上哪一节？回去把那一节重学一遍
  3. **统计**：哪类题型失分最多 → 下阶段的复习重心
- 时间不够时：**做透三套 > 走马十套**

## 三、错题本系统（错因分类是关键）

别只抄错题——按**错因**分类管理：

| 错因 | 特征 | 治法 |
|------|------|------|
| **概念不清** | 完全不会/用错公式 | 回炉重学该概念（配 `02` 的默写） |
| **思路卡壳** | 知道考什么但没思路 | 积累"题型 → 突破口"的映射 |
| **粗心** | 会做但算错/看错 | 建立检查清单（单位/符号/条件），练"慢一点" |
| **时间不够** | 做不完 | 练节奏（先易后难、限时组题） |

**每周重做错题一遍**（遮住答案）——**错题第二次做对才算真会**。

## 四、考前节奏（七天版）

- **前 7 天**：做题保持手感 + 过薄笔记（不碰新题源）
- **前 3 天**：背记忆性内容（此时背诵的"保鲜期"正好覆盖考试）+ 看错题本
- **前 2 天**：完整过一遍各科框架（默写思维导图）；**确认考场信息**
  （地点/证件/文具/天气/路线）
- **前 1 天**：轻量复习（只看薄笔记）+ 正常作息（**不熬夜——睡眠是记忆的朋友**）
  + 准备好所有物品放包里
- **当天**：正常吃早饭；进考场前不看新东西（看框架图/错题即可）

## 五、考场技巧（每一条都救过分）

- **先易后难**：卡壳超 3 分钟的题标记跳过——**别在难题上烧掉简单题的时间**
- **时间分块**：开考先按分值分配时间（如每部分 X 分钟），过半程检查进度
- **审题慢半拍**：圈出"不正确/除外/至少"这类词——**冤枉分大多死在这**
- **检查法**：优先检查"标记过/不确定"的题；改答案要谨慎
  （除非确定错，**第一直觉的统计表现不差**）
- **一门考砸不回头**：出考场不对答案、不刷群——把精力留给下一科
  （弃考的人里，一半是被"对答案"击溃的）

## 六、心态的两个锚

1. **考试的真相**：考的不是"你会多少"，是"你在限时高压下能拿出多少"——
   所以**模拟的意义大于复习**（把"考试状态"提前练熟）
2. **一门≠全局**：单科失手后的最优策略是**立刻最大化剩余科目**，
   而不是复盘已经无法改变的分数

**一句话**：复习的终点不是"都看过"，是"**都提取过 + 都模拟过 + 错的都清过**"。
