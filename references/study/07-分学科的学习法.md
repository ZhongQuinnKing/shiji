# 学习·分学科的学习法

`01` 的机制、`02` 的实操，对所有科目都成立。但落地形态不一样：
数学难在推不出，医科法学难在记不住，编程难在不动手就永远学不会，
实验课难在手生。这一篇每类只给**一套循环**，拿去就能转起来。

## 一、先分清你的"难"是哪一种

- 推不出来（数学、物理、理论力学）→ 卡在理解与推导，缺的是"合书重推"
- 记不住（医学、法学、中医、历史）→ 卡在提取，缺的是间隔与自测
- 写不出代码（编程、数据类课程）→ 卡在动手量，缺的是项目
- 手不稳（实验、乐器、绘画、发音、操作课）→ 卡在练习密度，缺的是短时高频

方法对症才有用。用"多读几遍"对付这四种难，四边都不讨好。

## 二、数学：推导与做题的循环

**循环**：读定理 → **合书自己推一遍** → 推不出就回去看卡点 → 做教材例题 →
做变式题 → 错题归档 → 周末回炉。

- **独立推导是核心动作**。看懂别人的证明，和自己写出来，中间差着一条河。
  手写公式，别只用眼睛看
- 做题先独立，**卡住就标记继续往下**，别立刻翻答案。答案是用来看思路的，
  不是用来抄过程的
- **错题按两类分**：知识点没掌握、计算失误。前一类回去补推导，后一类加练手速
- 每章结束做一次"题型总结"：这一章有几种题型、每种的第一刀往哪切

**场景差异**：数学分析盯"有穷逼近无穷"和放缩技巧；
高等代数以线性空间与映射为主线，多想几何与代数的互相翻译；
概率统计靠每周温习加章节自测，拖到最后两周必崩。

## 三、理工科：模型与检验的循环

**循环**：读题 → 画图或建模 → 列式 → **量纲与极限检验** → 复盘误差来源。

- 每用一条公式，先写清**适用条件**。物理化学的失分，多半死于条件不对
- **量纲检验**是免费的纠错器：单位对不上，式子一定错
- **极限检验**：把参数推到 0 或无穷，看结果合不合理。这一招能拦住大半低级错
- 实验课单独一套：预习写流程、现场记**原始数据**（不誊抄）、当天整理、
  写误差分析。**原始数据当场记录是纪律**，事后编数据的代价远大于不好看

## 四、编程：项目驱动的循环

**循环**：学最小语法集 → 立刻做一个小项目 → 卡住 → 查文档 → 看别人怎么写的 →
回来加一个功能。

- **只看视频不动手，等于假性学会**。每天手写代码，哪怕二十行
- 顺序感要有：语法 → 数据结构与算法（**自己手写实现一遍**）→ 刷题与小程序交叉
  → 主流框架 → 一个完整项目 → 拆解开源项目
- **刷题和项目不是二选一**：刷题练算法与边界思维，项目练工程与"做完"的能力
- 数字参考：一学期至少 3 个项目，每个项目配一个 README 写清"它解决什么问题"

## 五、背诵大户：抗遗忘的循环（医学、法学、中医、历史）

`job/34` 写过一句话：**医＝记忆量之王，背是硬功夫**。这一条对法学、中医、
历史同样成立。它不等于死记，它等于**有结构的重复**。

**循环**：框架先行 → 关键词挖空 → 主动回忆 → 间隔复习 → 红笔回炉。

1. **先搭骨架**：一章一张框架图，只写关键词与逻辑关系。骨架不清就开始背，
   背得越多越乱
2. **挖空自测**：把关键概念、数字、年份做成填空题，每天自测一章
3. **间隔节奏**：当天、第 2、4、7 天各过一次；难章节缩短间隔，熟章节拉长
4. **红笔回炉**：默写框架，写不出的用红笔标，睡前再背红笔区。
   **框架能复现八成以上，这一章才算过**
5. **口诀适量**：理解了再编，编了要能还原。满篇口诀本身就是负担。
   例：阿司匹林副作用记"为您扬名"，四个字各对一类反应

**法学多加一步**：背"构成要件 + 例外"，再用案例反推——给一个案情，
先判断够不够成，再回头找法条。**用案例查漏，比顺着目录背有效**。

## 六、技能与实验型课程：手感循环

**循环**：慢练最小单元 → 连成片段 → 完整走一遍 → **录像回看** → 只定一个改进点。

- **短时高频胜过周末突击**：每天 20-30 分钟，比一周攒三小时管用
- **录像回看**是进步最快的动作，自己看不见的问题，镜头看得见
- 一次只改一个点。同时改三处，三处都会反弹
- 语言发音、乐器、绘画、手术操作、体育，全部适用同一套

## 七、一张对照表

| 科目类型 | 循环 | 检验标准 |
|----------|------|----------|
| 数学 | 推导—例题—变式—错题回炉 | 合书能独立推出定理，题型能说出来 |
| 理工理论课 | 建模—列式—量纲与极限检验 | 单位自洽、极限合理、条件写对 |
| 编程 | 语法—小项目—查文档—加功能 | 独立做出 3 个有 README 的项目 |
| 医科法学类 | 骨架—挖空—回忆—间隔—回炉 | 默写框架复现八成以上 |
| 技能实验类 | 慢练—连段—完整—录像回看 | 同一动作连续三次不走形 |

## 八、案例：三个人的三周

【情境】同一间自习室里，三个人都在为期末挣扎，方法完全不同。

> **小陈（高数）**："我把课本例题全抄了一遍，可一合书还是不会。"
> **小李（临床）**："抄没用。我背书也是一样，看十遍记不住，
> 合书默一遍反而记住了。"
> **小陈**："那我也默？"
> **小李**："你先合书把那定理自己推一遍。推不出来，才是你真不会的地方。"
> **小王（计算机）**："我们那门课我干脆不看了，直接写个能跑的小东西，
> 报错报两小时，比看视频一天都值。"

【三周后】小陈把每章定理合书重推一遍，错题按两类归档，期末从 61 提到 82；
小李用"骨架加挖空"，一天背一章、第 2 天和第 4 天回炉，默写复现率到八成五；
小王交了三个小项目，其中两个还在面试时被追问过。

【拆解】**三个人用的都不是"更努力"，是各自科目的正确循环**。
数学的循环在推导，背诵科目的循环在提取，编程的循环在动手。
方法错了，努力全部折损。

## 一句话

分学科的学习法不是五套不同的道理，是**同一条原理换五种载体**：
理解的东西靠推导验证，记忆的东西靠提取重复，会做的东西靠项目练手，
手上的东西靠高频慢练。**先认出你卡在哪一种，再选循环。**
