# 研究生·科研入门

## 一、先接受"迷茫是标配"

本科是"学知识"，研究生是"**做问题**"——两种活法的切换期，迷茫是必然的。
先熟悉课题组方向、读几篇经典文献、把"我到底要干嘛"这个问题**从焦虑改成任务**：
它不是想出来的，是**做着做着清晰起来的**。

## 二、读文献：研究生的第一项硬技能

（检索方法见 `thesis/02`；这里讲"研究生怎么读"）

**动手前先问三件事**（问导师或师兄姐）：
1. 这个方向的**中英文关键词**、常见缩写、经典方法名
2. **3-5 篇入门必读**（通常=一篇综述 + 一两篇经典 + 一两篇课题组近年论文）
3. 读完要**交付什么**（组会汇报？文献表？综述？）——交付形式决定读法

**读的顺序**（先建地图，再进细节）：
```
综述（了解全局）→ 经典（建立主线）→ 近期（找前沿）→ 课题组论文（找准切入点）
```
**别一上来逐篇精读硬啃公式**——那是新手最常见的沉没成本。

**论文三遍读法**：
1. 第一遍（约 10 分钟）：标题/摘要/引言/方法框架图/结论——**判断值不值得继续**
2. 第二遍（30-60 分钟）：理解研究逻辑与结构（问题→方法→结果怎么串的）
3. 第三遍：确有价值的精读（公式推导/实验设计细节）

**带着问题读**——每篇都在回答三件事：这个方向的核心问题是什么？
别人做到哪一步了？哪些地方还没人碰？
**读完用一两句话写"它和我的课题什么关系"**。没关系就只留摘要，别恋战。

**两个纪律**：
- **批量读**（下载分类后集中几天读完+写总结——零散读=读了忘）
- **随时记录**（可引用的句子/数据/观点当场记——"两个月后想引用找不到出处"
  是每个研究生的共同教训）

## 三、找题：务实优先

- **读综述的"展望"部分**——"尚不清楚""有待研究"的句子，就是前辈留的题
- **直接问导师/师兄姐要"跑通过基本流程的题"**——原话值得刻进骨头：
  **"走通一次完整流程，比拿着一个牛题目做不动要强得多。"**
- 选题综合权衡：创新性 × 可行性 × 数据可得性 × 设备排期——**别空中楼阁**
- **创新不只是"从文献到文献"**——敢于质疑：别人做过但可能有问题的（疑区）、
  无人探索的（荒区）、能证明前人研究有误的（误区）——都算创新

## 四、科研习惯（拉开差距的部分）

1. **动手前先动脑**：新想法先查文献（有没有人做过）→ 评估原理可行 → 设计实验
   ——**"别用行动的勤奋掩盖思维的懒惰"**
2. **实验记录**：详细到"新人能按它复现"；当天记；**异常结果哪怕很小也记下**
   （异常往往是发现的门）
3. **资料分类留痕**：课题按"我的研究/师兄师姐的/公共事务/组会/会议"分类；
   论文文件夹再分"参考文献/原始数据/图表/初稿/投稿"——**所有事项有迹可查**
4. **每天写一点**：论文/总结/申报书——每天 500 字，写东西会越来越不费力
   （写作是研究生的第二硬技能）

## 五、组会：5 分钟汇报模板

每人 5-10 分钟、最多 5 页 PPT，只讲三件事：

```
① 上周做了什么（3 分钟）：跑了什么数据、做了哪些图、读了哪些文献
② 遇到什么问题（3 分钟）：【组会最有价值的部分】
③ 下周计划（1-2 分钟）：要完成什么（说具体）
```

"问题部分"别藏——**很多突破就发生在组会讨论里**；把卡点讲清楚，
会有意想不到的角度进来。

## 五·补、同门与实验室（课题组怎么运转）

课题组是个小单位：谁管设备、谁管耗材、谁手里有数据、谁说话管用——没人给你发手册。
摸清它只有一条路：先看，再问，别急着评价。

**怎么从师兄姐手里接课题**

毕业季就是交接季。师兄姐走之前那两三个月，是他最愿意教、也最没时间教的时候。
开口要具体，别要"方向"：

> "师兄，你之前那个 XX 实验我打算往下做。能不能给我讲讲：数据存在哪、
> 脚本怎么跑、哪几步容易出错、有没有你试过但没走通的路？"

接活三条纪律：
1. **要"完整的半成品"，不要"半个传说"**——接手前确认最低交付：原始数据在哪、
   处理到哪一步、结论是什么、还缺什么。听不懂的当场问，别回去猜
2. **亲手跑通一遍才算接手**——照他给的步骤复现一次，复现不出来就是交接没完成
3. **从接手那天起自己记**——日期、改动、异常。将来出问题，记录是唯一能自证的东西

**数据与代码的交接规范**（最容易翻车的地方）

- 原始数据只读，永不在原件上改；副本加工，命名带日期（同 `thesis/05` 的数据纪律）
- 代码进版本库（Git 私库），交接时连同 README 一起给：环境依赖、运行顺序、参数含义
- 交接留个凭据：一封邮件列清"收到哪些文件、在哪个目录、什么状态"——
  不是不信任，是三个月后双方都记不清
- 涉及他人未发表结果的数据，**不私下拷给组外**，这条没有例外

**实验室的日常运转**

通常有人管设备（预约、维护、报修）、有人管耗材（采购、领用、报销）、有人管公共
事务（值日、安全、组会记录）。分工各校各组不同，规律一致：**动手前先问谁负责**。
新人最常犯的两个错，一是没预约就用公共仪器，二是用完不还原。守两条就能避掉：
**用完恢复原样；坏了立刻说**——瞒着不报是小错变大过的标准开局。

**成果归属的边界**

- 谁做的实验、谁写的稿、谁出的想法，写清楚（署名规则见 `06`）
- 用别人的数据发文章，**先谈位置再动手**——合作开始时谈，比投稿前谈容易十倍
- 帮过忙不等于作者，作者也不等于只是帮过忙：贡献按实质性算

**跟同门闹矛盾怎么办**

分三档：
1. **资源摩擦**（抢仪器、抢工位、作息冲突）——当面说，就事论事，别上升人品
2. **贡献不清**（谁的活说不清、署名排序有异议）——**拉记录**：
   实验记录本、聊天记录、邮件里写过谁做什么。有记录的事好谈，没记录只剩情绪
3. **越界**（长期被支使、成果被拿走、被挤到做不了事）——先找导师；
   涉及钱、承诺、权力不对等且可能踩线的，**留证据 + 走正式渠道**
   （同 `life/03` 与 `workplace/05` 的处置流程）

一条底线：**别在组里站队**。导师最不想管的就是组内分派系，卷进去的人，
最后都得花时间证明自己"只是路过"。

**一段真实的交接**

【情境】小许研一接手师姐没做完的项目。他没急着跑数据，先做了三件事：约师姐一个
下午，把数据目录、脚本、踩过的坑全过一遍；自己按步骤复现，发现漏了一个环境依赖，
当场补上；当天发邮件把交接清单抄给师姐和导师。

【三个月后】结果对不上。他翻出那封邮件，问题出在师姐当初用的那批试剂批号不同，
不是他跑错。导师在组会上说了一句："这交接做得像个研究生。"

【拆解】接手别人没做完的东西，难点不在技术，在**信息**。把信息固定成文件和邮件，
争议就没有生长的地方。

**话术成品句**（问师兄姐时直接说）

- 接手："这个课题我想接着做，你哪天有空，我把数据和脚本跟你过一遍？"
- 要资料："组里的惯例文档、常用账号、仪器预约方式，你走之前能给我一份吗？"
- 有异议："这篇里我做了 ×× 和 ××，署名能不能按这个再对一下？"
- 坏了："× 号仪器我今天用的时候出了 ×× 情况，已经停了，要不要报修？"

**边界**

全国没有统一的课题组管理规范；实验室分工、数据交接要求、署名惯例**各组各校不同**，
有的组有书面交接制度，有的全靠口口相传。拿不准就问导师，或者问上一届——
同门的信息永远比攻略准。

## 六、正视失败（科研的底色）

实验不顺利、数据不对、复现不出来——**这不是你笨，这是科研的日常形态**。
一句要记住的话：**"失败不是科研的副产品，失败就是科研本身的一部分。"**
跑不出来：先放下换个角度，或找同门聊（聊着聊着盲区自己会浮出来）。

## 六·补、工具箱（少而精的几件）

- **文献管理**：Zotero（免费、插件多）或 EndNote（学校常送正版）——
  从**第一篇文献**就用，别等"文献多了再整理"（那时已经晚了）
- **写作**：Word 配样式够用；公式多、排版重的方向学 LaTeX（Overleaf 在线可用）
- **绘图**：优先矢量图（Origin / Python matplotlib 等）——**论文里的图要能无损放大**；
  配色用系统色板，别用荧光色
- **数据与代码**：原始数据**永不手改**（留底+副本加工）；代码存版本（Git 私库）
- 一条边界：**AI 可辅助（润色/翻译/调试/找线索），研究判断必须是你自己的**
  （同 `thesis/05` 第六节的 AI 合规线）

## 六·补2、案例：从"读不动"到"读得动"

【情境】小杨研一，导师给的方向文献全是英文，前两个月他逐篇精读——
一篇读三天，读完全忘，越读越慌："是不是我不适合读研？"

【转折：换成"三遍读法+批量"】

1. **先读综述**（一篇综述抵十篇散读）——一周读完，方向地图第一次有了轮廓
2. **论文三遍读**：第一遍 10 分钟只判断"值不值得读"（大部分止步于此）；
   第二遍 30-60 分钟读逻辑；**只有和课题直接相关的才进第三遍精读**
3. **批量读**：把 20 篇下载分类，集中三个下午读完+每篇写两行"和我的课题
   什么关系"——之前零散两个月没做到的事，三个下午做完了

【一个月后】他能在组会上说出"这个方向有三条路线，我们在第二条"——
导师说：**"这就算入门了。"**

【拆解】他从"读不动"到"读得动"，不是英语变好了——是**读法换了**：
**综述建地图 → 三遍读法筛价值 → 批量+写关系句**。阅读量不是目标，
"读完能说出关系"才是。

## 七、四个避坑

1. **"我要把领域所有文献读完"**——读完几百篇却答不出"你打算做什么"，
   是新生最大的陷阱（**问题导向，不是文献导向**）
2. 只动手不动脑（做完一堆实验，讲不出为什么做）
3. 不记录不整理（两个月后数据成谜）
4. 闭门造车（**多与导师沟通、多与同门讨论**——选题有时就在吃饭聊天里冒出来）
