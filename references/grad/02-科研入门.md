# 研究生·科研入门

## 一、先接受"迷茫是标配"

本科是"学知识"，研究生是"**做问题**"——两种活法的切换期，迷茫是必然的。
先熟悉课题组方向、读几篇经典文献、把"我到底要干嘛"这个问题**从焦虑改成任务**：
它不是想出来的，是**做着做着清晰起来的**。

## 二、读文献：研究生的第一项硬技能

（检索方法见 `thesis/02`；这里讲"研究生怎么读"）

**动手前先问三件事**（问导师或师兄姐）：
1. 这个方向的**中英文关键词**、常见缩写、经典方法名
2. **3-5 篇入门必读**（通常=一篇综述 + 一两篇经典 + 一两篇课题组近年论文）
3. 读完要**交付什么**（组会汇报？文献表？综述？）——交付形式决定读法

**读的顺序**（先建地图，再进细节）：
```
综述（了解全局）→ 经典（建立主线）→ 近期（找前沿）→ 课题组论文（找准切入点）
```
**别一上来逐篇精读硬啃公式**——那是新手最常见的沉没成本。

**论文三遍读法**：
1. 第一遍（约 10 分钟）：标题/摘要/引言/方法框架图/结论——**判断值不值得继续**
2. 第二遍（30-60 分钟）：理解研究逻辑与结构（问题→方法→结果怎么串的）
3. 第三遍：确有价值的精读（公式推导/实验设计细节）

**带着问题读**——每篇都在回答三件事：这个方向的核心问题是什么？
别人做到哪一步了？哪些地方还没人碰？
**读完用一两句话写"它和我的课题什么关系"**——没关系就只留摘要，别恋战。

**两个纪律**：
- **批量读**（下载分类后集中几天读完+写总结——零散读=读了忘）
- **随时记录**（可引用的句子/数据/观点当场记——"两个月后想引用找不到出处"
  是每个研究生的共同教训）

## 三、找题：务实优先

- **读综述的"展望"部分**——"尚不清楚""有待研究"的句子，就是前辈留的题
- **直接问导师/师兄姐要"跑通过基本流程的题"**——原话值得刻进骨头：
  **"走通一次完整流程，比拿着一个牛题目做不动要强得多。"**
- 选题综合权衡：创新性 × 可行性 × 数据可得性 × 设备排期——**别空中楼阁**
- **创新不只是"从文献到文献"**——敢于质疑：别人做过但可能有问题的（疑区）、
  无人探索的（荒区）、能证明前人研究有误的（误区）——都算创新

## 四、科研习惯（拉开差距的部分）

1. **动手前先动脑**：新想法先查文献（有没有人做过）→ 评估原理可行 → 设计实验
   ——**"别用行动的勤奋掩盖思维的懒惰"**
2. **实验记录**：详细到"新人能按它复现"；当天记；**异常结果哪怕很小也记下**
   （异常往往是发现的门）
3. **资料分类留痕**：课题按"我的研究/师兄师姐的/公共事务/组会/会议"分类；
   论文文件夹再分"参考文献/原始数据/图表/初稿/投稿"——**所有事项有迹可查**
4. **每天写一点**：论文/总结/申报书——每天 500 字，写东西会越来越不费力
   （写作是研究生的第二硬技能）

## 五、组会：5 分钟汇报模板

每人 5-10 分钟、最多 5 页 PPT，只讲三件事：

```
① 上周做了什么（3 分钟）——跑了什么数据/做了哪些图/读了哪些文献
② 遇到什么问题（3 分钟）——【组会最有价值的部分】
③ 下周计划（1-2 分钟）——要完成什么（说具体）
```

"问题部分"别藏——**很多突破就发生在组会讨论里**；把卡点讲清楚，
会有意想不到的角度进来。

## 六、正视失败（科研的底色）

实验不顺利、数据不对、复现不出来——**这不是你笨，这是科研的日常形态**。
一句要记住的话：**"失败不是科研的副产品，失败就是科研本身的一部分。"**
跑不出来：先放下换个角度，或找同门聊（聊着聊着盲区自己会浮出来）。

## 六·补、工具箱（少而精的几件）

- **文献管理**：Zotero（免费、插件多）或 EndNote（学校常送正版）——
  从**第一篇文献**就用，别等"文献多了再整理"（那时已经晚了）
- **写作**：Word 配样式够用；公式多、排版重的方向学 LaTeX（Overleaf 在线可用）
- **绘图**：优先矢量图（Origin / Python matplotlib 等）——**论文里的图要能无损放大**；
  配色用系统色板，别用荧光色
- **数据与代码**：原始数据**永不手改**（留底+副本加工）；代码存版本（Git 私库）
- 一条边界：**AI 可辅助（润色/翻译/调试/找线索），研究判断必须是你自己的**
  （同 `thesis/05` 第六节的 AI 合规线）

## 六·补2、案例：从"读不动"到"读得动"

【情境】小杨研一，导师给的方向文献全是英文，前两个月他逐篇精读——
一篇读三天，读完全忘，越读越慌："是不是我不适合读研？"

【转折：换成"三遍读法+批量"】

1. **先读综述**（一篇综述抵十篇散读）——一周读完，方向地图第一次有了轮廓
2. **论文三遍读**：第一遍 10 分钟只判断"值不值得读"（大部分止步于此）；
   第二遍 30-60 分钟读逻辑；**只有和课题直接相关的才进第三遍精读**
3. **批量读**：把 20 篇下载分类，集中三个下午读完+每篇写两行"和我的课题
   什么关系"——之前零散两个月没做到的事，三个下午做完了

【一个月后】他能在组会上说出"这个方向有三条路线，我们在第二条"——
导师说：**"这就算入门了。"**

【拆解】他从"读不动"到"读得动"，不是英语变好了——是**读法换了**：
**综述建地图 → 三遍读法筛价值 → 批量+写关系句**。阅读量不是目标，
"读完能说出关系"才是。

## 七、四个避坑

1. **"我要把领域所有文献读完"**——读完几百篇却答不出"你打算做什么"，
   是新生最大的陷阱（**问题导向，不是文献导向**）
2. 只动手不动脑（做完一堆实验，讲不出为什么做）
3. 不记录不整理（两个月后数据成谜）
4. 闭门造车（**多与导师沟通、多与同门讨论**——选题有时就在吃饭聊天里冒出来）
