# 论文·规范与格式

格式在论文考核里是"隐形分"：没人因为格式好给高分，但**格式错会被硬扣**——
盲审阶段格式问题是直接写进评审意见的。这一篇把最常错的说清。

## 一、第一条铁律

**学校发的模板是唯一真经**——字体、字号、行距、页边距、标题层级、页码格式，
一律照模板。网上（包括本篇）说的都是通则，**冲突时以学校模板为准**。

## 二、参考文献：格式与"体质"

**两种著录制**（看学校要求）：
- **顺序编码制**（国内多数）：正文里标 `[1]`，文末按引用顺序列
- **著者-出版年制**：正文标 `（张三，2024）`，文末按字母/拼音排

**GB/T 7714 常用格式实例**（顺序编码制，照着套）：

```
[1] 作者. 题名[J]. 期刊名, 年, 卷(期): 起止页码.
     例：李四. 县域直播电商的农户增收效应[J]. 农业经济问题, 2024, 45(3): 88-97.

[2] 作者. 书名[M]. 版本. 出版地: 出版社, 出版年: 起止页码.
     例：王五. 社会研究方法[M]. 5版. 北京: 中国人民大学出版社, 2019: 112-115.

[3] 作者. 题名[D]. 城市: 学校名, 年.
     例：赵六. 短视频平台算法推荐对用户信息行为的影响[D]. 上海: 华东师范大学, 2023.

[4] 作者. 题名[EB/OL]. (发布日期)[引用日期]. 网址.
```

**高频错误**（每一个都真实常见）：
- 标点混用（中文文献用中文标点、英文文献用英文标点——GB/T 7714 用英文标点体系，
  以学校示例为准）
- 作者超三名只列前三位加"等"/"et al."
- 只写网址不写引用日期（电子文献必须标引用日期）
- **正文标号和文末列表对不上**（删过段落忘了改——定稿后逐条核对一遍）

## 三、图表规范

- 编号分章（图 3-1 = 第 3 章第 1 图；表同理）
- **图题在图下、表题在表上**（最经典的错位）
- 正文必须"提到"每张图表（"如图 3-1 所示"）——没被引用的图表删掉
- 数据来源标注（图表下方小字：数据来源：XX）
- 学术表格用三线表（顶线/底线/栏目线，无竖线）——模板里的示例照抄

## 四、标题层级

- 层级符号全篇统一（1 → 1.1 → 1.1.1，或 一、→（一）→ 1.，看学校）
- 不越级（1 下面直接 1.1.1 = 错误）
- 标题末尾不加句号；标题不超 20 字；同级标题的句式对仗（都是名词短语或都是动宾）

## 五、引用与转述的规矩（学术诚信的技术面）

- **直接引用**：加引号 + 标出处；比例别超过学校红线（常见"正文引用不超 30%"类要求）
- **转述（改写了别人的观点）**：也要标注出处——**判定抄袭看思想来源，不看你改了
  几个词**
- **引用要服务于论证**（"张三说 XX。李四说 YY。"连排=综述没消化，会挨批）

## 六、排版自查清单（交稿前逐条）

- [ ] 全文一种正文字体、一种标题字体（照模板）
- [ ] 行距、页边距、缩进（首行缩进两字符）全篇统一
- [ ] 页码格式正确（摘要用罗马数字/正文从 1 开始——看模板）
- [ ] 目录自动生成（不用手打——手打的一定会错页码）
- [ ] 中英文标点各就各位（英文词句用半角，中文行文用全角）
- [ ] 空行/空格干净（多余空行会进查重系统的"字数"）
- [ ] 通篇扫一遍错别字（打印出来读一遍，屏幕看不出）

## 七、最后一句

格式是"交卷礼仪"——**它不证明你的水平，但会暴露你的态度**。
把格式做干净，是让评审安心读你内容的最便宜的方式。
