# 论文·全流程地图（先看这篇）

毕业论文不是一篇"长作文"，是一条**八到十个月的流水线**：每个环节有交付物、有截止点、
有人验收。焦虑的大半来源是"不知道现在在哪、下一步交什么"——这张图把全流程摊开，
看完心就定一半。

## 一、六段流水线（以次年 5-6 月答辩的学校为例）

各校时间前后浮动，**以本校教务处/学院通知为准**（通常在教务系统或学院群发布）：

| 段 | 典型时间 | 你在这段的产出 | 什么标志算过关 |
|----|----------|----------------|----------------|
| ① 启动·定题 | 大四上 10-11 月 | 选题意向 → 系统选题 → 与导师双向确认 | 系统选题通过、任务书下达 |
| ② 开题 | 11 月-次年 1 月 | 文献综述 + 开题报告 + 开题答辩 | 开题答辩通过（不过则改后重审） |
| ③ 研究与写作 | 1-4 月 | 调研/实验/数据 + 初稿 + 中期检查 | 中期检查通过；初稿交导师 |
| ④ 查重与定稿 | 4-5 月 | 定稿 + 查重检测（近年多校加 AIGC 检测） | 查重过线、导师同意答辩 |
| ⑤ 答辩 | 5 月 | 讲稿 + PPT + 现场答辩 | 答辩通过（未过可二辩） |
| ⑥ 定稿存档 | 5-6 月 | 答辩后修改稿 + 终稿查重 + 材料归档 | 系统定稿、成绩录入、论文存档 |

两个容易被忽略的环节，先打个照面：

- **中期检查**（在 ③ 里）：学校查进度的正式动作——不是走过场，进度过慢会被点名督促
- **终稿查重**（在 ⑥ 里）：答辩后改了论文，很多学校**要再查一遍**——答辩后别大改、别补抄

## 二、倒排时间表（把这张抄进备忘录）

**原则：一切从答辩日往回倒，每站留出缓冲。**以"次年 5 月中旬答辩"为例：

| 节点 | 时间 | 硬标准 |
|------|------|--------|
| 答辩 | 5 月中 | 讲稿掐表 3 遍 + PPT 到现场电脑试放 |
| 查重+格式冲刺 | 答辩前 2 周 | 自查查重过线；格式逐条核对 |
| 定稿 | 答辩前 1 个月 | 全文完整、导师同意 |
| 初稿 | 2 月底前后 | 完整初稿——哪怕糙（烂初稿哲学见 `03`） |
| 数据/材料齐 | 3 月中 | 问卷回收完 / 访谈做完 / 数据到手 |
| 开题过 | 1 月前后 | 开题答辩通过 |
| 题定 | 11 月 | 系统选题确认 |

**缓冲铁律**：每个节点给自己留一半时间。查重预计三天做完，就按一周排——
真实世界里"预计"从来不准。

## 三、三个最容易出事的时刻（翻车高发区）

1. **开题前文献没读够**——开题答辩被问"这个方向别人做到哪了"答不上来，
   当场挂起大改（怎么读够 → `02-文献检索`）
2. **3 月底初稿还没影**——后面每一步都被压缩，格式、查重、答辩连环出事
   （写不出来怎么办 → `03-结构与写作` 的卡壳急救）
3. **查重放到最后一周**——降重是脑力活，一周内做不完（趁早自查 → `05-查重与降重`）

## 四、你现在在哪一段（对号入座）

| 你的处境 | 去读 |
|----------|------|
| 还没定题、题目拿不准 | `01-选题` |
| 题定了，文献没碰 | `02-文献检索` |
| 要写开题报告、准备开题答辩 | `07-开题报告` |
| "研究方法"不会填、不知道研究怎么做 | `08-研究方法` |
| 数据/问卷到手了，不知道怎么分析 | `09-数据与分析` |
| 写不动、结构乱、摘要不会写 | `03-结构与写作` |
| 格式排版、参考文献格式 | `04-规范与格式` |
| 怕查重、要降重、担心 AIGC 检测 | `05-查重与降重` |
| 答辩快到了 | `06-答辩` |
| 导师不回消息、不知道怎么汇报 | `10-与导师相处` |
| 想看别人怎么翻车、怎么救 | `11-案例集·论文全程` |

## 四·补、每个阶段一句"战斗指令"（贴墙上）

| 阶段 | 这个阶段只干一件事 |
|------|--------------------|
| 定题期 | 把题目打磨到"数据拿得到、范围写得死"（`01`） |
| 开题期 | 文献读够+开题报告过导师（`02`/`07`） |
| 研究期 | 数据/实验先跑通最小版本，别追求一步到位（`08`/`09`） |
| 写作期 | 每天 300 字，烂初稿先行（`03`） |
| 查重期 | 自查要趁早，给降重留两周（`05`） |
| 答辩期 | 讲稿掐表 3 遍，附录页备好（`06`） |

**误期案例**：小 Y 查重拖到答辩前三天，46%——熬夜改了两晚仍没过线，
延到下一批答辩。**每个环节的"最后一周"都是给别人留的缓冲，
不是给你的。**

## 五、进度管理的两个机制

1. **每周自检三问**（15 分钟，固定一天做）：这周推进了什么？卡在哪？
   下周第一件事是什么？——写下来，别凭感觉
2. **和导师对齐节奏**：多久见一次、怎么汇报，开题前就谈定
   （话术 → `10-与导师相处`）

谁都有卡住的时候——卡住不是异常，是流程的一部分。区别只在：
**是每周发现一次卡点，还是三个月后才发现。**

## 六、一句话

流水线的每个环节，都是"小一号的论文"：选题是缩小的问题意识，开题是缩小的全景论证，
答辩是当场复述。**把每段交割清楚，答辩那天你只是把做过的事，再讲一遍。**
