# 论文·全流程地图（先看这篇）

毕业论文不是一篇"长作文"，是一条**八到十个月的流水线**：每个环节有交付物、有截止点、
有人验收。焦虑的大半来源是"不知道现在在哪、下一步交什么"——这张图把全流程摊开，
看完心就定一半。

## 一、六段流水线（以次年 5-6 月答辩的学校为例）

各校时间前后浮动，**以本校教务处/学院通知为准**（通常在教务系统或学院群发布）：

| 段 | 典型时间 | 你在这段的产出 | 什么标志算过关 |
|----|----------|----------------|----------------|
| ① 启动·定题 | 大四上 10-11 月 | 选题意向 → 系统选题 → 与导师双向确认 | 系统选题通过、任务书下达 |
| ② 开题 | 11 月-次年 1 月 | 文献综述 + 开题报告 + 开题答辩 | 开题答辩通过（不过则改后重审） |
| ③ 研究与写作 | 1-4 月 | 调研/实验/数据 + 初稿 + 中期检查 | 中期检查通过；初稿交导师 |
| ④ 查重与定稿 | 4-5 月 | 定稿 + 查重检测（近年多校加 AIGC 检测） | 查重过线、导师同意答辩 |
| ⑤ 答辩 | 5 月 | 讲稿 + PPT + 现场答辩 | 答辩通过（未过可二辩） |
| ⑥ 定稿存档 | 5-6 月 | 答辩后修改稿 + 终稿查重 + 材料归档 | 系统定稿、成绩录入、论文存档 |

进度过半的地方站着两个环节，容易被忽略；还有一个环节，你根本不在场。
这三个先讲透，后面的节奏才踩得准。

## 一·补、中期检查：学校第一次正式盘你的进度

中期检查落在 ③ 段（多校排在大四下的 3-4 月）。形式各校不同：填一张中期检查表、
现场汇报十分钟、或者导师带着检查组当面问。名字温和，性质不温和。这是学校层面
第一次盘点，进度过慢会被点名督促，严重些进预警名单，此后学院会盯着你走。

**它查四样**：

1. **进度**：任务书上的计划完成了几成——文献读了多少、数据或实验到哪一步、初稿动没动笔
2. **方向**：和开题定的题目有没有跑偏。这里纠正还来得及，答辩前再纠正就晚了
3. **困难**：卡在哪、要学院协调什么（设备排不上、数据拿不到、访谈约不齐）
4. **材料**：开题报告、任务书、指导记录、初稿片段。按学院清单备齐，**缺件当场就尴尬**

**怎么过一次**（三条）：

- 提前一周把做完的东西整理成一个能翻给人看的文件夹。证据比嘴说可信
- 汇报十分钟只讲三件事：做了什么（给证据）、还差什么（给时间表）、卡在哪（给方案）
- **别报虚假进度**。中期报"接近完成"、答辩前拿不出东西的人，后面每一步都在还这笔账

**场景差异**：理工实验类看数据出没出来，跑不出结果的，这里就该换方案或缩范围；
文科调研类看材料和框架，访谈做了几场、问卷回收多少、章节搭到几级标题；
艺术类看作品进度（→ `13-毕业创作与展演`）。

**本科与硕士不是一回事**。本科的中期检查多为提醒性质，学院催进度、导师签字确认；
硕士常与"学位论文中期考核"绑定，有的学校算作必经环节，不通过要延期重新考核
（以本校研究生院规定为准）。

## 一·补2、评阅：一场你不在场的评分

答辩之前，论文先过一道你不在场的关：**评阅**。同行老师给你的论文打分、写评语，
分数进总成绩（常见构成：指导教师 40% + 评阅教师 20% + 答辩 40%，各校比例不同
→ `06-答辩`），评语进档案。

**三种叫法先分清**：

- **交叉评阅**（本科常见）：本院或兄弟院校老师互评，评阅人知道你是谁
- **盲审**（硕士为主，部分学校本科也在试点）：隐去作者与导师信息送外校专家，
  你也不知道谁评的你。最客观，也最不讲情面
- **外审**：送校外专家，可能盲也可能不盲

**评阅人手里只有论文，没有你**。所以他的判断全落在纸面：

1. 选题有没有价值、和专业方向配不配
2. 结构逻辑成不成立、章节之间是递进还是堆砌
3. 方法用对没有、数据与材料撑不撑得住结论
4. 规范：摘要、参考文献、格式、图表编号。**最易失分的地方，也最易拿分**
5. 有没有学术不端的迹象（文字雷同、数据可疑、图片重复）

**意见怎么读、怎么改**：

- 先看结论档位（同意答辩 / 修改后答辩 / 修改后重审 / 不同意答辩），它决定下一步
- 再按"必改"和"可选"分两栏，逐条抄成对照表：意见 → 修改处 → 页码。答辩时要交，
  这张表也证明你认真对待了意见
- **两位评阅人意见冲突**（一个嫌太详、一个嫌太略）：按导师和答辩组的判断取舍；
  实在改不动的，在修改说明里讲清理由
- 分数低不等于全盘否定。盯住扣分理由落在哪：格式类改起来最快，结构类要动手，
  方法类最要紧

**盲审不过怎么办**（各校差异大，以本校研究生院、教务处文件为准）：

- 常见分档：A 同意答辩 / B 修改后答辩 / C 修改后重审 / D 不同意答辩，C、D 一般算不通过
- 出现 C 或一个 D：多数学校给复评通道，按意见修改（硕士常见不少于 2 周到 1 个月，
  出现 D 的有的要求 3 个月），导师与学院同意后送原专家复评或另聘专家增评；
  复评仍不通过，才算真不过
- **申诉**只在"意见明显不成立"时用，有期限（常见 5-7 个工作日）也有次数限制（多为一次）。
  因错别字、格式这类理由被判 C 或 D 的，多数学校不受理申诉
- 二次送审仍不过：从"延到下一批次答辩"到"延期毕业"不等，硕士还可能触发分流退出。
  听着吓人，但复盘下来，不过的原因集中在两条：**没改透、送审前没自查**

**送审前的自查找替**：请一位不熟悉你题目的同学只读摘要和结论，问他"这篇在做什么、
结论是什么"。他答不上，评阅人大概率也答不上。

**案例**：小何的评阅意见回来，三条修改建议，外加一句"结论部分论证不足"。
她拿着意见去找导师：

> **小何**："老师，他说结论论证不足，我是不是要把结论重写一遍？"
> **导师**："先别动字。看他第二条，说'第三章数据没有支撑第四章的结论'。
> 这两条说的是同一件事：结论不是写得不够，是前面缺了一块。"
> **小何**："那我把第四章的推断挪回第三章？"
> **导师**："对。改完把三条意见做成对照表，每条写清改在哪一页。"

【拆解】评阅意见要**连着读**。几条意见常常指向同一个病根，
抓病根改一处，比对着字面改三处有效。

**还有一处易漏的动作**：终稿查重。答辩后改了论文，很多学校**要再查一遍**。
答辩后别大改、别补抄（→ `05-查重与降重`）。

## 二、倒排时间表（把这张抄进备忘录）

**原则：一切从答辩日往回倒，每站留出缓冲。**以"次年 5 月中旬答辩"为例：

| 节点 | 时间 | 硬标准 |
|------|------|--------|
| 答辩 | 5 月中 | 讲稿掐表 3 遍 + PPT 到现场电脑试放 |
| 查重+格式冲刺 | 答辩前 2 周 | 自查查重过线；格式逐条核对 |
| 定稿 | 答辩前 1 个月 | 全文完整、导师同意 |
| 初稿 | 2 月底前后 | 完整初稿——哪怕糙（烂初稿哲学见 `03`） |
| 数据/材料齐 | 3 月中 | 问卷回收完 / 访谈做完 / 数据到手 |
| 开题过 | 1 月前后 | 开题答辩通过 |
| 题定 | 11 月 | 系统选题确认 |

**缓冲铁律**：每个节点给自己留一半时间。查重预计三天做完，就按一周排——
真实世界里"预计"从来不准。

## 三、三个最容易出事的时刻（翻车高发区）

1. **开题前文献没读够**——开题答辩被问"这个方向别人做到哪了"答不上来，
   当场挂起大改（怎么读够 → `02-文献检索`）
2. **3 月底初稿还没影**——后面每一步都被压缩，格式、查重、答辩连环出事
   （写不出来怎么办 → `03-结构与写作` 的卡壳急救）
3. **查重放到最后一周**——降重是脑力活，一周内做不完（趁早自查 → `05-查重与降重`）

## 四·补、每个阶段一句"战斗指令"（贴墙上）

| 阶段 | 这个阶段只干一件事 |
|------|--------------------|
| 定题期 | 把题目打磨到"数据拿得到、范围写得死"（`01`） |
| 开题期 | 文献读够+开题报告过导师（`02`/`07`） |
| 研究期 | 数据/实验先跑通最小版本，别追求一步到位（`08`/`09`） |
| 写作期 | 每天 300 字，烂初稿先行（`03`） |
| 查重期 | 自查要趁早，给降重留两周（`05`） |
| 答辩期 | 讲稿掐表 3 遍，附录页备好（`06`） |

**误期案例**：小 Y 查重拖到答辩前三天，46%——熬夜改了两晚仍没过线，
延到下一批答辩。**每个环节的"最后一周"都是给别人留的缓冲，
不是给你的。**

## 五、进度管理的两个机制

1. **每周自检三问**（15 分钟，固定一天做）：这周推进了什么？卡在哪？
   下周第一件事是什么？——写下来，别凭感觉
2. **和导师对齐节奏**：多久见一次、怎么汇报，开题前就谈定
   （话术 → `10-与导师相处`）

谁都有卡住的时候——卡住不是异常，是流程的一部分。区别只在：
**是每周发现一次卡点，还是三个月后才发现。**

## 六、毕业不等于结束（抽检：毕业后还有一道关）

拿到毕业证学位证，不等于这件事翻篇。2021 年起，教育部施行《本科毕业论文（设计）
抽检办法（试行）》：**每年抽一次，抽的是上一学年度已授予学士学位的论文**，
比例原则上不低于 2%，覆盖本地区所有本科高校和全部本科专业。也就是说，
毕业一年之内，你那篇论文仍可能被抽出来，送 3 位同行专家重看一遍。
它是继 AIGC 检测之后（→ `05-查重与降重`）的第二道新关卡。前一道在你毕业前，
这一道在你毕业后。

**谁抽、抽什么**：省级教育行政部门依托全国本科毕业论文抽检信息平台随机抽取。
抽中后先跑学术不端检测，再送专家评议。考察的是"合格性"：选题意义、写作安排、
逻辑构建、专业能力、学术规范。它不要你有多创新（创新是硕博抽检的重心），
只要求它像一篇合格的本科生论文。

**怎么判**：初评送 3 位专家，2 位及以上评"不合格"的，认定为"存在问题毕业论文"；
只有 1 位评"不合格"的，再送 2 位复评，复评里再出现 1 位"不合格"即认定。
换个说法：**一位专家的差评不致命，两三位一致差评才致命**。

**什么情况容易被点名**（按常见理由排）：

1. **学术不端实锤**：抄袭、剽窃、伪造、篡改、买卖、代写。查实后依法撤销已授予学位、
   注销学位证书。这是唯一会把证收回去的一类
2. **通篇看不见"我做了什么"**：综述大段堆砌，没有研究设计，没有数据或材料，
   读起来像一篇读书笔记
3. **结构与规范失守**：章节立不住、参考文献大片缺失或对不上号、图表编号混乱、
   摘要和正文说的是两件事
4. **明显跑题**：实际内容与题目、与专业方向两张皮

**被抽到怎么办**：抽检抽的是论文，不是人。流程一般经学校、学院转到个人，
有的省份设申诉通道（以省级教育行政部门与学校通知为准）。该配合配合，别失联。
**失联本身比论文的问题更麻烦**。

**毕业后改论文与补数据的边界**：

- 可以做：更正笔误、格式、图注，补说明性注释；配合学校提供过程材料，
  包括原始数据、开题报告、指导记录、版本历史。**这些材料毕业时就该留档一份**
- 不该做：把论文改好重新提交充当"原件"（抽检抽的是当年存档那一版）；
  毕业后补实验、补问卷去凑当年的结论；找人修补"窟窿"
- 边界一句话：**可以修文字的错，不能改事实的账**。数据当年什么样就什么样；
  真补做了新实验，那是新研究，不是给旧论文打补丁

**给在读的人两个动作**：定稿版、原始数据、过程稿，打包留一份在自己手里；
写的时候就把"三年后还经得起看"当标准。这一条比任何临考技巧都值钱。

## 七、一句话

流水线的每个环节，都是"小一号的论文"：选题是缩小的问题意识，开题是缩小的全景论证，
答辩是当场复述。**把每段交割清楚，答辩那天你只是把做过的事，再讲一遍。**
