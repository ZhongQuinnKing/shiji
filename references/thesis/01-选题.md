# 论文·选题：定好题，就成了一半

选题是整篇论文里**性价比最高的一步**——题好了，后面顺流而下；题错了，后面全是修修补补。
这一篇说：怎么找到"能写好"的题，怎么判断一个题是好题。

## 一、好题的四条线（缺一条都难受）

1. **在专业的地界里**——符合专业培养目标、用得上专业的训练（跨太远，答辩会被问"这跟本专业什么关系"）
2. **不大不小**——大到写不动、小到没得写，都不行（判断标尺见下"小题大做"）
3. **资料够得着**——本科阶段尤其现实：数据能拿到吗？案例能进去吗？文献找得到吗？
   （查资料的方法见 `02-文献检索`）
4. **你真的有兴趣**——要陪伴你几个月的东西，纯为完成任务选的题，写起来是煎熬

## 二、小题大做、老题新作（八个字，本科选题的真经）

**小题大做**：本科生的常见悲剧是野心太大——"中国经济发展研究"这种题，
博士都写不完。正确姿势是**小切口、写到底**：

- 大："直播电商对经济的影响"
- 小："县域直播电商对农产品价格的影响——以 X 县为例"（有对象、有边界、能跑数据）

**老题新作**：题目老不可怕，**四新占一**就成立——新对象（新地区/新群体/新产品）、
新场景（新政策/新平台）、新数据、新方法。老题的最大优势是**资料多**，
你站在一堆前人肩膀上，起步快。

## 二·补、题目怎么拟（三要素打磨法）

好题目自带三要素：**对象 + 范围 + 角度/方法**。拿一个粗题打磨三遍：

1. 粗题："大学生就业焦虑研究"——对象模糊、范围无穷、没有角度
2. 加对象与范围："X 校应届毕业生的就业焦虑"——能落地了，但还平
3. 加角度与方法："X 校 2026 届毕业生就业焦虑现状与成因——基于问卷与访谈的调查"
   ——有边界、有方法，答辩时你已知道"怎么干"

三条自检：

- 题目里有"我够得着"的对象吗？（学校、地区、企业、群体——具体到能说出名字）
- 副标题说清方法或角度了吗？（"——基于……"句式是好用工具）
- 长度 20 字上下；避开"浅析""初探"这类自我矮化的词——**题目是小切口，不是"浅"**

## 三、从哪找题（五个矿脉）

1. **课程作业挖深**：哪门课的作业你做得最有劲？它就是种子
2. **老师的课题**：跟着老师的方向走——资料有人带、评审有底
3. **实习/实践中的真问题**：真的场景里的真麻烦，往往就是好题
4. **文献的"未来展望"**：好文献的结尾都写着"本研究不足与展望"——
   **那是前辈给你留的题**
5. **综述类文献**：搜"XX 综述"，看领域地图哪里还是空白（检索方法见 `02`）

## 三·补、案例：一个题目的三次打磨

【情境】小孟的初定题目：《短视频对大学生的影响研究》——被导师一句
"这个题太大了，回去收一收"打回。

【三次打磨实录】

1. **第一次（收范围）**：《短视频对大学生学习的影响》——导师："还是大，
   而且'影响'是好是坏说不清。"
2. **第二次（加对象+加角度）**：《短视频使用对大学生学习投入的影响——
   以 X 大学为例》——导师："可以，但你要回答'影响'，得说清怎么测。"
3. **定稿（加方法+可操作）**：《短视频使用时长与大学生学习投入的关系
   ——基于 X 大学 300 名学生的问卷调查》，导师："这个能做了。"

【拆解】三次打磨就是"三要素"的逐个落位：**第二次收进了"对象与范围"，
第三次补上了"角度与方法"**。选题的"收"不是把题改小，是**把每个词都
变成你可以动手的东西**。

## 四、好题自检（五问，全过才动笔）

- [ ] 资料找得到吗？（先花半天试检文献 + 想清数据来源）
- [ ] 范围能控制吗？（写不完的部分能砍掉吗）
- [ ] 跟专业相关吗？（答辩第一关）
- [ ] 我有话可说吗？（至少能说出三个想探究的点）
- [ ] 万一卡住了，有 B 计划吗？（缩小范围/换案例的退路）

## 四·补、选题的程序与纪律（别在这翻车）

- **一人一题**：选题系统里撞题是硬事故——师兄师姐写过的题，查重库里原样躺着（→ `05`）
- **实践性导向**：不少学校要求实践性选题占相当比例（文科常见"不低于 60%"）——
  纯文献综述型的选题慎选，以本校文件为准
- **变更要报批**：定题后不得随意换题，确需变更走学院审批——
  **换题的成本，远大于换题前多想三天**
- 时间表：多数学校 10-11 月完成系统选题（→ `00-论文全流程`）

## 五、和导师怎么谈题

- **带着 2-3 个方向去**，不要空手问"老师我写什么"——你给方向，老师给校准
- 谈之前每个方向写三行：想研究什么 / 为什么值得研究 / 初步想到的资料渠道
- 老师说"这个不行"时，追问"那往哪个方向调"——把否决变成指引
- **定题要趁早**（多数学校 10-11 月定题，晚了好的方向都被挑了）

## 六、四个误区（躲开）

1. **过大**：写不完=灾难
2. **过旧**：题目被写烂且你毫无新角度——查重都费劲
3. **过偏**：搜不到任何文献时别得意"我是空白"——可能只是没人觉得这值得研究，
   或者你还没找对词（先怀疑检索方法，见 `02`）
4. **直接复制师兄师姐的题**：撞题在国内查重库里是事故现场

## 一句话

选题不追求"惊艳"，追求"**能写完、写实、写出你自己的东西**"。带着这个尺子去选，
错不了。
