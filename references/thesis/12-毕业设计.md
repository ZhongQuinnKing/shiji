# 论文·毕业设计（工科版）

工科（及部分农、医）的毕业环节是**毕业设计**：重头不是"写一篇"，是"**做出来**"。
这篇讲清它和毕业论文的差异，以及设计路线独有的坑。

## 一、先分清：两套路线

| | 毕业论文 | 毕业设计 |
|--|----------|----------|
| 主产物 | 一篇研究论文 | **设计成果**（图纸/程序/实物/方案）＋设计说明书 |
| 核心能力 | 研究论证 | 综合运用与工程实现 |
| 评价重心 | 结论有没有价值 | **方案合不合理、做没做出来、能不能用** |
| 典型专业 | 文、理、经管 | 工科为主，部分农、医 |

（不少学校"毕业设计（论文）"并称、管理文件一套——**以本校规定为准**）

## 二、产出物清单（先搞清楚要交什么）

- **设计说明书**（相当于"论文"）：封面 / 摘要 / 目录 / 正文 / 谢辞 /
  参考文献 / 附录
- **图纸**：二维工程图、三维模型（机械），电路图、原理图（电子），
  架构图、流程图（软件）
- **程序 / 仿真 / 实物**（视课题）
- 过程文件：任务书、开题报告、外文翻译、成绩评定书

⚠️ 图纸有**国家标准**（制图规范）——"图表多处不符国标"是明确的扣分项，
有的学校直接不能评优。画图前把国标翻一遍，或照学长学姐的合格图纸核对。

## 三、设计说明书怎么写（结构和论文不同）

1. **任务与目标**：课题要求、原始条件、技术指标——**验收标准就写在这**
2. **方案论证**：**设计的灵魂**——为什么选这个方案？摆 2-3 个候选方案对比
   （成本 / 可行性 / 性能），论证选定的理由
3. **方案设计**：总体架构 → 分模块设计（图纸 + 计算 + 选型）
4. **实现与实验**：做出来的过程、调试、测试数据（截图、波形、测试表）
5. **总结**：指标达成了吗？没达成的如实说 + 原因

（写作与格式的通用技巧 → `03`/`04`；查重 → `05`；答辩细节 → `06`）

## 四、时间账（比论文更紧）

论文可以"坐着写"，设计必须"做着来"——**东西做不出来，就没得写**。倒排要点：

- **留出"做砸重来"的时间**：调试和返工是常态不是意外，按"预计时间 ×2"排
- 硬件：器件采购预留物流时间——别等最后一周才发现买错型号
- 软件：环境配置、数据获取、跑通最简版本，各留缓冲
- 中期检查看的就是"做出来多少"：有阶段成果（demo、半成品）就稳

## 五、答辩：要"演示"的那种

报告 + **实物/程序演示** + 提问（有的学校公开答辩、要求全程旁听）。

**演示预案（工科独有，提前备）**：

- **必须录像**：演示当天设备出问题的概率不为零——录好视频＝保险
- 现场跑不起来的说法提前想好：讲清设计原理 + 展示截图/录像，
  **别现场埋头修半小时**（评委的时间是别人的答辩时间）
- 提前到现场测设备：接口、电源、投屏

**会被问什么**：方案为什么这么选（第三章）、指标达成度、
**"你独立做了哪部分"**——这题要答得诚实且具体。

（时长和流程按学校要求练；论文答辩的问答技巧通用 → `06`）

## 五·补、答辩常见追问（工科特有，提前备）

- "这个参数为什么取 X？"——**每处选型都要有依据**（计算/手册/对比试验）
- "如果换成 [更大负载/不同环境]，方案还成立吗？"——边界条件提前想
- "成本算过吗？"——经济性分析是毕设的加分项（哪怕粗算）
- "你独立完成的部分具体是哪些？"——如实、具体（合做的部分说清分工）

**案例**：小 Z 的演示现场板子烧了——他不慌：举手说明 + 用手机播放
提前录好的演示录像 + 讲清原理与测试数据，评委照样给了高分。
印证第五节那条：**演示录像就是保险，出发前一定录好。**

## 六、最容易翻的三处

1. **方案论证写成"我选了这个方案"**——没有对比、没有理由，
   答辩第一刀就落在这
2. **图纸不规范**（图线、标注、编号不按国标）——硬扣分，还显得不专业
3. **买现成方案/抄开源项目当自己做的**——说明书查重 + 代码实现细节提问，
   双通道暴露；被问"这一段为什么这么写"就穿

## 一句话

毕业设计的评委看三样：**方案有没有道理、东西有没有做出来、你讲不讲得清自己做的部分。**
把这三样立住，说明书是水到渠成的事。
