# 论文·案例集（全程翻车现场）

论文路上出的"事故"，九成都集中在同样几个位置。这一篇把高频翻车写成案例：
**看懂别人怎么掉的坑，你的坑就少一半。**每则按"情境 → 现场 → 拆解 → 带走"走。

## 案例一、开题被打回："这个题，全校没人做得完"

【情境】小李第一次开题会，PPT 第一页题目：《中国中小企业数字化转型研究》。

【现场】

- 评委 A："这个题，顶尖团队做了五年。你打算用什么数据？"
- 小李："我……发问卷。"
- 评委 B："发给谁？全国的中小企业？你认识几个老板？"
- 开题挂起，要求收窄。

【拆解】题目三个毛病：**无边界**（全中国）、**数据无着落**、"我"在题里没有支点。
评委不是刁难——这三个问题他一定会问，今天不问，等你写到第三章才崩。

【改后】《县域中小企业数字化转型的困难与对策——以 X 市 Y 区 12 家企业为例》：
对象、范围、方法全落地。

【带走】题目自检三问：**数据拿得到吗？范围写得死吗？我够得着吗？**（→ `01-选题`）

## 案例二、文献没读够，开题被问倒

【情境】开题答辩。小张的文献综述 800 字，引了 6 篇文献，5 篇是教材。

【现场】

- 评委："这个方向，国内谁做得最多，知道吗？"
- 小张："呃……我查到的资料有限。"
- 评委："有限不是理由，是没查。这个主题，文献库里有四百多篇。"

【拆解】文献综述不是"凑篇数"，是证明"你知道这片地谁在种"。
800 字、6 篇、全是教材 = 告诉评委你没进场，后面的研究计划可信度直接归零。

【带走】开题前的最低量：读完 **3 篇综述 + 按被引量排序的 top10 + 近三年核心 5 篇**；
搜法不够熟练，回去看 `02-文献检索` 的高级检索五步。

## 案例三、问卷 60 份，写"代表了消费者群体"

【情境】正文写"本研究对消费者进行了问卷调查（N=60）"，来源是朋友圈和三个群。

【现场】

- 评委："60 份，样本量怎么确定的？代表性呢？"
- 学生："老师，我尽力了……"
- 评委："那就在局限里如实写。"

【拆解】60 份不是致命伤，**"60 份装成大样本"才是**。如实写局限 + 方法透明，
小样本的探索性研究照样过；硬写"代表消费者群体"，一问就穿。

【带走】样本小就诚实标局限、定位成"探索性调查"——**不装，就不崩**。
（怎么报告回收率 → `09-数据与分析`）

## 案例四、查重 46% 的七天抢救

【情境】交稿前一周自查，46%，红色满屏。学生第一反应：找代降重。

【操作】（正当流程，七天够用）

1. 逐段看标红来源：分两类——**引用没标规范**的、**贴着原文转述**的
2. 引用补全标注和引号（这一类改完，比例常常直接掉一大块）
3. 贴原文的段落：合上屏幕，用自己的话重写（真正消化过再落笔）
4. 大段数据描述改成表格
5. 再查：46% → 18%，过线

【拆解】标红的不是文字，是"没消化"。降重的根本方法是**消化学**（→ `05-查重与降重`）；
代降重＝学术不端 + 论文外泄，双风险，绝对不碰。

【带走】查重失败的本质是**引用不规范 + 转述太贴原文**，对症就能救。

## 案例五、AIGC 检测 38%，被导师叫去问话

【情境】小王自认为没让 AI 写——但摘要、绪论的每段，都让 AI"润色一下"。
AIGC 检测 38%，学校红线 30%。

【现场】

- 导师："这些段落是你写的吗？"
- 小王："是我写的……用工具润色了。"
- 导师："下次润色自己来。学院要的，是你写的东西像你写的。"

【拆解】AIGC 检测分不清"AI 生成"和"AI 润色过头"——它按文本特征打分，
**全文润色 = 全文 AI 腔 = 高危**。政策面：查资料、润色个别句可以，
整段生成不行；各校红线 15%-40% 不等（→ `05` 的 AIGC 专节）。

【带走】① 别让 AI 整段重写，润色到句子为止；② **保留写作过程稿**
（版本历史、手写大纲）——被误判时，过程就是证据；③ 有争议时找导师/学院沟通，
说明使用情况，别硬扛也别乱认。

## 案例六、答辩被问倒的救场

【情境】答辩现场。评委："你这个回归模型，为什么没控制行业变量？"

【❌ 反例】"呃……这个……我没想到……"（沉默二十秒，全场尴尬）

【✅ 正例】"您提的这点我之前没考虑到。我的初步理解是：样本里行业比较集中，
影响可能不大——但这确实是局限，我回去会补控制变量重新跑，把结果补进修改稿。"
（评委点头，进入下一个问题。）

【拆解】评委提问不是找茬，是看你怎么接球。答不上来不可耻；
**现场编一个错的答案，才是致命伤**。承认 + 初步理解 + 补救方案，三步稳。

【带走】"答不上来标准姿势"背下来（→ `06-答辩`）。

## 案例七、导师失联一个月

【情境】小赵 4 月发消息不回，后来发现导师在带另一个组开会——只是没顾上他。

【操作】

1. 停止内心戏；按 48 小时规则，简短重发一次
2. 仍没回 → 课间当面堵："老师，我的稿子 V3 发您两周了，想请您指点一下大方向。"
3. 导师："哦，那个我看到了，先按你的思路写。"
4. 小赵追加一句："好，那我这周把第 3 章写完，**下周二再来找您**，可以吗？"——
   当场把下一次钉死

【拆解】导师不回 ≠ 针对你，是大忙人的常态。破局三件套：**简短重发 → 当面 →
当场约定下次**。最怕的是拿"导师失联"当自己拖延的挡箭牌。

【带走】催的节奏有章法（→ `10-与导师相处`），别让沉默把你拖停。

## 案例八、数据到手，打开 Excel 就懵

【情境】问卷 218 份回收完，看着表格发愁：想学 SPSS，又觉得来不及。

【操作】从描述统计破局——

1. 数据透视表：每题的频数、百分比（一天）
2. 交叉表：按年级、性别分组比较（半天）
3. 挑出差异最大的两三个点深挖（要不要上检验，问导师）
4. 结果章框架：**现状描述 → 差异分析 → 小结**

【拆解】本科的数据分析不是越高级越好，是"现状讲透 + 方法透明 + 局限如实"。
方法选择对照表和工具 → `09-数据与分析`。

【带走】**先描述、后推断**——数据分析的八成工作，在第一次做透视表时就已经完成。

## 收尾

八则案例，翻来覆去是同一件事：**论文的坑都在"以为没问题"的地方**。
把这几则当体检表，走到哪个环节，对一遍同名的那则，安全边际就出来了。
