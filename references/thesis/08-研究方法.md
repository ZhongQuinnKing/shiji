# 论文·研究方法（怎么选、怎么用）

"研究方法"一节在论文里只有几百字，但它是答辩被问的第二多的问题（第一是数据）。
更现实的是：**方法选错了，后面全白干**。这篇按"先分类 → 怎么选 → 逐个方法的操作要点
→ 怎么落笔 → 常见翻车"讲透。

## 一、先定位：你的研究问题属于哪类

选工具之前先回答：**我要干的事是什么性质？**

| 研究目的 | 典型问句 | 方法方向 |
|----------|----------|----------|
| 探索（这事怎么回事） | "X 现象是怎么形成的？" | 访谈、案例、观察 |
| 描述（现状什么样） | "X 的现状/水平/分布如何？" | 问卷、二手数据统计 |
| 解释（有没有关系、为什么） | "A 对 B 有没有影响？" | 问卷+统计、实验 |

先定问题性质，再选方法。反过来（"我想用问卷所以研究点啥呢"）是翻车的起点。

## 二、两大族：量化与质化（一张表看明白）

| | 量化族 | 质化族 |
|--|--------|--------|
| 回答什么 | 有多少、有没有关系 | 怎么回事、为什么 |
| 典型方法 | 问卷、实验、内容分析、二手数据统计 | 访谈、案例研究、文本分析、观察 |
| 样本 | 大样本（几十到上千） | 小样本、深挖（几个到几十个） |
| 数据形态 | 数字 | 文字、材料、记录 |
| 你在做什么 | 测量 | 理解 |

本科两族都行；研究生看学科传统（理工医偏量化，人文社科两边都有）。
两族混着用叫**混合方法**——见第五节。

## 三、怎么选（三步筛）

1. **问题性质定方向**（第一节的表）
2. **资源现实筛一遍**：问卷——发得出去几百份吗？访谈——约得到关键人吗？
   案例——进得了现场吗？**做得成的才是好方法**
3. **导师传统参考**：导师熟悉的方法，出问题有人问——这不是讨好，是资源利用

## 四、四个常用方法的操作要点

### 问卷法（本科最常用）

- **设计流程**：研究问题 → 拆概念维度 → 每维度出题项 → 小范围预试 →
  修改定稿（预试：找 5-10 个人试填，看有没有读不懂的题）
- 题型：单选 / 多选 / **量表题**（李克特五级："非常不同意 → 非常同意"）
- **样本量**：经验参考——题项数的 5-10 倍；要做统计检验还得更多（听导师的）
- 发放：线上线下并用；**回收情况如实报告**（发出 300、回收 250、有效 218——
  三行数写清楚，评委就看这个）
- 信效度：知道意思就行——信度＝测得稳不稳，效度＝测得准不准
  （本科多数被要求报告 Cronbach's α，具体问导师）
- ❌ 翻车现场：题目全带诱导（"您是否同意……的好处？"）；朋友圈发了 60 份，
  正文写"对消费者群体进行了调查"——样本代表性一问就穿

### 访谈法

- 三种：结构式（照提纲念）／**半结构式**（有提纲、能追问——本科首选）／
  非结构式（自由深聊）
- **提纲设计**：漏斗式——暖场题 → 核心问题（3-5 个）→ 收尾开放题
- 约人话术（关键三句）："我是 X 学校 X 专业的学生，在做关于 X 的研究；
  想请教您 20 分钟；结果匿名处理，只用于论文"——第一封消息决定成败
- 现场：**先征得同意再录音**；追问用"能再具体说说吗""当时您怎么想的"——
  追问是访谈的魂，只念提纲不如发问卷
- 之后：转录逐字稿 → 编号（受访者 A、B、C——**匿名是承诺，不是客套**）
- 何时算够：**信息饱和**——新受访者不再说出新东西，就可以停
  （本科常见 5-15 人；纯粹的深度访谈研究学界建议 30+，本科量力，跟导师对齐）

### 案例研究

- 选案例三种思路：**典型**（有代表性）、**极端**（最成功/最失败的）、
  **关键**（能检验理论的）
- 资料要**三角验证**：文档 + 访谈 + 观察，至少两种来源交叉——
  单一来源会被批"证据不足"
- 别把"举例"当案例研究：案例研究是**系统考察一个对象的背景、过程、机制**，
  不是正文里随手插个例子

### 文献研究法与文本分析（最容易被写空）

- 文献研究法不是"我看过文献"——是**以文献本身为研究对象**
  （如政策文本的变迁、某领域研究的趋势计量）
- 文本分析：确定文本来源 → 建分析框架/编码表 → 系统编码 → 归纳——
  **分析框架要出现在论文里**，没框架就是读后感
- 这两类最大的坑：方法一栏写了，正文里找不到"分析"的痕迹

## 五、混合方法（问题需要时）

- 最常见组合：**问卷先探分布，访谈再问原因**（量化找现象、质化挖机制）
- 本科若无把握：**一种主方法做扎实**，好过两种各做一半——
  半成品的方法在答辩上藏不住

## 六、论文里"研究方法"一节怎么写（骨架）

1. 一句话总述研究思路（什么性质的研究、整体怎么设计）
2. 方法点名 + **为什么选它**（与问题的匹配逻辑，一句就够）
3. 具体怎么做：研究对象与样本、工具（问卷/提纲）、过程（怎么收的数据）、
   分析方式（怎么处理的数据）
4. 一句话局限（样本范围、方法边界）

（数据拿到手之后怎么分析 → `09-数据与分析`）

## 七、翻车清单（答辩减分项，逐条自查）

- 方法堆砌：列了四种，实际只用了一种
- 名实不符：写"问卷调查"，实际只发了 50 份、全是熟人
- 错配：研究"为什么"，方法却只有问卷（只能答"有多少"，答不了"为什么"）
- 不写局限：样本、方法的边界一句不提——你不提，评委会替你提
- 开题的技术路线图和正文写法对不上（正文自洽即可，但差异太大要能解释）

## 一句话

方法没有高级低级，只有**匹配不匹配**。答辩最该能脱口而出的一句是：
"**我这个问题，为什么用这个方法最合适。**"答得出，这关就过了。

## 八、案例：一份问卷的两次"返修"

【情境】小陶设计了"大学生睡眠与手机使用"问卷，30 题一气呵成，
发了朋友圈——回收 180 份。导师看了一眼："你这个测不出'关系'。"

【三处病】①全是"是否/单选"，没有量表题——**测不了程度，就做不了相关分析**；
②14 题是诱导性问法（"您是否同意熬夜有害健康？"）；
③样本全是本校本专业——"大学生"三个字撑不住。

【二次返修】①核心变量改成李克特五级量表（睡眠质量 5 题、手机使用
5 题、各配 2 题反向题防"一路同意"）；②中性化措辞（"过去两周，
您平均几点入睡？"）；③发放扩到两个学院+线上社群，回收 260 份

【结果】能跑相关分析了，结论也有了："入睡时间与手机使用时长显著
相关（r=0.42）"。导师："这回像研究了。"

【拆解】问卷的两次返修只改了三样：**量表题（测得出程度）、中性措辞
（测得出真相）、样本面（撑得起结论）**——三样占齐，一份问卷才
对得起"研究"两个字。
