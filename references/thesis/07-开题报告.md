# 论文·开题报告与开题答辩

开题报告是论文的"施工合同"：向学院证明这个题**能做、值得做、你会做**。
过了这道门，你的题目才算数；没过，改到过为止。这篇说清：报告怎么写、答辩怎么过。

## 一、先立三个认知（想通了就不难写）

1. **它是审批件，不是作文**——评委看的是可行性三件事：问题清楚吗？方法落得下去吗？
   工作量够吗？文采在这里不值钱
2. **它是承诺书**——开了题，题目和方向就有约束力：大改方向要报批、小调可以
   （程序各校不同，问导师）。这不是形式主义，是防止有人写着写着"换了个题"
3. **它是缩小的全文**——开题报告里的文献综述、研究内容、方法，将来直接长成
   论文的绪论和第一章。**这里偷的懒，正文里都要还**

## 二、结构七件套（逐件讲透）

标准结构（各校模板大同小异，**以本校模板为准**；篇幅本科常见 1500-3000 字、
研究生 3000 字起——以本校要求为准）：

### 1. 选题背景与意义——两段式，禁止宏大开场

- **背景**（一段）：从大往小收——领域大背景一两个句号带过，**快速收到你的具体问题**
- **意义**（分两层）：理论意义（对研究领域补什么）+ 现实意义（对谁有用）

❌ 常见翻车："随着社会的发展……"开头的宏大叙述占半页，评委读到第三行还没见到你的题
✅ 正确姿势：**背景不超过半页**，第二页就得让评委看到"所以本文要研究 X"

### 2. 国内外研究现状——"综"与"述"分开做

（文献怎么搜怎么读 → `02-文献检索`）

- **"综"＝归纳**：把几十篇文献按主题/流派/时间**分类整理**——
  不是"张三说 A，李四说 B"的流水账
- **"述"＝评述**：每类研究做到哪了、方法有什么局限、还差什么——
  最后**收敛到"所以本文要研究 X"**
- 结构建议：国外研究 → 国内研究 → 研究述评（不足与空白）
- 数量参考：不少学校要求参考文献 20+ 篇，含核心期刊与外文文献（以本校为准）

❌ 三连错（评审手册高频批评）：**列举无归纳**（五十篇文献五十个"认为"）；
**平行不聚焦**（每篇提一句、没有一篇说透、也没收到自己题目）；
**主观评论过早**（综述堆"我认为"，评述应留给专门的"研究述评"一节）。

### 3. 研究内容——把"研究问题"拆成章

- 一句话写出研究问题——写不出来就是还没想清（回 `01-选题`）
- 附论文提纲，编到三级标题：每章回答什么子问题，摆在同一页上
- 节奏感：一般 5-6 章、工作量均衡，避免头重脚轻

### 4. 研究方法与技术路线

- 方法要**点名**：问卷法 / 访谈法 / 案例法 / 文献研究法 / 实验法……
  不写"采用多种方法"这种空话
- 关键：**方法与问题匹配**（怎么选 → `08-研究方法`）
- **技术路线图**：一张流程图把"从问题到结论"画出来——五六个方框加箭头，
  用 PPT 就能画。评委特别爱看图：**图清楚＝你想清楚了**

### 5. 重点难点与解决方案

- 诚实一点：数据可能难拿、样本可能难找——**但每个难点后面必须跟一个方案**
  （"若问卷回收不足，将增加线上渠道并联系校友协助发放"）
- 只写难点不写方案＝给评委递刀

### 6. 进度安排

和全流程倒排表对齐（`00-论文全流程` 的表直接改成本校时间点）。

### 7. 参考文献

格式照 GB/T 7714（→ `04-规范与格式`）；数量以本校要求为准。

## 三、开题答辩：三个回合

流程通常是：个人陈述 5-8 分钟 → 评委提问 → 当场或事后给结论（各校略不同）。
过了，进入写作；没过，按意见改后重审——**多数学校都允许，不算事故**。

### 陈述讲稿骨架（5-8 分钟）

1. 题目一句话 + 为什么做（30 秒）
2. 别人做到哪、缺什么（1-2 分钟，综述压缩版）
3. 我要做什么、怎么做（2-3 分钟，**这是重点**）
4. 难点与对策 + 进度（1 分钟）

### 大概率被问的五个问题（提前写好答案）

1. **"这个题别人做过吗？你的增量在哪？"**→ 用"四新占一"答：
   新对象 / 新场景 / 新数据 / 新方法（→ `01-选题`）
2. **"数据/样本拿得到吗？"**→ 给具体渠道 + 备选渠道（"主渠道 X，备份渠道 Y"）
3. **"为什么用这个方法？"**→ 方法与问题的匹配逻辑（→ `08-研究方法`）
4. **"工作量够不够？"**→ 用章节提纲答（每章都有活干）
5. **"题目是不是太大了？"**→ 顺从地收边界："您说得对，我可以收窄到 XX 范围"——
   **被指正时收缩比辩护得分高**

### 开题被毙或要求大改，怎么办

- 先别慌也别硬刚：**评委的否定几乎都是"防守提醒"**——他们见过太多人栽在你正要踩的坑上
- 拿意见清单回去：逐条改、改完再谈；多数学校有二次开题，改到位就过
- 大改不丢人：开题改十稿，好过答辩挂一次

**案例**：小宋开题答辩被要求"大改"（评委三位提了同一个问题：
研究问题不聚焦）。她当天没有急着改稿，而是做了一件事，**把三条意见
抄在一张纸上，逐条翻译成"评委其实在担心什么"**：
"不聚焦"＝"你自己都不知道要回答哪个问题"；然后带着这张纸去找导师，
十五分钟就把新题目定了下来（聚焦到"X 场景下的 Y 问题"）。
二次开题一次通过。她的实操心得：**意见别当天改、别自己硬猜——
先翻译成"担心清单"，拿给导师对齐**，改起来是几小时的事。

（**多数学校允许二次开题**——把它当"免费的第一轮评审"，
拿到意见就是赚到。）

## 四、和导师的分工

- 报告**写完先给导师过**——多数学校流程要求导师审阅/签字，别直接拿去答辩
- 给导师看的版本：把不确定处**标出来问**
  （"第 2 节综述我拿不准按主题还是按时间线组织，您看哪种顺？"）——
  比"老师您看看"高效十倍

## 一句话

开题报告每一节，都是在替评委问你自己：**这个问题，真想清楚了吗？**
想清楚了，报告是自然流出来的；没想清，怎么润色都是空的。
